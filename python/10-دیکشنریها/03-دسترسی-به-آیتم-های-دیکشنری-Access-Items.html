دسترسی به آیتم های دیکشنری (Access Items)

هدف: با کلید مقدار را بخوانی و بدانی [] در نبود کلید خطا می‌دهد ولی get می‌تواند پیش‌فرض بدهد.

پوشه: دیکشنری‌ها  |  پیش‌نیاز: درس‌های قبلی «دیکشنری‌ها».
ارتباط با قبل: این مبحث در پوشهٔ «دیکشنری‌ها» بعد از مفاهیم قبلی همان موضوع می‌آید؛ قبل از پرش به درس بعدی، مثال را خودت یک‌بار تایپ کن.

مفهوم

برخلاف لیست که با شماره کار می‌کند، دیکشنری با کلید کار می‌کند. d["name"] اگر کلید نباشد KeyError می‌دهد. d.get("name", پیش‌فرض) امن‌تر است.

ساختار

d["key"] d.get("key", default) "key" in d

مثال 1: [] و get

user = {"name": "سارا", "age": 20} print(user["name"]) print(user.get("city", "نامشخص")) print("age" in user)
خط ۲: کلید name هست → سارا.
خط ۳: city نیست؛ به‌جای خطا «نامشخص» برمی‌گردد.
خط ۴: in روی کلیدها True/False می‌دهد.

مثال 2: keys و values

user = {"name": "سارا", "age": 20} print(list(user.keys())) print(list(user.values()))
خط ۲: لیست کلیدها.
خط ۳: لیست مقادیر.

اشتباه رایج

d = {"a": 1} print(d["b"])
چرا اشتباه است؟ کلید b وجود ندارد.
چه می‌بینی؟ KeyError: 'b'
درست: print(d.get("b")) یا if "b" in d: ...
معیار تمام‌شدن: بتوانی بدون نگاه به متن، یک مثال سه‌خطی دربارهٔ «دسترسی به آیتم های دیکشنری» بنویسی و اجرا کنی.
جمع‌بندی
  • دسترسی با کلید نه ایندکس عددی.
  • [] → KeyError اگر نباشد.
  • get → پیش‌فرض یا None.
  • in وجود کلید را چک می‌کند.

گام عملی

  1. یک dict کاربر بساز و name را چاپ کن.
  2. با get فیلد اختیاری را با پیش‌فرض بگیر.
  3. عمداً کلید ناموجود با [] بخوان و KeyError را ببین.

اگر گیر کردی: فقط همان خط خطا را با بخش «اشتباه رایج» و توضیح خط‌به‌خط مقایسه کن؛ کل درس را از صفر حفظ نکن.
