MongoDB: شروع (Get Started)

هدف: با PyMongo یک سند را بر اساس فیلد مشخص پیدا کنی و فیلدهای لازم را از نتیجه بخوانی.

پوشه: شروع و مبانی  |  پیش‌نیاز: درس‌های قبلی «شروع و مبانی».
ارتباط با قبل: dict و list داده را در RAM نگه می‌داشتند؛ دیتابیس بعد از بستن برنامه هم می‌ماند.

مفهوم

MongoDB سندها را در collection نگه می‌دارد. با PyMongo می‌توانی شرط جستجو را به شکل یک دیکشنری بنویسی؛ لازم نیست query را با اتصال رشته بسازی.

پیش‌نیاز اجرا

python -m pip install pymongo

مثال: پیدا کردن سفارش با شناسه

import os from pymongo import MongoClient client = MongoClient(os.environ["MONGODB_URI"]) orders = client.shop.orders order = orders.find_one( {"order_id": 1042}, {"_id": 0, "order_id": 1, "status": 1}, ) print(order) client.close()
پیش‌نیاز: MongoDB در دسترس باشد و نشانی اتصال در متغیر محیطی MONGODB_URI تنظیم شده باشد.
find_one: اولین سند منطبق را پیدا می‌کند؛ projection فقط فیلدهای خواسته‌شده را برمی‌گرداند.

اشتباه رایج

query = "SELECT * FROM users WHERE name = '" + name + "'"
چرا اشتباه است؟ ورودی کاربر می‌تواند کوئری را بشکند یا داده بدزدد.
چه می‌بینی؟ آسیب‌پذیری SQL Injection
درست: execute با پارامتر جدا
معیار تمام‌شدن: یک filter دیکشنری بسازی و توضیح بدهی projection چه فیلدهایی را در خروجی نگه می‌دارد.
جمع‌بندی
  • داده پایدار
  • کوئری پارامتریک
  • هرگز ورودی را مستقیم بچسبان
  • درایور رسمی

گام عملی

  1. فیلتر را تغییر بده تا سفارش با وضعیت shipped پیدا شود.
  2. یک SELECT مفهومی با placeholder بنویس.

اگر گیر کردی: فقط همان خط خطا را با بخش «اشتباه رایج» و توضیح خط‌به‌خط مقایسه کن؛ کل درس را از صفر حفظ نکن.
