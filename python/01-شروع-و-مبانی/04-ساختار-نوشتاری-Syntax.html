ساختار نوشتاری پایتون

هدف این درس: قواعد نوشتن کد در پایتون را بفهمی؛ مخصوصاً اهمیت تورفتگی (indentation).

مفهوم به زبان ساده

در خیلی از زبان‌ها با آکولاد { } بلوک کد را مشخص می‌کنند. در پایتون به جای آکولاد از تورفتگی (فاصله از اول خط) استفاده می‌شود. این ویژگی باعث می‌شود کد پایتون خیلی خوانا باشد.

تورفتگی چگونه کار می‌کند؟

if True: print("این خط داخل بلوک است") print("این هم داخل همان بلوک است") print("این خط بیرون بلوک است")
خطوطی که فاصله از اول دارند، متعلق به بلوک بالایی هستند.
معمولاً از ۴ فاصله (یا یک Tab) استفاده می‌کنیم.

حروف بزرگ و کوچک مهم هستند

name = "Ali" print(name) # درست # print(Name) # خطا می‌دهد چون Name تعریف نشده
پایتون بین name و Name تفاوت قائل می‌شود. همیشه یکسان بنویس.

اشتباه رایج تورفتگی

if True: print("خطا!")
مشکل: بعد از : باید خط بعدی تورفتگی داشته باشد.
خطا: IndentationError
درست:
if True: print("درست است")
معیار تمام‌شدن درس: بتوانی یک بلوک ساده با تورفتگی درست بنویسی و خطای IndentationError نگیری.
جمع‌بندی
  • پایتون به جای { } از تورفتگی استفاده می‌کند
  • معمولاً ۴ فاصله برای هر سطح
  • حروف بزرگ و کوچک مهم هستند
  • تورفتگی اشتباه = IndentationError

گام عملی

  1. یک شرط ساده if بنویس و دو دستور داخل آن با تورفتگی قرار بده.
  2. عمداً تورفتگی را حذف کن و پیام خطا را بخوان تا با آن آشنا شوی.
