ساختار نوشتاری (Syntax)

هدف: بفهمی پایتون چطور کد را می‌خواند و چرا تورفتگی مهم است.

در پایتون، فاصله ابتدای خط (تورفتگی) بخشی از قواعد زبان است. بلوک‌های کد معمولاً با تورفتگی مشخص می‌شوند.

x = 10 if x > 5: print("بزرگ‌تر از پنج") print("پایان")
توضیح خط‌به‌خط
  1. خط 1x = 10مقداردهی.
  2. خط 2if x > 5:شرط؛ بعد از : بدنه می‌آید.
  3. خط 3print(...)این خط داخل if است چون تورفتگی دارد.
  4. خط 4print("پایان")بیرون از if اجرا می‌شود.
جمع‌بندی
  • تورفتگی در پایتون معنا دارد.
  • ترتیب خطوط از بالا به پایین اجرا می‌شود.
