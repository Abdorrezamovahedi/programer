Matplotlib مقدمه (Matplotlib Intro)

هدف: بفهمی Matplotlib داده‌های عددی را به نمودار تبدیل می‌کند و نخستین نمودار خطی را بسازی.

پوشه: شروع و مبانی  |  پیش‌نیاز: درس‌های قبلی «شروع و مبانی».
ارتباط با قبل: list و dict پایه بودند؛ اینجا همان داده با ابزار تخصصی سریع‌تر و بزرگ‌تر پردازش می‌شود.

مفهوم

Matplotlib کتابخانه‌ای برای رسم نمودار در Python است. داده‌ها را به آن می‌دهی و با pyplot نمودار می‌سازی. برای اجرای مثال باید کتابخانه را نصب کرده باشی.

ساختار

python -m pip install matplotlib

مثال: رسم تعداد بازدید روزانه

import matplotlib.pyplot as plt days = ["Mon", "Tue", "Wed"] visitors = [12, 18, 15] plt.plot(days, visitors, marker="o") plt.show()
خروجی: نمودار خطی سه نقطهٔ Mon، Tue و Wed را نمایش می‌دهد.
plt.plot: داده‌ها را به شکل خط رسم می‌کند؛ plt.show: پنجرهٔ نمودار را باز می‌کند.

اشتباه رایج

import matplotlib.pyplot as plt
اگر Matplotlib نصب نباشد import خطای ModuleNotFoundError می‌دهد.
درست: python -m pip install matplotlib را در محیط مجازی پروژه اجرا کن.
معیار تمام‌شدن: یک فهرست x و y بسازی و بدانی plot هر جفت مقدار را به چه نقطه‌ای تبدیل می‌کند.
جمع‌بندی
  • Matplotlib داده‌ها را نمودار می‌کند.
  • pyplot ابزار رسم نمودار است.
  • plot نمودار خطی می‌سازد.
  • برای نمایش نمودار show را اجرا کن.

گام عملی

  1. برچسب روزها و تعداد بازدیدها را با داده‌های دلخواه جایگزین کن.
  2. تعداد بازدید روز چهارم را اضافه و نمودار را دوباره رسم کن.

اگر گیر کردی: فقط همان خط خطا را با بخش «اشتباه رایج» و توضیح خط‌به‌خط مقایسه کن؛ کل درس را از صفر حفظ نکن.
