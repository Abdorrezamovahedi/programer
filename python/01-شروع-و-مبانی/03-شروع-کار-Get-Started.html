شروع کار با پایتون

هدف: بدانی از کجا پایتون را اجرا کنی و اولین برنامه را ببینی.

برای شروع می‌توانی Python 3 را نصب کنی یا از محیط آنلاین پایتون استفاده کنی. مهم این است که بتوانی یک فایل یا یک سلول کد را اجرا کنی.

print("اولین برنامه من") print(2 + 3)
توضیح خط‌به‌خط
  1. خط 1print("...")یک متن را چاپ می‌کند.
  2. خط 2print(2 + 3)نتیجه جمع را چاپ می‌کند: 5.
جمع‌بندی
  • محیط اجرا را آماده کن.
  • با print خروجی را ببین.
