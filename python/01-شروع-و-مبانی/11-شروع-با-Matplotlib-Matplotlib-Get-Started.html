شروع با Matplotlib (Matplotlib Get Started)

هدف: بدانی این مبحث روی آرایه/جدول داده و مدل‌سازی آماری سوار است و نیاز به نصب کتابخانه دارد.

پوشه: شروع و مبانی  |  پیش‌نیاز: درس‌های قبلی «شروع و مبانی».
ارتباط با قبل: list و dict پایه بودند؛ اینجا همان داده با ابزار تخصصی سریع‌تر و بزرگ‌تر پردازش می‌شود.

مفهوم

NumPy آرایهٔ عددی سریع است؛ Pandas جدول (DataFrame)؛ مدل‌های ML از دادهٔ آموزش الگو می‌گیرند و روی دادهٔ جدید پیش‌بینی می‌کنند. بدون نصب پکیج، کد واقعی اجرا نمی‌شود.

ساختار

# pip install numpy pandas # import numpy as np

مثال 1: ایده بدون وابستگی اجباری

# مفهوم: میانگین دستی شبیه ایدهٔ آماری data = [2, 4, 4, 6] mean = sum(data) / len(data) print(mean) # در NumPy: np.mean(np.array(data))
data: نمونهٔ کوچک به‌جای دیتاست بزرگ.
mean: همان ایده‌ای که کتابخانه‌ها بهینه می‌کنند.

اشتباه رایج

import numpy as np # بدون نصب
چرا اشتباه است؟ پکیج روی سیستم نیست.
چه می‌بینی؟ ModuleNotFoundError
درست: pip install numpy (ترجیحاً داخل venv)
معیار تمام‌شدن: میانگین یک لیست را با خالص پایتون حساب کنی و بگویی معادلش در NumPy چیست.
