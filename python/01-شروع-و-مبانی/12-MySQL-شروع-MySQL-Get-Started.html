MySQL: شروع (MySQL Get Started)

هدف: بفهمی دیتابیس داده را پایدار نگه می‌دارد و کوئری باید پارامتریک باشد نه چسباندن رشته.

پوشه: شروع و مبانی  |  پیش‌نیاز: درس‌های قبلی «شروع و مبانی».
ارتباط با قبل: dict و list داده را در RAM نگه می‌داشتند؛ دیتابیس بعد از بستن برنامه هم می‌ماند.

مفهوم

فایل برای دادهٔ کوچک کافی است؛ دیتابیس برای جستجو، هم‌زمانی و یکپارچگی ساخته شده. در کد واقعی از placeholder استفاده کن نه f-string داخل SQL.

پیش‌نیاز اجرا

python -m pip install mysql-connector-python

مثال: خواندن نام محصول با شناسه

import os import mysql.connector product_id = 7 connection = mysql.connector.connect( host="127.0.0.1", user="app_user", password=os.environ["MYSQL_PASSWORD"], database="shop", ) try: cursor = connection.cursor() cursor.execute( "SELECT name FROM products WHERE id = %s", (product_id,), ) print(cursor.fetchone()) finally: cursor.close() connection.close()
پیش‌نیاز: سرور MySQL و جدول products باید از قبل آماده باشند؛ رمز را در متغیر محیطی MYSQL_PASSWORD بگذار.
%s و tuple: درایور مقدار را جدا از دستور SQL می‌فرستد و از چسباندن ورودی جلوگیری می‌کند.

اشتباه رایج

query = "SELECT * FROM users WHERE name = '" + name + "'"
چرا اشتباه است؟ ورودی کاربر می‌تواند کوئری را بشکند یا داده بدزدد.
چه می‌بینی؟ آسیب‌پذیری SQL Injection
درست: execute با پارامتر جدا
معیار تمام‌شدن: یک مقدار را با placeholder پارامتری به query بدهی و توضیح بدهی چرا رمز دیتابیس در کد ثابت نوشته نشده است.
جمع‌بندی
  • داده پایدار
  • کوئری پارامتریک
  • هرگز ورودی را مستقیم بچسبان
  • درایور رسمی

گام عملی

  1. تفاوت فایل و DB را در دو خط بنویس.
  2. یک SELECT مفهومی با placeholder بنویس.

اگر گیر کردی: فقط همان خط خطا را با بخش «اشتباه رایج» و توضیح خط‌به‌خط مقایسه کن؛ کل درس را از صفر حفظ نکن.
