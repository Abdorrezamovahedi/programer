پایتون چیست؟

هدف این درس: بفهمی پایتون چه زبانی است، چرا برای شروع عالی است و بتوانی اولین دستور ساده را بنویسی و اجرا کنی.

پیش‌نیاز: هیچ. حتی اگر تا حالا هیچ کدی ننوشته‌ای، این درس برای توست.
برای اجرای مثال‌ها می‌توانی Python 3 را نصب کنی یا از محیط‌های آنلاین پایتون استفاده کنی.

مفهوم به زبان خیلی ساده

پایتون یک زبان برنامه‌نویسی است. یعنی با آن به کامپیوتر می‌گویی چه کاری انجام دهد. تفاوتش با زبان‌های سخت این است که دستورهایش خیلی شبیه زبان انسان نوشته می‌شوند و خواندنشان آسان است.

مثلاً برای چاپ یک پیام روی صفحه فقط می‌نویسی:

print("سلام دنیا")

همین یک خط کافی است تا کامپیوتر پیام «سلام دنیا» را نشان دهد. به همین سادگی.

پایتون کجا استفاده می‌شود؟

  • خودکارسازی کارها: کارهای تکراری را به کامپیوتر بسپار
  • توسعه وب: ساخت بخش‌های پشتیبان سایت‌ها
  • تحلیل داده: کار با جدول‌ها و آمار
  • یادگیری ماشین و هوش مصنوعی: یکی از محبوب‌ترین زبان‌ها در این حوزه
  • ساخت ابزارهای ساده روزمره: از محاسبه تا مرتب‌کردن فایل‌ها

مثال: ذخیره و نمایش یک مقدار

بیایید یک مقدار را در حافظه نگه داریم و بعد آن را چاپ کنیم:

language = "Python" print("در حال یادگیری", language)
خط ۱: یک متغیر به نام language می‌سازیم و متن «Python» را داخل آن قرار می‌دهیم.
متغیر مثل یک جعبه‌ی نام‌گذاری‌شده است که می‌توانی چیزی داخلش بگذاری و بعداً استفاده کنی.
خط ۲: با دستور print دو چیز را چاپ می‌کنیم: متن «در حال یادگیری» و مقدار داخل متغیر language.

اشتباه رایج مبتدی‌ها

خیلی‌ها این کد را تنها اجرا می‌کنند و خطا می‌گیرند:

print(language)
چرا خطا می‌دهد؟
چون هنوز متغیر language را تعریف نکرده‌ای. پایتون نمی‌داند language چیست و خطای NameError می‌دهد.
راه حل: همیشه اول متغیر را بساز، بعد از آن استفاده کن.
معیار تمام‌شدن این درس:
باید بتوانی با زبان خودت توضیح بدهی پایتون چیست و یک متن ساده را با print روی صفحه نشان بدهی.
جمع‌بندی
  • پایتون زبانی خوانا و مناسب برای شروع برنامه‌نویسی است.
  • دستورها معمولاً خط‌به‌خط از بالا به پایین اجرا می‌شوند.
  • print() برای دیدن نتیجه روی صفحه استفاده می‌شود.
  • متغیر نامی است که یک مقدار را در حافظه نگه می‌دارد.
  • قبل از استفاده از متغیر، باید آن را تعریف کرده باشی.

گام عملی — همین الان انجام بده

  1. یک متغیر به نام name بساز و اسم خودت را داخل آن قرار بده. سپس با print آن را چاپ کن.
  2. دو متغیر بساز (مثلاً city و age) و هر دو را در یک دستور print نشان بده.

عجله نکن. همین تمرین‌های خیلی کوچک باعث می‌شوند مفهوم در ذهنت بنشیند. اگر خطا دیدی، پیام خطا را بخوان؛ معمولاً خودش راهنمایی می‌کند.
