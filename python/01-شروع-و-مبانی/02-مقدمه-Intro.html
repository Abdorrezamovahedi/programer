پایتون چیست؟

هدف: با ماهیت زبان پایتون، چند کاربرد رایج آن و شکل اجرای یک دستور ساده آشنا شوی.

پیش‌نیاز: ندارد. برای اجرای مثال‌ها، Python 3 را نصب کن یا از محیط آموزشی پایتون استفاده کن.

آشنایی با پایتون

پایتون زبانی عمومی و سطح‌بالاست که به‌خاطر خوانایی دستورهایش در خودکارسازی کارها، توسعهٔ وب، تحلیل داده و یادگیری ماشین استفاده می‌شود. برای شروع، کافی است دستور را بنویسی و آن را با مفسر پایتون اجرا کنی.

مثال: ذخیره و نمایش یک مقدار

language = "Python"
print("در حال یادگیری", language)
خط ۱: متن Python در متغیر language ذخیره می‌شود.
خط ۲: print() دو مقدار را با فاصله در خروجی نشان می‌دهد.

اشتباه رایج

print(language)
چرا خطا می‌دهد؟ اگر خط نمایش را بدون اجرای خط تعریف متغیر اجرا کنی، پایتون متغیر language را نمی‌شناسد و NameError می‌دهد. ابتدا متغیر را تعریف کن.
معیار یادگیری: بتوانی توضیح بدهی پایتون چه نوع زبانی است و یک مقدار متنی را در خروجی نمایش دهی.
جمع‌بندی
  • دستورها معمولاً خط‌به‌خط اجرا می‌شوند.
  • print برای دیدن نتیجه.
  • پایتون برای خودکارسازی، وب و داده کاربرد دارد.
  • متغیر نامی برای نگهداری یک مقدار است.
  • print() مقدارها را در خروجی نشان می‌دهد.

گام عملی

  1. دو print پشت سر هم بنویس.
  2. یک محاسبهٔ ساده چاپ کن.
  3. مقدار متغیر را عوض کن و خروجی را دوباره ببین.

اگر گیر کردی: فقط همان خط خطا را با بخش «اشتباه رایج» و توضیح خط‌به‌خط مقایسه کن؛ کل درس را از صفر حفظ نکن.
