توضیحات (کامنت) در پایتون

هدف این درس: یاد بگیری چطور در پایتون توضیح بنویسی تا کد خواناتر شود و بتوانی بخش‌هایی از کد را موقتاً غیرفعال کنی.

مفهوم به زبان ساده

کامنت یادداشتی است که فقط برای انسان نوشته می‌شود. پایتون آن را اجرا نمی‌کند و هیچ تأثیری روی نتیجه برنامه ندارد.

کامنت تک‌خطی

با علامت # شروع می‌شود و تا پایان همان خط ادامه دارد.

# این یک توضیح است print("سلام") # این هم توضیح کنار کد است
هر چیزی بعد از # تا آخر خط نادیده گرفته می‌شود.

کامنت چندخطی

برای توضیحات طولانی‌تر از سه علامت نقل‌قول استفاده می‌کنیم:

""" این یک توضیح چند خطی است. می‌تواند چندین خط باشد. """ print("کد اصلی")
این روش بیشتر برای توضیح کل توابع یا بخش‌های بزرگ استفاده می‌شود.

غیرفعال کردن موقت کد

print("این اجرا می‌شود") # print("این فعلاً اجرا نمی‌شود") print("این هم اجرا می‌شود")
با گذاشتن # جلوی یک خط، آن خط موقتاً از کار می‌افتد بدون اینکه پاکش کنی.

اشتباه رایج

/* این کامنت CSS است و در پایتون کار نمی‌کند */ print("سلام")
مشکل: علامت‌های /* */ مخصوص CSS هستند.
در پایتون: از # برای تک‌خطی و از """ برای چندخطی استفاده کن.
معیار تمام‌شدن درس: بتوانی حداقل دو کامنت مفید (یکی تک‌خطی و یکی برای غیرفعال کردن) بنویسی.
جمع‌بندی
  • کامنت تک‌خطی با #
  • کامنت چندخطی با """ ... """
  • پایتون کامنت را اجرا نمی‌کند
  • برای توضیح و غیرفعال کردن موقت کد عالی است

گام عملی

  1. بالای یک دستور print یک کامنت بنویس که بگوید این دستور چه کاری انجام می‌دهد.
  2. یک دستور را با # موقتاً غیرفعال کن و ببین خروجی چه تغییری می‌کند.
