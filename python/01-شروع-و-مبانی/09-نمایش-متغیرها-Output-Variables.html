هدف درس

در پایان این درس می‌توانی مقدار ذخیره‌شده در متغیر را با print ببینی و متن و عدد را کنار هم چاپ کنی.

پیش‌نیازها

  • متغیرها
  • خروجی با print
name = "Sara" age = 20 print(name) print("سن:", age)
توضیح خط‌به‌خط همین مثال
  1. خط 1: name = "Sara" — رشته را در متغیر name می‌گذارد.
  2. خط 2: age = 20 — عدد را در age می‌گذارد.
  3. خط 3: print(name) — مقدار name را چاپ می‌کند.
  4. خط 4: print("سن:", age) — متن و مقدار age را کنار هم چاپ می‌کند.
جمع‌بندی
  • برای دیدن مقدار متغیر از print استفاده کن
  • می‌توانی چند چیز را با کاما در print جدا کنی
  1. متغیر city بساز و چاپ کن.
  2. متن «سن من» و یک عدد را با هم چاپ کن.
