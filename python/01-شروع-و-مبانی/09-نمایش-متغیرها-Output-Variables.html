نمایش متغیرها در پایتون

هدف این درس: بتوانی مقدار یک یا چند متغیر را به شکل خوانا روی صفحه نشان بدهی.

مفهوم به زبان ساده

متغیر مثل جعبه‌ای است که چیزی داخلش گذاشته‌ای. برای دیدن محتویات جعبه از print استفاده می‌کنیم.

چاپ یک متغیر

name = "مینا" print(name)

چاپ چند متغیر با متن

name = "مینا" age = 22 city = "اصفهان" print("نام:", name) print("سن:", age) print("شهر:", city)
با گذاشتن متن قبل از متغیر، خروجی خواناتر می‌شود.

همه در یک خط

print(name, "در", city, "زندگی می‌کند و", age, "ساله است")
معیار تمام‌شدن درس: بتوانی اطلاعات چند متغیر را به شکل مرتب و خوانا چاپ کنی.
جمع‌بندی
  • برای دیدن مقدار متغیر از print استفاده کن
  • متن و متغیر را می‌توانی با کاما کنار هم بگذاری
  • ترتیب آرگومان‌ها در خروجی حفظ می‌شود

گام عملی

  1. نام، سن و علاقه خودت را در سه متغیر ذخیره کن و مرتب چاپ کن.
  2. همه را در یک print پشت سر هم نشان بده.
