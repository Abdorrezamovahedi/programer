دستورات در پایتون

هدف این درس: بفهمی هر خط کد معمولاً یک دستور است و چطور دستورها پشت سر هم اجرا می‌شوند.

مفهوم به زبان ساده

دستور یعنی یک کار کامل که به پایتون می‌گویی انجام بدهد. مثل «این مقدار را ذخیره کن» یا «این متن را چاپ کن».

هر خط یک دستور

name = "سارا" age = 25 print(name) print(age)
خط ۱: یک دستور برای ساخت متغیر name
خط ۲: یک دستور برای ساخت متغیر age
خط ۳ و ۴: دو دستور برای چاپ

ترتیب اجرا مهم است

پایتون از بالا به پایین خط‌ها را یکی‌یکی اجرا می‌کند. اگر متغیری را قبل از تعریف استفاده کنی، خطا می‌گیری.

print(city) # خطا! هنوز تعریف نشده city = "تهران"
همیشه اول تعریف کن، بعد استفاده کن.
معیار تمام‌شدن درس: بتوانی چند دستور پشت سر هم بنویسی و ترتیب درست آن‌ها را رعایت کنی.
جمع‌بندی
  • هر خط معمولاً یک دستور است
  • دستورها از بالا به پایین اجرا می‌شوند
  • قبل از استفاده از متغیر، باید آن را تعریف کرده باشی

گام عملی

  1. سه متغیر بساز و هر سه را چاپ کن.
  2. عمداً ترتیب را عوض کن و پیام خطا را ببین.
