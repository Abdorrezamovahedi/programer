تمرین نهایی RegEx

هدف درس: چند مهارت RegEx را در یک سناریوی کوچک کنار هم استفاده کنی.

  • ترکیب findall و match و sub
  • تمرین عملی روی یک متن واقعی‌تر
  • مرور مسیر کامل بخش RegEx
قبل از دیدن پاسخ خودت امتحان کن:
  1. همه رقم‌های متن را پیدا کن.
  2. بررسی کن متن با «سلام» شروع می‌شود یا نه.
  3. دنباله‌های عددی را با # عوض کن.
import re msg = "سلام 42 بار و 7 پیام" print(re.findall(r"\d+", msg)) print(bool(re.match(r"سلام", msg))) print(re.sub(r"\d+", "#", msg))
توضیح خط‌به‌خط
  1. خط 2msg = ...متن تمرین.
  2. خط 3findallهمه اعداد: 42 و 7.
  3. خط 4matchبررسی شروع متن با سلام.
  4. خط 5subاعداد را با # جایگزین می‌کند.
جمع‌بندی
  • findall برای گرفتن همه موارد
  • match برای بررسی شروع متن
  • sub برای ویرایش متن
  • با تمرین روی متن خودت مطلب تثبیت می‌شود
