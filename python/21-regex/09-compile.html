compile و پرچم‌ها

هدف درس: الگو را با compile از پیش بسازی و پرچم‌هایی مثل IGNORECASE را بشناسی.

  • re.compile برای الگوی آماده‌شده
  • پرچم IGNORECASE
  • استفاده چندباره از یک الگو

اگر یک الگو را چند بار استفاده می‌کنی، یک‌بار آن را compile کن. IGNORECASE باعث می‌شود بزرگی و کوچکی حروف انگلیسی مهم نباشد.

import re pat = re.compile(r"python", re.IGNORECASE) print(bool(pat.search("I love PYTHON"))) print(bool(pat.search("python3")))
توضیح خط‌به‌خط
  1. خط 2compile(...)الگو یک‌بار ساخته می‌شود.
  2. خط 2IGNORECASEحروف بزرگ و کوچک یکی گرفته می‌شوند.
  3. خط 3search("I love PYTHON")با وجود حروف بزرگ، تطابق دارد.
جمع‌بندی
  • compile الگو را آماده نگه می‌دارد
  • IGNORECASE حساسیت حروف را کم می‌کند
  • برای استفاده تکراری مفید است
