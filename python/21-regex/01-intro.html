مقدمه و ماژول re در پایتون

هدف درس: بفهمی عبارت منظم چیست، چه زمانی به آن نیاز داری، و اولین جست‌وجو را با re.search درست انجام بدهی.

پیش‌نیاز: آشنایی خیلی کوتاه با رشته و print.

در این درس چه چیزی یاد می‌گیری؟

  • تفاوت جست‌وجوی متن ثابت با الگوی متن
  • نقش ماژول استاندارد re
  • اولین استفاده از re.search
  • معنی الگوی r"\d+" و raw string

این مفهوم چیست؟

گاهی نمی‌خواهی فقط یک کلمه مشخص را پیدا کنی؛ می‌خواهی «شکل» متن را پیدا کنی. مثلاً «هر عددی که در پیام آمده». این‌جا عبارت منظم (RegEx) به کار می‌آید.

در پایتون از ماژول استاندارد re استفاده می‌کنیم؛ نیازی به نصب جداگانه نیست.

مثال پایه

import re text = "قیمت نهایی 250 تومان است" result = re.search(r"\d+", text) print(result) if result: print(result.group())
توضیح خط‌به‌خط همین مثال
  1. خط 1import reماژول عبارات منظم را وارد می‌کند.
  2. خط 2text = "..."متنی که داخلش می‌گردیم.
  3. خط 3re.search(r"\d+", text)\d+ یعنی یک یا چند رقم؛ search اولین مورد را پیدا می‌کند.
  4. خط 4print(result)شیء نتیجه یا None.
  5. خط 5-6if result: print(result.group())فقط اگر چیزی پیدا شد، متن پیدا‌شده را چاپ کن.
نکته: حرف r قبل از الگو (raw string) بک‌اسلش‌ها را درست نگه می‌دارد.

اشتباه‌های رایج

  • فراموش کردن import re
  • خواندن group وقتی result برابر None است
  • نوشتن الگو بدون r
جمع‌بندی
  • RegEx الگوی متن است.
  • در پایتون با ماژول re کار می‌کنیم.
  • search اولین تطابق را پیدا می‌کند.
  • \d+ یعنی یک یا چند رقم.
