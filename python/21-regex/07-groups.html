گروه‌ها در RegEx

هدف درس: با پرانتز گروه بسازی و بخشی از متن پیدا‌شده را جدا بخوانی.

  • گروه‌بندی با ()
  • خواندن group(1) و group(2)
  • جدا کردن بخش‌های یک الگو مثل قبل و بعد @

پرانتز یک گروه می‌سازد تا بتوانی قسمت‌های مختلف الگو را جداگانه برداری.

import re m = re.search(r"(\w+)@(\w+\.\w+)", "user@mail.com") print(m.group(0)) print(m.group(1)) print(m.group(2))
توضیح خط‌به‌خط
  1. خط 2(\w+)@(...)دو گروه: قبل از @ و دامنه.
  2. خط 3group(0)کل تطابق.
  3. خط 4group(1)گروه اول: user
  4. خط 5group(2)گروه دوم: mail.com
جمع‌بندی
  • () گروه می‌سازد
  • group(1) اولین گروه است
  • group(0) کل تطابق است
