search و match در پایتون

هدف درس: فرق دقیق re.search و re.match را بفهمی و بدانی هرکدام کجا مناسب است.

در این درس چه چیزی یاد می‌گیری؟

  • رفتار search در کل متن
  • رفتار match فقط از ابتدای متن
  • نتیجه None وقتی چیزی پیدا نشود
  • انتخاب درست بین search و match

مفهوم به زبان ساده

هر دو تابع برای پیدا کردن الگو هستند، اما نقطه شروعشان فرق دارد. search متن را می‌گردد و اولین مورد مناسب را برمی‌گرداند. match فقط اول متن را بررسی می‌کند؛ اگر از همان ابتدا جور نباشد، حتی با وجود الگو در وسط متن، نتیجه None است.

مثال

import re s = "abc123xyz" print(re.search(r"\d+", s)) print(re.match(r"\d+", s)) print(re.match(r"abc", s))
توضیح خط‌به‌خط همین مثال
  1. خط 1import reماژول re را می‌آوریم.
  2. خط 2s = "abc123xyz"متن نمونه با رقم در وسط.
  3. خط 3re.search(r"\d+", s)رقم را در وسط متن پیدا می‌کند.
  4. خط 4re.match(r"\d+", s)چون متن با رقم شروع نشده، None می‌دهد.
  5. خط 5re.match(r"abc", s)متن با abc شروع شده؛ تطابق موفق است.
جمع‌بندی
  • search در هر جای متن می‌گردد.
  • match فقط از ابتدای متن.
  • اگر چیزی پیدا نشود، نتیجه None است.
