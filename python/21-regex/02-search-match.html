search و match در پایتون

هدف: بدانی search و match کجا را می‌گردند.

  • search در کل متن
  • match فقط از ابتدا
  • نتیجه None

search متن را می‌گردد. match فقط از ابتدای متن. اگر از اول جور نباشد، match حتی با وجود الگو در وسط متن None می‌دهد.

import re s = "abc123xyz" print(re.search(r"\d+", s)) print(re.match(r"\d+", s)) print(re.match(r"abc", s))
توضیح خط‌به‌خط
  1. خط 3searchرقم را در وسط پیدا می‌کند.
  2. خط 4match \d+چون با رقم شروع نشده، None.
  3. خط 5match abcاز اول متن جور است.
جمع‌بندی
  • search همه متن
  • match فقط ابتدا
  • None یعنی عدم تطابق
