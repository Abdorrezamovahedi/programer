کلاس کاراکتر و میانبرها

هدف درس: نوع نویسه‌ها را با کلاس کاراکتر و میانبر مشخص کنی.

  • [abc] یکی از حروف a یا b یا c
  • \d رقم
  • \w حرف/رقم/زیرخط
  • \s فاصله سفید

با [] مجموعه محدود تعریف می‌کنی. برای حالت‌های رایج از میانبر استفاده کن.

import re print(re.findall(r"[A-Z]", "AbCd")) print(re.findall(r"\d", "a1b2")) print(re.findall(r"\w+", "hi_1 ok"))
توضیح خط‌به‌خط
  1. خط 2[A-Z]حروف بزرگ انگلیسی.
  2. خط 3\dتک‌تک رقم‌ها.
  3. خط 4\w+دنباله‌های کلمه‌مانند مثل hi_1.
جمع‌بندی
  • [] مجموعه کاراکتر می‌سازد
  • \d رقم است
  • \w و \s میانبرهای پرکاربردند
