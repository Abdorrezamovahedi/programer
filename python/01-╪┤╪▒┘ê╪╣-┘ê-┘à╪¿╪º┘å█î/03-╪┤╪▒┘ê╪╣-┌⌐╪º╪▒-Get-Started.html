شروع کار با پایتون

هدف این درس: پایتون را آماده کنی و بتوانی اولین برنامه خیلی ساده را اجرا کنی.

مفهوم به زبان ساده

برای اینکه کامپیوتر دستورهای پایتون را بفهمد، باید «مفسر پایتون» را نصب کرده باشی. مفسر مثل مترجم است: کد تو را می‌خواند و اجرا می‌کند.

گام ۱: نصب پایتون

  1. به سایت رسمی python.org برو
  2. نسخه Python 3 را دانلود کن
  3. در ویندوز هنگام نصب، گزینه Add Python to PATH را فعال کن
  4. نصب را تمام کن

برای تست، در ترمینال یا Command Prompt بنویس:

python --version
اگر نسخه‌ای شبیه Python 3.x.x دیدی، نصب درست انجام شده است.

گام ۲: اولین برنامه

یک فایل متنی با پسوند .py بساز (مثلاً hello.py) و این کد را داخلش بنویس:

print("سلام، اولین برنامه‌ام!")
این یک خط کافی است تا پیام روی صفحه ظاهر شود.

گام ۳: اجرا

در ترمینال، به پوشه فایل برو و بنویس:

python hello.py
اگر پیام را دیدی، اولین برنامه‌ات با موفقیت اجرا شده است.

اشتباه رایج

مشکل: دستور python شناخته نمی‌شود.
علت رایج: گزینه Add to PATH هنگام نصب فعال نشده یا ترمینال را بعد از نصب باز نکرده‌ای.
راه‌حل: ترمینال را ببند و دوباره باز کن. اگر باز هم کار نکرد، پایتون را دوباره با فعال کردن PATH نصب کن.
معیار تمام‌شدن درس: بتوانی یک فایل .py بسازی، یک print ساده در آن بنویسی و نتیجه را در ترمینال ببینی.
جمع‌بندی
  • مفسر پایتون کد را اجرا می‌کند
  • فایل‌های پایتون پسوند .py دارند
  • با دستور python نام‌فایل.py برنامه را اجرا می‌کنی
  • اولین برنامه فقط یک print است

گام عملی

  1. پایتون را نصب کن و نسخه آن را چک کن.
  2. یک فایل بساز و پیام دلخواه خودت را با print چاپ کن.
