شرط کوتاه (Shorthand If)

هدف این درس: شکل یک‌خطی if/else را برای مقدار ساده بشناسی — نه برای منطق پیچیده.

پوشه: شرط و حلقه

مفهوم به زبان ساده

گاهی فقط می‌خواهی یک مقدار را بر اساس شرط انتخاب کنی. پایتون شکل کوتاهی دارد، ولی اگر منطق شلوغ شد همان if چندخطی خواناتر است.

ساختار

مقدار_اگر_درست if شرط else مقدار_اگر_نادرست

بالا فقط شکل کلی است؛ پایین مثال واقعی می‌بینی که اجرا می‌شود.

مثال 1: برچسب زوج/فرد

n = 7 label = "زوج" if n % 2 == 0 else "فرد" print(label)
خط ۱: عدد ۷.
خط ۲: اگر باقی‌مانده بر ۲ صفر بود «زوج»، وگرنه «فرد» در label می‌رود.
خط ۳: چاپ: فرد.

مثال 2: حداقل سن برای پیام

age = 20 msg = "بالغ" if age >= 18 else "نابالغ" print(msg)
خط ۲: انتخاب بین دو متن کوتاه با یک شرط.
خط ۳: چاپ: بالغ.

اشتباه رایج مبتدی‌ها

print("ok") if x > 0
چرا اشتباه است؟ شکل کوتاه وقتی else دارد کامل است؛ بدون else این فرم برای انتساب/عبارت محدود است.
چه می‌بینی؟ SyntaxError در بسیاری حالت‌ها
درست: یا else اضافه کن یا if معمولی چندخطی بنویس
معیار تمام‌شدن درس: یک برچسب متنی با شرط کوتاه بسازی و چاپ کنی.
جمع‌بندی
  • برای انتخاب یک مقدار ساده مناسب است
  • منطق شلوغ را با if معمولی بنویس

گام عملی — همین الان

  1. با شرط کوتاه بگو عدد مثبت است یا نه.

هر مثال را خودت تایپ کن و اجرا کن؛ فقط خواندن کافی نیست.
