حلقه while در پایتون

هدف این درس: بتوانی کاری را تا وقتی شرط برقرار است تکرار کنی.

count = 1 while count <= 5: print(count) count = count + 1
تا وقتی شرط True باشد، بلوک داخل while تکرار می‌شود. مراقب باش شرط بالاخره False شود تا حلقه بی‌نهایت نشود.
معیار تمام‌شدن درس: یک حلقه while ساده که چند عدد چاپ کند نوشته باشی.
جمع‌بندی

  • معمولاً داخل حلقه متغیر شرط را تغییر می‌دهیم
  • مراقب حلقه بی‌نهایت باش
