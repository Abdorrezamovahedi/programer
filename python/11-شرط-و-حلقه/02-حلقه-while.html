حلقه while

حلقه while در پایتون

هدف این درس: کاری را تا وقتی شرط برقرار است تکرار کنی.

count = 1 while count <= 5: print(count) count = count + 1
توضیح خط‌به‌خط همین مثال
  1. خط 1: count = 1 — شمارنده را از ۱ شروع می‌کند.
  2. خط 2: while count <= 5: — تا وقتی count حداکثر ۵ است تکرار کن.
  3. خط 3: print(count) — عدد فعلی را چاپ می‌کند.
  4. خط 4: count = count + 1 — شمارنده را یکی زیاد می‌کند تا حلقه تمام شود.
اگر شرط هیچ‌وقت غلط نشود، حلقه بی‌نهایت می‌شود.

یادگیری بیشتر

اگر جزئی از مثال را بلد نیستی، همان موضوع را باز کن:

  • متغیر شمارنده — رفتن به درس متغیرها
  • مقایسه <= — رفتن به درس عملگرهای مقایسه‌ای
  • افزایش با + — رفتن به درس عملگرهای حسابی
  • print — رفتن به درس خروجی
  • شرط if — رفتن به درس if
  • حلقه for — رفتن به درس for
