حلقه while

هدف: تا وقتی شرط برقرار است کار را تکرار کنی.

count = 1 while count <= 5: print(count) count = count + 1

یادگیری بیشتر

روی هر دکمه کلیک کن تا همان درس باز شود:

  • متغیر شمارنده count — رفتن به درس متغیرها
  • مقایسه <= — رفتن به درس عملگرهای مقایسه‌ای
  • افزایش با + — رفتن به درس عملگرهای حسابی
  • چاپ با print — رفتن به درس خروجی
  • شرط if — رفتن به درس if
  • حلقه for — رفتن به درس for
