حلقه while

خانه/Python/شرط و حلقه/while

شرط و حلقه

1. if elif else 2. حلقه while 3. حلقه for

هدف درس

در پایان این درس می‌توانی با while کاری را تا وقتی شرط برقرار است تکرار کنی و با افزایش شمارنده از حلقه بی‌نهایت جلوگیری کنی.

پیش‌نیازها

  • متغیرها
  • شرط if
  • خروجی با print

کاربرد واقعی

وقتی نمی‌دانی از قبل چند بار باید تکرار شود — مثلاً خواندن ورودی تا وقتی کاربر «خروج» بزند، یا شمارش تا رسیدن به یک حد.

count = 1 while count <= 5: print(count) count = count + 1
توضیح خط‌به‌خط همین مثال
  1. خط 1: count = 1 — شمارنده را از ۱ شروع می‌کند.
  2. خط 2: while count <= 5: — تا وقتی count حداکثر ۵ است تکرار کن.
  3. خط 3: print(count) — عدد فعلی را چاپ می‌کند.
  4. خط 4: count = count + 1 — شمارنده را یکی زیاد می‌کند تا حلقه تمام شود.
خطای رایج: اگر count را زیاد نکنی، شرط همیشه درست می‌ماند و حلقه بی‌نهایت می‌شود.
جمع‌بندی
  • while تا وقتی شرط درست است تکرار می‌کند
  • باید چیزی داخل حلقه تغییر کند تا شرط روزی غلط شود
  • برای تعداد مشخص تکرار، اغلب for ساده‌تر است

گام عملی

  1. اعداد ۱ تا ۳ را با while چاپ کن.
  2. عمداً count را حذف کن و ببین چه می‌شود، بعد اصلاح کن.
