شرط تو در تو (Nested If)

هدف این درس: یک if داخل if دیگر بگذاری وقتی تصمیم دو لایه دارد.

پوشه: شرط و حلقه

مفهوم به زبان ساده

تو در تو یعنی بعد از برقرار بودن شرط اول، یک شرط دوم هم چک می‌شود. زیاد تودرتو کردن خواندن را سخت می‌کند؛ وقتی می‌توانی با and ساده کن، ساده کن.

ساختار

if شرط1: if شرط2: ... else: ... else: ...

بالا فقط شکل کلی است؛ پایین مثال واقعی می‌بینی که اجرا می‌شود.

مثال 1: ورود به بخش ویژه

age = 20 has_ticket = True if age >= 18: if has_ticket: print("ورود به بخش ویژه") else: print("بلیط لازم است") else: print("سن کافی نیست")
توضیح خط‌به‌خط همین مثال
  1. خط 1: age = 20 — یک مقدار را داخل «age» ذخیره می‌کند.
  2. خط 2: has_ticket = True — یک مقدار را داخل «has_ticket» ذخیره می‌کند.
  3. خط 3: if age >= 18: — شرط را بررسی می‌کند؛ اگر درست باشد وارد این بخش می‌شود.
  4. خط 4: if has_ticket: — شرط را بررسی می‌کند؛ اگر درست باشد وارد این بخش می‌شود.
  5. خط 5: print("ورود به بخش ویژه") — مقدار یا متن داخل print را در خروجی نشان می‌دهد.
  6. خط 6: else: — اگر هیچ‌کدام از شرط‌های قبلی برقرار نبود، این بخش اجرا می‌شود.
  7. خط 7: print("بلیط لازم است") — مقدار یا متن داخل print را در خروجی نشان می‌دهد.
  8. خط 8: else: — اگر هیچ‌کدام از شرط‌های قبلی برقرار نبود، این بخش اجرا می‌شود.
  9. خط 9: print("سن کافی نیست") — مقدار یا متن داخل print را در خروجی نشان می‌دهد.
خط ۳: اول سن چک می‌شود.
خط ۴–۵: اگر سن کافی بود، تازه بلیط چک می‌شود.
خط ۶–۷: سن کافی است ولی بلیط نیست.
خط ۸–۹: اگر سن کافی نباشد، اصلاً سراغ بلیط نمی‌رویم.

مثال 2: همان منطق با and (خواناتر)

age = 20 has_ticket = True if age >= 18 and has_ticket: print("ورود به بخش ویژه") elif age >= 18: print("بلیط لازم است") else: print("سن کافی نیست")
توضیح خط‌به‌خط همین مثال
  1. خط 1: age = 20 — یک مقدار را داخل «age» ذخیره می‌کند.
  2. خط 2: has_ticket = True — یک مقدار را داخل «has_ticket» ذخیره می‌کند.
  3. خط 3: if age >= 18 and has_ticket: — شرط را بررسی می‌کند؛ اگر درست باشد وارد این بخش می‌شود.
  4. خط 4: print("ورود به بخش ویژه") — مقدار یا متن داخل print را در خروجی نشان می‌دهد.
  5. خط 5: elif age >= 18: — اگر شرط قبلی برقرار نبود، این شرط را چک می‌کند.
  6. خط 6: print("بلیط لازم است") — مقدار یا متن داخل print را در خروجی نشان می‌دهد.
  7. خط 7: else: — اگر هیچ‌کدام از شرط‌های قبلی برقرار نبود، این بخش اجرا می‌شود.
  8. خط 8: print("سن کافی نیست") — مقدار یا متن داخل print را در خروجی نشان می‌دهد.
خط ۳: هر دو شرط با هم برای ورود کامل.
خط ۵–۶: سن کافی است ولی بلیط نه.
این مثال: گاهی می‌توانی بدون تو در تو، همان حرف را روشن‌تر بزنی.

اشتباه رایج مبتدی‌ها

if age >= 18: if has_ticket: print("ok")
توضیح خط‌به‌خط همین مثال
  1. خط 1: if age >= 18: — شرط را بررسی می‌کند؛ اگر درست باشد وارد این بخش می‌شود.
  2. خط 2: if has_ticket: — شرط را بررسی می‌کند؛ اگر درست باشد وارد این بخش می‌شود.
  3. خط 3: print("ok") — مقدار یا متن داخل print را در خروجی نشان می‌دهد.
چرا اشتباه است؟ if دوم باید داخل if اول تورفتگی داشته باشد.
چه می‌بینی؟ منطق/Syntax غلط
درست: زیر if اول، با تورفتگی if دوم را بنویس
معیار تمام‌شدن درس: یک مثال تو در تو بنویسی و بعد اگر ممکن است همان را با and ساده‌تر کنی.
جمع‌بندی
  • تو در تو برای تصمیم لایه‌ای
  • تورفتگی معنا دارد
  • اگر می‌شود ساده کن

  1. وضعیت آب‌وهوا و داشتن چتر را با تو در تو مدل کن.
