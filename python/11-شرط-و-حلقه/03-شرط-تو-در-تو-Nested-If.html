شرط تو در تو (Nested If)

هدف این درس: یک if داخل if دیگر بگذاری وقتی تصمیم دو لایه دارد.

پوشه: شرط و حلقه

مفهوم به زبان ساده

تو در تو یعنی بعد از برقرار بودن شرط اول، یک شرط دوم هم چک می‌شود. زیاد تودرتو کردن خواندن را سخت می‌کند؛ وقتی می‌توانی با and ساده کن، ساده کن.

ساختار

if شرط1: if شرط2: ... else: ... else: ...

بالا فقط شکل کلی است؛ پایین مثال واقعی می‌بینی که اجرا می‌شود.

مثال 1: ورود به بخش ویژه

age = 20 has_ticket = True if age >= 18: if has_ticket: print("ورود به بخش ویژه") else: print("بلیط لازم است") else: print("سن کافی نیست")
خط ۳: اول سن چک می‌شود.
خط ۴–۵: اگر سن کافی بود، تازه بلیط چک می‌شود.
خط ۶–۷: سن کافی است ولی بلیط نیست.
خط ۸–۹: اگر سن کافی نباشد، اصلاً سراغ بلیط نمی‌رویم.

مثال 2: همان منطق با and (خواناتر)

age = 20 has_ticket = True if age >= 18 and has_ticket: print("ورود به بخش ویژه") elif age >= 18: print("بلیط لازم است") else: print("سن کافی نیست")
خط ۳: هر دو شرط با هم برای ورود کامل.
خط ۵–۶: سن کافی است ولی بلیط نه.
این مثال: گاهی می‌توانی بدون تو در تو، همان حرف را روشن‌تر بزنی.

اشتباه رایج مبتدی‌ها

if age >= 18: if has_ticket: print("ok")
چرا اشتباه است؟ if دوم باید داخل if اول تورفتگی داشته باشد.
چه می‌بینی؟ منطق/Syntax غلط
درست: زیر if اول، با تورفتگی if دوم را بنویس
معیار تمام‌شدن درس: یک مثال تو در تو بنویسی و بعد اگر ممکن است همان را با and ساده‌تر کنی.
جمع‌بندی
  • تو در تو برای تصمیم لایه‌ای
  • تورفتگی معنا دارد
  • اگر می‌شود ساده کن

گام عملی — همین الان

  1. وضعیت آب‌وهوا و داشتن چتر را با تو در تو مدل کن.

هر مثال را خودت تایپ کن و اجرا کن؛ فقط خواندن کافی نیست.
