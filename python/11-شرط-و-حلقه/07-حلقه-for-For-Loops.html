حلقه for (For Loops)

هدف: با for یا while کار را تکرار کنی بدون کپی کردن کد.

پوشه: شرط و حلقه  |  پیش‌نیاز: درس‌های قبلی «شرط و حلقه».
ارتباط با قبل: این مبحث در پوشهٔ «شرط و حلقه» بعد از مفاهیم قبلی همان موضوع می‌آید؛ قبل از پرش به درس بعدی، مثال را خودت یک‌بار تایپ کن.

مفهوم

for روی اعضای یک دنباله (مثل range) می‌چرخد. while تا وقتی شرط True است تکرار می‌کند؛ باید چیزی را عوض کنی وگرنه بی‌نهایت می‌شود.

ساختار

for i in range(n): ... while cond: ...

مثال 1: for و range

for i in range(1, 4): print(i, i * i)
خط ۱: i برابر ۱، سپس ۲، سپس ۳ (۴ نه).
خط ۲: عدد و مربعش.

مثال 2: while با پیشروی

n = 3 while n > 0: print(n) n = n - 1
خط ۲: تا n مثبت است ادامه بده.
خط ۴: حتماً کم کن تا حلقه تمام شود.

اشتباه رایج

n = 5 while n > 0: print(n)
چرا اشتباه است؟ n کم نمی‌شود؛ شرط همیشه True می‌ماند.
چه می‌بینی؟ حلقهٔ بی‌نهایت
درست: داخل حلقه n = n - 1 بگذار.
معیار تمام‌شدن: بتوانی بدون نگاه به متن، یک مثال سه‌خطی دربارهٔ «حلقه for» بنویسی و اجرا کنی.
جمع‌بندی
  • for برای دنبالهٔ مشخص.
  • while وقتی پایان از قبل معلوم نیست.
  • range پایان را شامل نمی‌شود.
  • while باید به سمت False برود.

گام عملی

  1. ۱ تا ۵ را با for چاپ کن.
  2. شمارش معکوس با while.
  3. عمداً while بی‌نهایت بساز (و با Ctrl+C قطع کن).

اگر گیر کردی: فقط همان خط خطا را با بخش «اشتباه رایج» و توضیح خط‌به‌خط مقایسه کن؛ کل درس را از صفر حفظ نکن.
