خانهتمرین

if elif else

هدف: با شرط بین چند مسیر یکی را انتخاب کنی.

age = 18 if age >= 18: print("بالغ هستی") elif age >= 13: print("نوجوان هستی") else: print("کودک هستی")
توضیح خط‌به‌خط
  1. خط 1age = 18متغیر سن.
  2. خط 2if age >= 18شرط اصلی.
  3. خط 4elifشرط بعدی.
  4. خط 6elseحالت باقی‌مانده.

یادگیری بیشتر

روی هر مورد کلیک کن تا همان درس باز شود:

  • متغیر age — رفتن به درس متغیرها
  • عدد و نوع داده — رفتن به درس انواع داده
  • عملگر مقایسه >= — رفتن به درس عملگرهای مقایسه‌ای
  • چاپ با print — رفتن به درس خروجی
  • رشته متنی داخل print — رفتن به درس رشته‌ها
  • ادامه مسیر یادگیری — رفتن به درس while
