1. if elif else

شرط if در پایتون

هدف این درس: بتوانی با if بین چند مسیر یکی را انتخاب کنی.

age = 18 if age >= 18: print("بالغ هستی") elif age >= 13: print("نوجوان هستی") else: print("کودک هستی")
توضیح خط‌به‌خط همین مثال
  1. خط 1: age = 18 — یک مقدار را داخل «age» ذخیره می‌کند.
  2. خط 2: if age >= 18: — شرط را بررسی می‌کند؛ اگر درست باشد وارد این بخش می‌شود.
  3. خط 3: print("بالغ هستی") — مقدار یا متن داخل print را در خروجی نشان می‌دهد.
  4. خط 4: elif age >= 13: — اگر شرط قبلی برقرار نبود، این شرط را چک می‌کند.
  5. خط 5: print("نوجوان هستی") — مقدار یا متن داخل print را در خروجی نشان می‌دهد.
  6. خط 6: else: — اگر هیچ‌کدام از شرط‌های قبلی برقرار نبود، این بخش اجرا می‌شود.
  7. خط 7: print("کودک هستی") — مقدار یا متن داخل print را در خروجی نشان می‌دهد.
تورفتگی بعد از : بسیار مهم است. شرط درست باشد، بلوک داخل if اجرا می‌شود.
معیار تمام‌شدن درس: یک شرط ساده با if و else نوشته باشی.
جمع‌بندی
  • if برای شرط اصلی
  • elif برای شرط‌های بعدی
  • else برای حالت باقی‌مانده
