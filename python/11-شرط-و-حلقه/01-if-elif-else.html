شرط if در پایتون

هدف این درس: بتوانی با if بین چند مسیر یکی را انتخاب کنی.

age = 18 if age >= 18: print("بالغ هستی") elif age >= 13: print("نوجوان هستی") else: print("کودک هستی")
توضیح خط‌به‌خط همین مثال
  1. خط 1: age = 18 — مقدار سن را در متغیر age می‌گذارد.
  2. خط 2: if age >= 18: — شرط را بررسی می‌کند.
  3. خط 3: print("بالغ هستی") — اگر شرط درست باشد این پیام چاپ می‌شود.
  4. خط 4: elif age >= 13: — اگر شرط قبلی نه، این را چک می‌کند.
  5. خط 6: else: — اگر هیچ‌کدام نبود، این بخش اجرا می‌شود.
تورفتگی بعد از : بسیار مهم است. شرط درست باشد، بلوک داخل if اجرا می‌شود.
معیار تمام‌شدن درس: یک شرط ساده با if و else نوشته باشی.
جمع‌بندی
  • if برای شرط اصلی
  • elif برای شرط‌های بعدی
  • else برای حالت باقی‌مانده
