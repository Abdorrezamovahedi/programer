شرط if / elif / else

هدف: بر اساس یک شرط، مسیر اجرای برنامه را عوض کنی.

score = 17 if score >= 18: print("عالی") elif score >= 10: print("قبول") else: print("نیاز به تلاش بیشتر")
توضیح خط‌به‌خط
  1. خط 1score = 17نمره نمونه.
  2. خط 2if score >= 18اگر نمره ۱۸ یا بیشتر.
  3. خط 4elif score >= 10وگرنه اگر حداقل ۱۰.
  4. خط 6elseدر غیر این صورت.
