if / elif / else

هدف این درس: با if و elif و else یک تصمیم واقعی در برنامه بگیری.

پوشه: شرط و حلقه  |  شروع این مبحث — از همین درس شروع کن

مفهوم به زبان ساده

شرط یعنی برنامه بر اساس وضعیت، یکی از چند مسیر را برود. if اولین شرط است. اگر برقرار نبود، elif شرط بعدی را چک می‌کند. else وقتی است که هیچ‌کدام برقرار نباشد.

ساختار

if شرط: دستورها elif شرط_دیگر: دستورها else: دستورها

بالا فقط شکل کلی است؛ پایین مثال واقعی می‌بینی که اجرا می‌شود.

مثال 1: نمره و پیام

score = 17 if score >= 18: print("عالی") elif score >= 15: print("خوب") elif score >= 10: print("قابل قبول") else: print("نیاز به تلاش بیشتر")
خط ۱: نمره ۱۷ در متغیر score.
خط ۲–۳: آیا نمره حداقل ۱۸ است؟ اینجا نه؛ وارد این شاخه نمی‌شود.
خط ۴–۵: آیا حداقل ۱۵ است؟ بله — «خوب» چاپ می‌شود و بقیه چک نمی‌شوند.
خط ۶–۹: این شاخه‌ها فقط وقتی اجرا می‌شوند که شرط‌های بالاتر برقرار نباشند.

مثال 2: ورود با سن

age = 16 if age >= 18: print("ورود مجاز") else: print("ورود فقط با همراه")
خط ۱: سن ۱۶.
خط ۲–۳: شرط برقرار نیست؛ این print اجرا نمی‌شود.
خط ۴–۵: else اجرا می‌شود و پیام مناسب چاپ می‌شود.

اشتباه رایج مبتدی‌ها

if age >= 18 print("ok")
چرا اشتباه است؟ بعد از شرط باید : بیاید.
چه می‌بینی؟ SyntaxError
درست: if age >= 18:
معیار تمام‌شدن درس: یک برنامه با حداقل یک if، یک elif و یک else بنویسی و با دو مقدار مختلف نتیجهٔ متفاوت ببینی.
جمع‌بندی
  • if اولین شرط
  • elif شرط‌های بعدی
  • else مسیر باقی‌مانده
  • تورفتگی زیر if اجباری است

گام عملی — همین الان

  1. نمره را ۱۰ و ۱۹ بگذار و هر دو را اجرا کن.
  2. عمداً : را بردار و پیام خطا را بخوان.

هر مثال را خودت تایپ کن و اجرا کن؛ فقط خواندن کافی نیست.
