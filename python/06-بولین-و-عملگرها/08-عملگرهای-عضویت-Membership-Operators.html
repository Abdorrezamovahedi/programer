توضیح دانه‌به‌دانه با مثال

1. in / not in

آیا مقدار داخل یک مجموعه/رشته/فهرست هست؟ (عضویت)

print("a" in "abc") # True print(2 in [1, 2, 3]) # True

مرور سریع مثال 1

print("a" in "abc") # True print(2 in [1, 2, 3]) # True
