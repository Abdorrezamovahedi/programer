عملگرهای مقایسه ای (Comparison Operators)

هدف این درس: شش مقایسه را با خروجی True/False بشناسی.

پوشه: بولین و عملگرها  |  نقش: درس معرفی مبحث

مفهوم به زبان ساده

مقایسه سؤال می‌پرسد و جواب بله/خیر (True/False) می‌دهد. بعداً در if از همین‌ها استفاده می‌کنی.

فهرست معرفی: عملگرهای مقایسه

همهٔ موارد این مبحث را یک‌جا در کد ببین. هر خط با کامنت توضیح داده شده است.

# عملگرهای مقایسه — نتیجه همیشه True یا False است print(3 == 3) # == برابر است؟ → True print(3 != 4) # != نابرابر است؟ → True print(5 > 2) # > بزرگ‌تر؟ → True print(5 < 2) # < کوچک‌تر؟ → False print(5 >= 5) # >= بزرگ‌تر یا مساوی؟ → True print(3 <= 2) # <= کوچک‌تر یا مساوی؟ → False
توضیح خط‌به‌خط همین مثال
  1. خط 1: # عملگرهای مقایسه — نتیجه همیشه True یا False است — این خط توضیح (کامنت) است و اجرا نمی‌شود.
  2. خط 2: print(3 == 3) # == برابر است؟ → True — مقدار یا متن داخل print را در خروجی نشان می‌دهد.
  3. خط 3: print(3 != 4) # != نابرابر است؟ → True — مقدار یا متن داخل print را در خروجی نشان می‌دهد.
  4. خط 4: print(5 > 2) # > بزرگ‌تر؟ → True — مقدار یا متن داخل print را در خروجی نشان می‌دهد.
  5. خط 5: print(5 < 2) # < کوچک‌تر؟ → False — مقدار یا متن داخل print را در خروجی نشان می‌دهد.
  6. خط 6: print(5 >= 5) # >= بزرگ‌تر یا مساوی؟ → True — مقدار یا متن داخل print را در خروجی نشان می‌دهد.
  7. خط 7: print(3 <= 2) # <= کوچک‌تر یا مساوی؟ → False — مقدار یا متن داخل print را در خروجی نشان می‌دهد.
== نه =: یک مساوی برای ذخیره است؛ دو مساوی برای مقایسه.

مثال 1: مقایسه دو متغیر

a = 7 b = 10 print(a == b) print(a < b) print(a >= 7)
توضیح خط‌به‌خط همین مثال
  1. خط 1: a = 7 — یک مقدار را داخل «a» ذخیره می‌کند.
  2. خط 2: b = 10 — یک مقدار را داخل «b» ذخیره می‌کند.
  3. خط 3: print(a == b) — مقدار یا متن داخل print را در خروجی نشان می‌دهد.
  4. خط 4: print(a < b) — مقدار یا متن داخل print را در خروجی نشان می‌دهد.
  5. خط 5: print(a >= 7) — مقدار یا متن داخل print را در خروجی نشان می‌دهد.
خط ۱–۲: دو عدد در متغیر.
خط ۳: آیا برابرند؟ False.
خط ۴: آیا a کوچک‌تر است؟ True.
خط ۵: آیا a حداقل ۷ است؟ True.

اشتباه رایج مبتدی‌ها

if x = 5:
توضیح خط‌به‌خط همین مثال
  1. خط 1: if x = 5: — شرط را بررسی می‌کند؛ اگر درست باشد وارد این بخش می‌شود.
چرا اشتباه است؟ یک = انتساب است نه مقایسه.
چه می‌بینی؟ SyntaxError یا منطق غلط
درست: if x == 5:
معیار تمام‌شدن درس: هر شش عملگر را یک‌بار با عدد دلخواه اجرا کنی.
جمع‌بندی
  • نتیجه bool است
  • == مقایسه است
  • = ذخیره است
