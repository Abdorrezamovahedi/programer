عملگرها (Operators)

هدف این درس: خانواده‌های عملگر را بشناسی و بدانی درس بعدی کدام جزئیات را می‌دهد.

پوشه: بولین و عملگرها  |  نقش: درس معرفی مبحث

مفهوم به زبان ساده

عملگر نماد کار روی مقدارهاست. اینجا فقط نقشه است؛ جزئیات حسابی، مقایسه‌ای و منطقی در درس‌های بعدی همین پوشه با فهرست کامل می‌آید.

فهرست معرفی: خانواده‌های عملگر

همهٔ موارد این مبحث را یک‌جا در کد ببین. هر خط با کامنت توضیح داده شده است.

# نقشهٔ خانواده‌های عملگر در پایتون # حسابی: + - * / // % ** # انتساب: = += -= *= /= ... # مقایسه: == != > < >= <= # منطقی: and or not # عضویت: in not in # هویت: is is not print(2 + 3) # نمونه حسابی print(3 == 3) # نمونه مقایسه print(True and True) # نمونه منطقی
مسیر: اول عملگرهای حسابی را کامل بخوان، بعد مقایسه و منطقی.

مثال 1: سه خانواده در یک نگاه

print(10 % 3) print(10 > 3) print(10 > 3 and 10 > 20)
خط ۱: حسابی % → باقی‌مانده ۱.
خط ۲: مقایسه → True.
خط ۳: منطقی and → False چون شرط دوم غلط است.

اشتباه رایج مبتدی‌ها

print(3 = 3)
چرا اشتباه است؟ = انتساب است.
چه می‌بینی؟ SyntaxError
درست: print(3 == 3)
معیار تمام‌شدن درس: بتوانی بگویی + و == و and هر کدام از کدام خانواده‌اند.
جمع‌بندی
  • چند خانواده عملگر داریم
  • جزئیات در درس‌های بعدی پوشه
  • == برای مقایسه
