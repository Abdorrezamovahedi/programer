عملگرهای منطقی (Logical Operators)

هدف این درس: and و or و not را با مثال True/False بفهمی.

پوشه: بولین و عملگرها  |  نقش: درس معرفی مبحث

مفهوم به زبان ساده

گاهی چند شرط را با هم لازم داری. and سخت‌گیر است؛ or آسان‌گیر؛ not برعکس می‌کند.

فهرست معرفی: عملگرهای منطقی

همهٔ موارد این مبحث را یک‌جا در کد ببین. هر خط با کامنت توضیح داده شده است.

# عملگرهای منطقی — ترکیب شرط‌ها print(True and False) # and: هر دو باید True باشند → False print(True or False) # or: حداقل یکی True → True print(not True) # not: برعکس → False print(5 > 2 and 5 > 10) # مثال ترکیبی → False
توضیح خط‌به‌خط همین مثال
  1. خط 1: # عملگرهای منطقی — ترکیب شرط‌ها — این خط توضیح (کامنت) است و اجرا نمی‌شود.
  2. خط 2: print(True and False) # and: هر دو باید True باشند → False — مقدار یا متن داخل print را در خروجی نشان می‌دهد.
  3. خط 3: print(True or False) # or: حداقل یکی True → True — مقدار یا متن داخل print را در خروجی نشان می‌دهد.
  4. خط 4: print(not True) # not: برعکس → False — مقدار یا متن داخل print را در خروجی نشان می‌دهد.
  5. خط 5: print(5 > 2 and 5 > 10) # مثال ترکیبی → False — مقدار یا متن داخل print را در خروجی نشان می‌دهد.
and: اگر یکی False باشد کل عبارت False است.
or: اگر یکی True باشد کل عبارت True است.

مثال 1: ورود با دو شرط

age = 20 has_id = True print(age >= 18 and has_id) print(age < 12 or age > 65)
توضیح خط‌به‌خط همین مثال
  1. خط 1: age = 20 — یک مقدار را داخل «age» ذخیره می‌کند.
  2. خط 2: has_id = True — یک مقدار را داخل «has_id» ذخیره می‌کند.
  3. خط 3: print(age >= 18 and has_id) — مقدار یا متن داخل print را در خروجی نشان می‌دهد.
  4. خط 4: print(age < 12 or age > 65) — مقدار یا متن داخل print را در خروجی نشان می‌دهد.
خط ۱: سن ۲۰.
خط ۲: کارت دارد True.
خط ۳: هر دو شرط ورود؛ نتیجه True.
خط ۴: کودک یا سالمند؟ False.

اشتباه رایج مبتدی‌ها

print(not age >= 18 and has_id) # بدون پرانتز با عجله
توضیح خط‌به‌خط همین مثال
  1. خط 1: print(not age >= 18 and has_id) # بدون پرانتز با عجله — مقدار یا متن داخل print را در خروجی نشان می‌دهد.
چرا اشتباه است؟ اولویت not ممکن است خلاف قصدت باشد.
چه می‌بینی؟ منطق غیرمنتظره
درست: با () واضح بنویس: not (age >= 18 and has_id)
معیار تمام‌شدن درس: یک عبارت and و یک or خودت بنویسی و نتیجه را درست حدس بزنی.
جمع‌بندی
  • and سخت‌گیر
  • or آسان‌گیر
  • not برعکس
  • پرانتز برای وضوح

گام عملی — همین الان

  1. شرط «نمره بالای ۱۰ و زیر ۲۰» را با and بنویس.
