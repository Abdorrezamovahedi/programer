عملگرهای حسابی (Arithmetic Operators)

هدف این درس: هفت عملگر حسابی را یکی‌یکی با خروجی بشناسی.

پوشه: بولین و عملگرها  |  نقش: درس معرفی مبحث

مفهوم به زبان ساده

عملگر حسابی روی عدد کار می‌کند و نتیجه می‌سازد. در باکس زیر همه کنار هم با کامنت آمده‌اند. بعد یک مثال ترکیبی را خط‌به‌خط می‌بینی.

فهرست معرفی: عملگرهای حسابی

همهٔ موارد این مبحث را یک‌جا در کد ببین. هر خط با کامنت توضیح داده شده است.

# عملگرهای حسابی — هر خط یک عمل print(3 + 2) # + جمع → 5 print(10 - 4) # - تفریق → 6 print(3 * 4) # * ضرب → 12 print(7 / 2) # / تقسیم اعشاری → 3.5 print(7 // 2) # // تقسیم صحیح → 3 print(7 % 2) # % باقی‌مانده → 1 print(2 ** 3) # ** توان (۲×۲×۲) → 8
/ و //: اسلش تنها اعشاری می‌دهد؛ دو اسلش قسمت صحیح را نگه می‌دارد.
%: باقی‌مانده برای زوج/فرد و دوره‌ها خیلی به کار می‌آید.

مثال 1: یک عبارت ترکیبی

a = 7 b = 2 print(a + b) print(a / b) print(a // b) print(a % b)
خط ۱: a برابر ۷.
خط ۲: b برابر ۲.
خط ۳: جمع → ۹.
خط ۴: تقسیم اعشاری → ۳.۵.
خط ۵: تقسیم صحیح → ۳.
خط ۶: باقی‌مانده → ۱.

اشتباه رایج مبتدی‌ها

print(7 / 0)
چرا اشتباه است؟ تقسیم بر صفر تعریف نشده.
چه می‌بینی؟ ZeroDivisionError
درست: مقسوم‌علیه غیرصفر بگذار
معیار تمام‌شدن درس: هر هفت عملگر را یک‌بار اجرا کنی و نتیجه را از حفظ بگویی.
جمع‌بندی
  • + - * حساب آشنا
  • / اعشاری و // صحیح
  • % باقی‌مانده
  • ** توان

گام عملی — همین الان

  1. ۲ ** ۵ را حساب کن.
  2. با % بگو ۱۰ زوج است یا فرد.
