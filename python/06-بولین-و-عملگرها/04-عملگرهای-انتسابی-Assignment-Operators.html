عملگرهای انتسابی (Assignment Operators)

هدف این درس: انتساب ساده و ترکیبی (+= و بقیه) را با کامنت و مثال بفهمی.

پوشه: بولین و عملگرها  |  نقش: درس معرفی مبحث

مفهوم به زبان ساده

= فقط ذخیره می‌کند. += و مشابهاتش «حساب کن و دوباره در همان متغیر بریز».

فهرست معرفی: عملگرهای انتساب

همهٔ موارد این مبحث را یک‌جا در کد ببین. هر خط با کامنت توضیح داده شده است.

# عملگرهای انتساب — کوتاه‌نویسی تغییر متغیر x = 5 # = مقدار ۵ را در x بگذار x += 3 # += همان x = x + 3 → 8 x -= 2 # -= همان x = x - 2 x *= 2 # *= همان x = x * 2 x /= 2 # /= همان x = x / 2 x //= 2 # //= تقسیم صحیح و ذخیره x %= 3 # %= باقی‌مانده و ذخیره x **= 2 # **= توان و ذخیره
توضیح خط‌به‌خط همین مثال
  1. خط 1: # عملگرهای انتساب — کوتاه‌نویسی تغییر متغیر — این خط توضیح (کامنت) است و اجرا نمی‌شود.
  2. خط 2: x = 5 # = مقدار ۵ را در x بگذار — یک مقدار را داخل «x» ذخیره می‌کند.
  3. خط 3: x += 3 # += همان x = x + 3 → 8 — این خط بخشی از منطق مثال را انجام می‌دهد.
  4. خط 4: x -= 2 # -= همان x = x - 2 — این خط بخشی از منطق مثال را انجام می‌دهد.
  5. خط 5: x *= 2 # *= همان x = x * 2 — این خط بخشی از منطق مثال را انجام می‌دهد.
  6. خط 6: x /= 2 # /= همان x = x / 2 — این خط بخشی از منطق مثال را انجام می‌دهد.
  7. خط 7: x //= 2 # //= تقسیم صحیح و ذخیره — این خط بخشی از منطق مثال را انجام می‌دهد.
  8. خط 8: x %= 3 # %= باقی‌مانده و ذخیره — این خط بخشی از منطق مثال را انجام می‌دهد.
  9. خط 9: x **= 2 # **= توان و ذخیره — این خط بخشی از منطق مثال را انجام می‌دهد.
ترتیب: سمت راست اول حساب می‌شود، بعد در چپ ذخیره می‌شود.

مثال 1: امتیاز با +=

score = 10 score += 5 print(score) score *= 2 print(score)
توضیح خط‌به‌خط همین مثال
  1. خط 1: score = 10 — یک مقدار را داخل «score» ذخیره می‌کند.
  2. خط 2: score += 5 — این خط بخشی از منطق مثال را انجام می‌دهد.
  3. خط 3: print(score) — مقدار یا متن داخل print را در خروجی نشان می‌دهد.
  4. خط 4: score *= 2 — این خط بخشی از منطق مثال را انجام می‌دهد.
  5. خط 5: print(score) — مقدار یا متن داخل print را در خروجی نشان می‌دهد.
خط ۱: شروع از ۱۰.
خط ۲: ۵ تا اضافه → ۱۵.
خط ۳: چاپ ۱۵.
خط ۴: دو برابر → ۳۰.
خط ۵: چاپ ۳۰.

اشتباه رایج مبتدی‌ها

+= 1
توضیح خط‌به‌خط همین مثال
  1. خط 1: += 1 — این خط بخشی از منطق مثال را انجام می‌دهد.
چرا اشتباه است؟ سمت چپ (نام متغیر) لازم است.
چه می‌بینی؟ SyntaxError
درست: x += 1
معیار تمام‌شدن درس: با += و *= یک شمارنده را دو مرحله عوض کنی.
جمع‌بندی
  • = ذخیره
  • += اضافه و ذخیره
  • همهٔ ترکیبی‌ها شکل کوتاه x = x ? n هستند

گام عملی — همین الان

  1. از ۰ با سه بار += ۱ به ۳ برس.
