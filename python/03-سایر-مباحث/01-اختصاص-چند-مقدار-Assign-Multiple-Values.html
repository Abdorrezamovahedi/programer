اختصاص چند مقدار (Assign Multiple Values)

هدف: چند متغیر را یک‌جا مقدار بدهی و بفهمی تعداد دو طرف باید یکی باشد.

پوشه: سایر مباحث  |  پیش‌نیاز: اولین درس این پوشه.
ارتباط با قبل: این مبحث در پوشهٔ «سایر مباحث» بعد از مفاهیم قبلی همان موضوع می‌آید؛ قبل از پرش به درس بعدی، مثال را خودت یک‌بار تایپ کن.

مفهوم

در پایتون می‌توانی چند نام را با چند مقدار در یک خط مقداردهی کنی. تعداد نام‌ها و مقدارها باید برابر باشد؛ وگرنه ValueError می‌گیری. این کار برای باز کردن تاپل/لیست هم استفاده می‌شود.

ساختار

a, b, c = 1, 2, 3 x = y = 0

مثال 1: انتساب موازی

a, b, c = 10, 20, 30 print(a) print(b) print(c)
خط ۱: سه نام، سه مقدار؛ به ترتیب جفت می‌شوند.
خط ۲–۴: هر متغیر جدا چاپ می‌شود تا ترتیب را ببینی.

مثال 2: یک مقدار برای چند نام و جابه‌جایی

x = y = 0 print(x, y) m, n = 1, 2 m, n = n, m print(m, n)
خط ۱: هر دو صفر می‌شوند.
خط ۳: m=1 و n=2.
خط ۴: جابه‌جایی بدون متغیر کمکی: سمت راست اول محاسبه می‌شود.
خط ۵: حالا m=2 و n=1.

اشتباه رایج

a, b = 1, 2, 3
چرا اشتباه است؟ دو نام و سه مقدار؛ پایتون نمی‌داند مال کدام است.
چه می‌بینی؟ ValueError: too many values to unpack
درست: a, b, c = 1, 2, 3 یا a, b = 1, 2
معیار تمام‌شدن: بتوانی بدون نگاه به متن، یک مثال سه‌خطی دربارهٔ «اختصاص چند مقدار» بنویسی و اجرا کنی.
جمع‌بندی
  • تعداد نام و مقدار باید یکی باشد.
  • x = y = 0 همه را یک مقدار می‌دهد.
  • جابه‌جایی با a, b = b, a ممکن است.
  • ValueError یعنی تعداد جفت‌ها جور نیست.

گام عملی

  1. نام و سن را با یک خط انتساب بگیر و چاپ کن.
  2. دو متغیر را جابه‌جا کن و قبل/بعد را چاپ کن.
  3. عمداً تعداد را اشتباه بگذار و ValueError را ببین.
