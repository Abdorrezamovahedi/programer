لانبدا (Lambda)

هدف: با lambda یک تابع یک‌خطی کوتاه برای map/sorted بنویسی و بدانی جایگزین def کامل نیست.

پوشه: توابع  |  پیش‌نیاز: درس‌های قبلی «توابع».
ارتباط با قبل: همان تابع که با def نوشتی؛ اینجا فقط برای کار کوتاه درجا.

مفهوم

lambda آرگومان می‌گیرد و یک عبارت برمی‌گرداند. برای توابع خیلی کوچک درجا مناسب است.

ساختار

lambda x: x * 2

مثال 1: با map و sorted

nums = [1, 2, 3] print(list(map(lambda n: n * 2, nums))) words = ["bb", "a", "ccc"] print(sorted(words, key=lambda w: len(w)))
map+lambda: هر عضو دو برابر.
key=lambda: مرتب‌سازی بر اساس طول.

اشتباه رایج

lambda x: y = x # assignment
چرا اشتباه است؟ بدنهٔ lambda فقط یک عبارت است نه بلوک با =.
چه می‌بینی؟ SyntaxError
درست: def با return یا عبارت خالص
معیار تمام‌شدن: با lambda لیست اعداد را یک واحد افزایش بده و لیست کنی.
جمع‌بندی
  • یک عبارت
  • مناسب map/filter/sorted
  • برای منطق طولانی def بهتر است

گام عملی

  1. sorted با key طول.
  2. lambda دو آرگومانی برای جمع.

اگر گیر کردی: فقط همان خط خطا را با بخش «اشتباه رایج» و توضیح خط‌به‌خط مقایسه کن؛ کل درس را از صفر حفظ نکن.
