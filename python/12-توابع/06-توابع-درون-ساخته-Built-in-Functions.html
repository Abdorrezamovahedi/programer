توابع درون ساخته (Built-in Functions)

هدف: تابع با def تعریف کنی، آرگومان بدهی و با return نتیجه بگیری.

پوشه: توابع  |  پیش‌نیاز: درس‌های قبلی «توابع».
ارتباط با قبل: این مبحث در پوشهٔ «توابع» بعد از مفاهیم قبلی همان موضوع می‌آید؛ قبل از پرش به درس بعدی، مثال را خودت یک‌بار تایپ کن.

مفهوم

تابع کار را با یک نام جمع می‌کند تا تکرار نشود. پارامتر ورودی است؛ return مقدار را به محل صدا برمی‌گرداند. بدون return نتیجه None است.

ساختار

def name(params): return value

مثال 1: return

def area(w, h): return w * h print(area(3, 4)) result = area(5, 2) print(result)
توضیح خط‌به‌خط همین مثال
  1. خط 1: def area(w, h): — یک تابع جدید تعریف می‌کند.
  2. خط 2: return w * h — نتیجه را از تابع برمی‌گرداند.
  3. خط 3: print(area(3, 4)) — مقدار یا متن داخل print را در خروجی نشان می‌دهد.
  4. خط 4: result = area(5, 2) — یک مقدار را داخل «result» ذخیره می‌کند.
  5. خط 5: print(result) — مقدار یا متن داخل print را در خروجی نشان می‌دهد.
خط ۱–۲: تابع مساحت را حساب و برمی‌گرداند.
خط ۳: ۱۲ چاپ می‌شود.
خط ۴: مقدار برگشتی در متغیر ذخیره می‌شود.

مثال 2: پیش‌فرض

def greet(name="مهمان"): print("سلام", name) greet() greet("سارا")
توضیح خط‌به‌خط همین مثال
  1. خط 1: def greet(name="مهمان"): — یک تابع جدید تعریف می‌کند.
  2. خط 2: print("سلام", name) — مقدار یا متن داخل print را در خروجی نشان می‌دهد.
  3. خط 3: greet() — یک دستور یا فراخوانی را اجرا می‌کند.
  4. خط 4: greet("سارا") — یک دستور یا فراخوانی را اجرا می‌کند.
خط ۱: اگر name ندهی «مهمان» استفاده می‌شود.
خط ۳: بدون آرگومان.
خط ۴: با آرگومان صریح.

اشتباه رایج

def double(x): x * 2 print(double(4))
توضیح خط‌به‌خط همین مثال
  1. خط 1: def double(x): — یک تابع جدید تعریف می‌کند.
  2. خط 2: x * 2 — این خط بخشی از منطق مثال را انجام می‌دهد.
  3. خط 3: print(double(4)) — مقدار یا متن داخل print را در خروجی نشان می‌دهد.
چرا اشتباه است؟ محاسبه شده ولی return نشده.
چه می‌بینی؟ خروجی None
درست: return x * 2
معیار تمام‌شدن: بتوانی بدون نگاه به متن، یک مثال سه‌خطی دربارهٔ «توابع درون ساخته» بنویسی و اجرا کنی.
جمع‌بندی
  • def برای تعریف.
  • return برای برگرداندن مقدار.
  • بدون return → None.
  • پارامتر پیش‌فرض اختیاری است.

گام عملی

  1. تابعی بنویس که سه عدد را میانگین کند و return کند.
  2. با و بدون آرگومان پیش‌فرض صدا بزن.
  3. عمداً return را بردار و None را ببین.

اگر گیر کردی: فقط همان خط خطا را با بخش «اشتباه رایج» و توضیح خط‌به‌خط مقایسه کن؛ کل درس را از صفر حفظ نکن.
