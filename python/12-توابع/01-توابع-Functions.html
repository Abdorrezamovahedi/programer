توابع (Functions)

هدف: در این درس از MCD programmers یاد می‌گیری تابع را با def تعریف کنی، آرگومان بدهی و با return نتیجه را برگردانی تا کد تکراری نداشته باشی.

پوشه: توابع  |  پیش‌نیاز: اولین درس این پوشه.
ارتباط با قبل: این مبحث در پوشهٔ «توابع» بعد از مفاهیم قبلی همان موضوع می‌آید؛ قبل از پرش به درس بعدی، مثال را خودت یک‌بار تایپ کن.

مفهوم

تابع کار را با یک نام جمع می‌کند تا تکرار نشود و کد خوانا‌تر شود. پارامتر ورودی تابع است؛ return مقدار را به محل صدا زدن برمی‌گرداند. اگر return ننویسی، نتیجه None خواهد بود. توابع یکی از مهم‌ترین ابزارهای برنامه‌نویسی برای تقسیم مسئله به بخش‌های کوچک‌تر هستند.

ساختار

def name(params): return value

مثال 1: return

def area(w, h): return w * h print(area(3, 4)) result = area(5, 2) print(result)
خط ۱–۲: تابع مساحت را حساب و برمی‌گرداند.
خط ۳: ۱۲ چاپ می‌شود.
خط ۴: مقدار برگشتی در متغیر ذخیره می‌شود.

مثال 2: پیش‌فرض

def greet(name="مهمان"): print("سلام", name) greet() greet("سارا")
خط ۱: اگر name ندهی «مهمان» استفاده می‌شود.
خط ۳: بدون آرگومان.
خط ۴: با آرگومان صریح.

اشتباه رایج

def double(x): x * 2 print(double(4))
چرا اشتباه است؟ محاسبه شده ولی return نشده.
چه می‌بینی؟ خروجی None
درست: return x * 2
معیار تمام‌شدن: بتوانی بدون نگاه به متن، یک مثال سه‌خطی دربارهٔ «توابع» بنویسی و اجرا کنی.
جمع‌بندی
  • با def تابع را تعریف می‌کنی
  • return مقدار را به محل صدا زدن برمی‌گرداند
  • بدون return نتیجه None است
  • می‌توانی پارامتر پیش‌فرض تعریف کنی
  • توابع کد را تمیزتر و قابل استفاده مجدد می‌کنند

سوالات پرتکرار: آیا تابع می‌تواند چند مقدار برگرداند؟ بله، با return چند مقدار (به صورت tuple). آیا همیشه باید return بنویسم؟ اگر فقط کاری انجام می‌دهد و نیازی به خروجی نیست، می‌توانی return ننویسی.

گام عملی

  1. تابعی بنویس که سه عدد را میانگین کند و return کند.
  2. با و بدون آرگومان پیش‌فرض صدا بزن.
  3. عمداً return را بردار و None را ببین.

اگر گیر کردی: فقط همان خط خطا را با بخش «اشتباه رایج» و توضیح خط‌به‌خط مقایسه کن. برای تمرین بیشتر به تمرین‌های پایتون مراجعه کن.
