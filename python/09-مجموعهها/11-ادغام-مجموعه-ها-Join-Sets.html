ادغام مجموعه ها (Join Sets)

هدف: بفهمی دیتابیس داده را پایدار نگه می‌دارد و کوئری باید پارامتریک باشد نه چسباندن رشته.

پوشه: مجموعه‌ها  |  پیش‌نیاز: درس‌های قبلی «مجموعه‌ها».
ارتباط با قبل: dict و list داده را در RAM نگه می‌داشتند؛ دیتابیس بعد از بستن برنامه هم می‌ماند.

مفهوم

فایل برای دادهٔ کوچک کافی است؛ دیتابیس برای جستجو، هم‌زمانی و یکپارچگی ساخته شده. در کد واقعی از placeholder استفاده کن نه f-string داخل SQL.

ساختار

# مفهومی # cursor.execute("SELECT * FROM t WHERE id = %s", (user_id,))

مثال 1: ایدهٔ پارامتریک (شبه‌کد قابل‌اجرا نیست بدون درایور)

# درست (ایده): # sql = "SELECT name FROM users WHERE id = %s" # cursor.execute(sql, (uid,)) # # غلط و خطرناک: # sql = f"SELECT name FROM users WHERE id = {uid}" print("همیشه پارامتر بده، رشته را بچسبان")
%s یا ?: جای خالی امن؛ درایور مقدار را جدا می‌فرستد.
f-string در SQL: ریسک SQL Injection.

اشتباه رایج

query = "SELECT * FROM users WHERE name = '" + name + "'"
چرا اشتباه است؟ ورودی کاربر می‌تواند کوئری را بشکند یا داده بدزدد.
چه می‌بینی؟ آسیب‌پذیری SQL Injection
درست: execute با پارامتر جدا
معیار تمام‌شدن: یک جمله بنویس که چرا f-string داخل SQL خطرناک است و شکل امن را از روی مثال بگویی.
جمع‌بندی
  • داده پایدار
  • کوئری پارامتریک
  • هرگز ورودی را مستقیم بچسبان
  • درایور رسمی

گام عملی

  1. تفاوت فایل و DB را در دو خط بنویس.
  2. یک SELECT مفهومی با placeholder بنویس.

اگر گیر کردی: فقط همان خط خطا را با بخش «اشتباه رایج» و توضیح خط‌به‌خط مقایسه کن؛ کل درس را از صفر حفظ نکن.
