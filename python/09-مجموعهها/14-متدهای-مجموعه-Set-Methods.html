متدهای مجموعه (Set Methods)

هدف: مجموعهٔ بدون تکرار بسازی و عضویت و اتحاد را امتحان کنی.

پوشه: مجموعه‌ها  |  پیش‌نیاز: درس‌های قبلی «مجموعه‌ها».
ارتباط با قبل: این مبحث در پوشهٔ «مجموعه‌ها» بعد از مفاهیم قبلی همان موضوع می‌آید؛ قبل از پرش به درس بعدی، مثال را خودت یک‌بار تایپ کن.

مفهوم

set اعضای یکتا دارد و برای تست عضویت سریع و حذف تکراری‌ها خوب است. ایندکس عددی ندارد.

ساختار

s = {1, 2, 3} s.add(4) 1 in s

مثال 1: یکتایی و add

s = {1, 2, 2, 3} print(s) s.add(4) print(4 in s)
خط ۱–۲: تکراری ۲ حذف می‌شود.
خط ۳: ۴ اضافه می‌شود.
خط ۴: عضویت True.

مثال 2: اتحاد و اشتراک

a = {1, 2, 3} b = {3, 4} print(a | b) print(a & b)
خط ۳: اتحاد.
خط ۴: اشتراک فقط ۳.

اشتباه رایج

s = {1, 2} print(s[0])
چرا اشتباه است؟ set ایندکس ندارد.
چه می‌بینی؟ TypeError: 'set' object is not subscriptable
درست: از in یا حلقه for استفاده کن نه s[i].
معیار تمام‌شدن: بتوانی بدون نگاه به متن، یک مثال سه‌خطی دربارهٔ «متدهای مجموعه» بنویسی و اجرا کنی.
جمع‌بندی
  • تکراری‌ها حذف می‌شوند.
  • ایندکس ندارد.
  • add برای اضافه.
  • | اتحاد و & اشتراک.

گام عملی

  1. از یک لیست با تکرار set بساز.
  2. عضویت یک عدد را چک کن.
  3. اتحاد دو set را چاپ کن.
