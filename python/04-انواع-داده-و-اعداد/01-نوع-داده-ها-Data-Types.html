نوع داده ها (Data Types)

هدف این درس: همهٔ نوع‌های پرکاربرد را در یک نگاه بشناسی و با type() چک کنی.

پوشه: انواع داده و اعداد  |  نقش: درس معرفی مبحث

مفهوم به زبان ساده

هر مقدار در پایتون یک «نوع» دارد. نوع مشخص می‌کند چه کارهایی روی آن مجاز است. در فهرست زیر، هر نوع با یک خط کد و کامنت معرفی شده است.

فهرست معرفی: انواع داده

همهٔ موارد این مبحث را یک‌جا در کد ببین. هر خط با کامنت توضیح داده شده است.

# انواع دادهٔ پایه در پایتون — هر خط یک نوع n = 10 # int: عدد صحیح (بدون اعشار) price = 3.5 # float: عدد اعشاری name = "سارا" # str: متن (رشته) داخل " (دابل‌کوتیشن) ok = True # bool: فقط True یا False items = [1, 2, 3] # list: فهرست قابل تغییر point = (1, 2) # tuple: چندتایی مرتب (معمولاً ثابت) user = {"age": 20} # dict: کلید → مقدار unique = {1, 2, 2} # set: بدون تکرار (اینجا {1, 2}) empty = None # NoneType: مقدار «هیچ»
خواندن فهرست: هر خط یک نمونه می‌سازد؛ کامنت جلوی همان خط معنی نوع را می‌گوید.
type(): در مثال بعدی با type می‌بینی پایتون چه نوعی گزارش می‌دهد.

مثال 1: دیدن نوع با type

print(type(10)) print(type(3.5)) print(type("سلام")) print(type(True))
خط ۱: type(10) → int ؛ عدد صحیح.
خط ۲: type(3.5) → float ؛ اعشاری.
خط ۳: type("سلام") → str ؛ متن.
خط ۴: type(True) → bool ؛ درست/نادرست.

اشتباه رایج مبتدی‌ها

print(type(سلام))
چرا اشتباه است؟ بدون " (دابل‌کوتیشن)، سلام نام متغیر فرض می‌شود نه متن.
چه می‌بینی؟ NameError
درست: print(type("سلام"))
معیار تمام‌شدن درس: چهار type بالا را اجرا کنی و بدون نگاه به جواب بگویی هر کدام چه نوعی است.
جمع‌بندی
  • هر مقدار یک نوع دارد
  • فهرست معرفی را با کامنت بخوان
  • type برای چک کردن است

گام عملی — همین الان

  1. type یک list و یک dict را چاپ کن.
  2. عمداً بدون " (دابل‌کوتیشن) خطا بگیر.

اگر گیر کردی، همان خط کد را با توضیح زیر مثال مقایسه کن.
