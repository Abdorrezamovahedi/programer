جمع دو عدد (Add Two Numbers)

هدف: نوع مقدار را با type ببینی و فرق int و float و str را بدانی.

پوشه: انواع داده و اعداد  |  پیش‌نیاز: درس‌های قبلی «انواع داده و اعداد».
ارتباط با قبل: این مبحث در پوشهٔ «انواع داده و اعداد» بعد از مفاهیم قبلی همان موضوع می‌آید؛ قبل از پرش به درس بعدی، مثال را خودت یک‌بار تایپ کن.

مفهوم

هر مقدار نوعی دارد که عملیات مجاز را مشخص می‌کند. type نوع را نشان می‌دهد.

ساختار

type(value)

مثال 1: انواع پایه

print(type(10)) print(type(3.5)) print(type("10")) print(type(True))
خط ۱: int
خط ۲: float
خط ۳: str — حتی اگر ظاهر عدد باشد
خط ۴: bool

اشتباه رایج

print("5" + 1)
چرا اشتباه است؟ str و int با + جمع نمی‌شوند.
چه می‌بینی؟ TypeError
درست: print(int("5") + 1)
معیار تمام‌شدن: بتوانی بدون نگاه به متن، یک مثال سه‌خطی دربارهٔ «جمع دو عدد» بنویسی و اجرا کنی.
جمع‌بندی
  • type نوع را می‌گوید.
  • ظاهر کافی نیست؛ نوع مهم است.
  • عملیات باید با نوع سازگار باشد.
  • TypeError یعنی نوع‌ها جور نیستند.

گام عملی

  1. type چند مقدار مختلف را چاپ کن.
  2. "5" و 5 را مقایسه کن.
  3. TypeError را عمداً بساز.

اگر گیر کردی: فقط همان خط خطا را با بخش «اشتباه رایج» و توضیح خط‌به‌خط مقایسه کن؛ کل درس را از صفر حفظ نکن.
