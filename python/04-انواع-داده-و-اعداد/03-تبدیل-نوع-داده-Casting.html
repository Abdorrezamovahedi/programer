تبدیل نوع داده (Casting)

هدف: بین int و str و float آگاهانه تبدیل کنی.

درس معرفی «انواع داده»: اگر هنوز فهرست کامل این مبحث را نخوانده‌ای، اول برو به نوع داده ها (Data Types) (همین پوشه — معمولاً اولین درس). آنجا همهٔ انواع/علامت‌ها یک‌جا معرفی شده‌اند.
پوشه: انواع داده و اعداد  |  پیش‌نیاز: درس‌های قبلی «انواع داده و اعداد».
ارتباط با قبل: این مبحث در پوشهٔ «انواع داده و اعداد» بعد از مفاهیم قبلی همان موضوع می‌آید؛ قبل از پرش به درس بعدی، مثال را خودت یک‌بار تایپ کن.

مفهوم

input همیشه رشته می‌دهد. برای حساب باید int یا float کنی. str عدد را به متن تبدیل می‌کند تا بشود به رشته چسباند.

ساختار

int(x) float(x) str(x)

مثال 1: رشته به عدد

text = "42" n = int(text) print(n + 8)
خط ۱: هنوز str است.
خط ۲: تبدیل به int.
خط ۳: حالا جمع عددی ممکن است → ۵۰.

مثال 2: عدد به رشته

age = 20 print("سن: " + str(age))
خط ۲: بدون str، + خطا می‌دهد.

اشتباه رایج

int("۳.۱۴")
چرا اشتباه است؟ int رشتهٔ اعشاری را مستقیم قبول نمی‌کند (و ارقام فارسی هم جداگانه مشکل‌سازند).
چه می‌بینی؟ ValueError
درست: int(float("3.14")) با ارقام لاتین
معیار تمام‌شدن: بتوانی بدون نگاه به متن، یک مثال سه‌خطی دربارهٔ «تبدیل نوع داده» بنویسی و اجرا کنی.
جمع‌بندی
  • int/float/str برای تبدیل.
  • input → str.
  • تبدیل نامعتبر ValueError.
  • int از float قسمت صحیح را برمی‌دارد.

گام عملی

  1. رشتهٔ عددی را int کن و جمع بزن.
  2. عدد را str کن و به جمله بچسبان.
  3. عمداً int روی متن غیرعددی و خطا را ببین.

اگر گیر کردی: فقط همان خط خطا را با بخش «اشتباه رایج» و توضیح خط‌به‌خط مقایسه کن؛ کل درس را از صفر حفظ نکن.
