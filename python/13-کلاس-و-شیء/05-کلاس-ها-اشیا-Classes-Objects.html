کلاس ها/اشیا (Classes/Objects)

هدف: یک کلاس با __init__ و متد بسازی و یک شیء از آن بسازی.

پوشه: کلاس و شیء  |  پیش‌نیاز: درس‌های قبلی «کلاس و شیء».
ارتباط با قبل: تابع کار را با نام جمع می‌کرد؛ کلاس داده + رفتار مرتبط را با هم جمع می‌کند.

مفهوم

کلاس قالب است؛ شیء نمونهٔ ساخته‌شده است. __init__ موقع ساخت اجرا می‌شود. self همان شیء جاری است.

ساختار

class Name: def __init__(self, ...): self.x = ... def method(self): ...

مثال 1: کلاس ساده

class Student: def __init__(self, name, score): self.name = name self.score = score def passed(self): return self.score >= 10 s = Student("سارا", 18) print(s.name, s.passed())
class: قالب Student.
__init__: موقع Student(...) صدا زده می‌شود.
self.name: داده روی خود شیء ذخیره می‌شود.
passed: متد از داده‌های همان شیء استفاده می‌کند.
Student(...): یک شیء واقعی ساخته می‌شود.

اشتباه رایج

class A: def __init__(self, x): x = x # نه self.x a = A(5) print(a.x)
چرا اشتباه است؟ x محلی است؛ روی شیء ذخیره نشده.
چه می‌بینی؟ AttributeError: 'A' object has no attribute 'x'
درست: self.x = x
معیار تمام‌شدن: کلاسی برای مستطیل با عرض و ارتفاع بساز که متد area داشته باشد و یک نمونه را چاپ کنی.
جمع‌بندی
  • کلاس قالب، شیء نمونه
  • self الزامی در متد
  • داده را با self ذخیره کن
  • AttributeError یعنی آن ویژگی ساخته نشده

گام عملی

  1. Student را با دو نمره مختلف بساز.
  2. عمداً self را حذف کن و خطا را ببین.
  3. یک متد دیگر اضافه کن.
