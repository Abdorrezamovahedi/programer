try...except

هدف این درس: کدی که ممکن است خطا بدهد را طوری بنویسی که برنامه نترکد و پیام روشن بدهد.

پوشه: مدیریت خطا

مفهوم به زبان ساده

try یعنی «این کار را انجام بده». except یعنی «اگر این خطای مشخص آمد، این کار را بکن». برای یادگیری، نوع خطا را مشخص بنویس نه except خالیِ همه‌چیز.

ساختار

try: کد_مشکوک except نوع_خطا: کد_جایگزین

بالا فقط شکل کلی است؛ پایین مثال واقعی می‌بینی که اجرا می‌شود.

مثال 1: تقسیم امن

a = 10 b = 0 try: print(a / b) except ZeroDivisionError: print("نمیشه بر صفر تقسیم کرد")
خط ۳–۴: تلاش برای تقسیم؛ اینجا خطا می‌دهد.
خط ۵–۶: به‌جای ترکیدن برنامه، پیام خودت چاپ می‌شود.

مثال 2: تبدیل ورودی به عدد

text = "۱۲" # یا هر متن غیرعددی برای تست try: n = int(text) print(n) except ValueError: print("این متن را نشد به عدد صحیح تبدیل کرد")
خط ۲–۴: تلاش برای int؛ اگر متن عدد نباشد خطا می‌شود.
خط ۵–۶: ValueError را می‌گیری و پیام می‌دهی.

اشتباه رایج مبتدی‌ها

try: print(10 / 0) except: pass
چرا اشتباه است؟ except خالی همه خطاها را قورت می‌دهد و اشکال واقعی را پنهان می‌کند.
چه می‌بینی؟ دیباگ سخت می‌شود
درست: except ZeroDivisionError: و پیام مشخص
معیار تمام‌شدن درس: یک تقسیم بر صفر را با پیام فارسی مدیریت کنی.
جمع‌بندی
  • try تلاش
  • except مسیر خطا
  • نوع خطا را مشخص کن

گام عملی — همین الان
