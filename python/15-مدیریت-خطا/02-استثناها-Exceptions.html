استثناها (Exceptions)

هدف: خطای قابل‌پیش‌بینی را با try/except بگیری تا برنامه نپرد.

پوشه: مدیریت خطا  |  پیش‌نیاز: درس‌های قبلی «مدیریت خطا».
ارتباط با قبل: قبلاً خطا برنامه را می‌بست؛ حالا می‌توانی همان نقطه را کنترل کنی.

مفهوم

try کدی را امتحان می‌کند که ممکن است خطا بدهد. except همان نوع خطا را می‌گیرد و مسیر جایگزین اجرا می‌کند.

ساختار

try: ... except SomeError: ...

مثال 1: تبدیل امن

text = "abc" try: n = int(text) print(n) except ValueError: print("عدد معتبر نیست")
try: int ممکن است ValueError بدهد.
except ValueError: فقط همین نوع را می‌گیریم؛ بقیه بالا می‌روند.
پیام: به‌جای کرش، پیام قابل‌فهم.

اشتباه رایج

try: int("x") except: pass
چرا اشتباه است؟ except خالی همه چیز را می‌بلعد و باگ را مخفی می‌کند.
چه می‌بینی؟ خطاهای جدی هم خاموش می‌شوند
درست: except ValueError: و پیام یا منطق مشخص
معیار تمام‌شدن: ورودی فرضی غیرعددی را int کن و فقط ValueError را با پیام فارسی بگیر.
جمع‌بندی
  • try برای بخش خطرناک
  • except نوع مشخص
  • از except برهنه پرهیز کن
  • پیام مفید بده

گام عملی

  1. int روی "3.5" را با except مدیریت کن.
  2. یک except جدا برای نوع دیگر اضافه کن.

اگر گیر کردی: فقط همان خط خطا را با بخش «اشتباه رایج» و توضیح خط‌به‌خط مقایسه کن؛ کل درس را از صفر حفظ نکن.
