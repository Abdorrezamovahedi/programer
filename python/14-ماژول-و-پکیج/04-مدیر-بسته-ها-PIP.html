مدیر بسته ها (PIP)

هدف: با import از کد آماده استفاده کنی و بفهمی ماژول چیست.

پوشه: ماژول و پکیج  |  پیش‌نیاز: درس‌های قبلی «ماژول و پکیج».
ارتباط با قبل: قبلاً تابع خودت می‌نوشتی؛ حالا از تابع‌های آماده‌ای استفاده می‌کنی که دیگران نوشته‌اند.

مفهوم

ماژول فایل/کتابخانه‌ای از توابع و ثابت‌هاست. import آن را در دسترس می‌گذارد تا چرخ را از نو نسازی.

ساختار

import math from math import sqrt

مثال 1: math و random

import math import random print(math.sqrt(16)) print(random.randint(1, 6))
import math: ماژول ریاضی استاندارد.
sqrt: جذر ۱۶ = ۴.۰
randint: عدد صحیح تصادفی در بازهٔ بسته.

اشتباه رایج

print(sqrt(9))
چرا اشتباه است؟ sqrt بدون import یا from در دسترس نیست.
چه می‌بینی؟ NameError: name 'sqrt' is not defined
درست: import math; math.sqrt(9) یا from math import sqrt
معیار تمام‌شدن: با math.ceil یک عدد اعشاری را به بالا گرد کن و با random یک تاس بینداز.
جمع‌بندی
  • import نام ماژول
  • نام.تابع
  • from ... import ...
  • NameError یعنی import نشده

گام عملی

  1. math.pi را چاپ کن.
  2. از random.choice روی یک لیست استفاده کن.
  3. عمداً بدون import صدا بزن.
