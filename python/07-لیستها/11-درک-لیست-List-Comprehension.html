درک لیست (List Comprehension)

هدف این درس: یک لیست جدید را در یک خط، از روی یک لیست/دامنه بسازی.

پوشه: لیست‌ها

مفهوم به زبان ساده

به‌جای حلقهٔ چندخطی برای ساختن لیست، می‌توانی بگویی «این مقدار را برای هر عضو بساز». شرط اختیاری هم می‌توانی بگذاری.

ساختار

[عبارت for عضو in دنباله] [عبارت for عضو in دنباله if شرط]

بالا فقط شکل کلی است؛ پایین مثال واقعی می‌بینی که اجرا می‌شود.

مثال 1: مربع عددها

nums = [1, 2, 3, 4] squares = [n * n for n in nums] print(squares)
خط ۱: لیست اولیه.
خط ۲: برای هر n، مقدار n*n را در لیست جدید بگذار.
خط ۳: خروجی: [1, 4, 9, 16]

مثال 2: فقط زوج‌ها

nums = [1, 2, 3, 4, 5, 6] evens = [n for n in nums if n % 2 == 0] print(evens)
خط ۲: فقط وقتی عضو را نگه دار که زوج باشد.
خط ۳: خروجی: [2, 4, 6]

اشتباه رایج مبتدی‌ها

[print(n) for n in nums]
چرا اشتباه است؟ درک لیست برای ساختن لیست است؛ print مقدار مفید در لیست نمی‌سازد.
چه می‌بینی؟ لیستی از None و عوارض جانبی
درست: یا حلقه for معمولی با print، یا درک لیست برای مقدار واقعی
معیار تمام‌شدن درس: یک لیست مربعات و یک لیست فیلترشده با if بسازی.
جمع‌بندی
  • برای ساخت لیست جدید مناسب است
  • if اختیاری برای فیلتر
  • عوارض جانبی را داخلش نگذار

گام عملی — همین الان

  1. از range(1, 6) لیست مکعب‌ها را بساز.

هر مثال را خودت تایپ کن و اجرا کن؛ فقط خواندن کافی نیست.
