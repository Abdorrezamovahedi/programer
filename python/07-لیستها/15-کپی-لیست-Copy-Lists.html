کپی لیست (Copy Lists)

هدف: بفهمی b=a ارجاع است نه کپی، و با copy یا slice کپی سطحی بسازی.

درس معرفی «کارهای رایج روی لیست»: اگر هنوز فهرست کامل این مبحث را نخوانده‌ای، اول برو به لیست ها (Lists) (همین پوشه — معمولاً اولین درس). آنجا همهٔ انواع/علامت‌ها یک‌جا معرفی شده‌اند.
پوشه: لیست‌ها  |  پیش‌نیاز: درس‌های قبلی «لیست‌ها».
ارتباط با قبل: این مبحث در پوشهٔ «لیست‌ها» بعد از مفاهیم قبلی همان موضوع می‌آید؛ قبل از پرش به درس بعدی، مثال را خودت یک‌بار تایپ کن.

مفهوم

b = a هر دو به یک لیست اشاره می‌کنند؛ تغییر یکی در دیگری دیده می‌شود. برای کپی مستقل سطح اول: a.copy() یا a[:]. برای ساختار تو در تو گاهی deepcopy لازم است.

ساختار

b = a.copy() b = a[:] import copy; copy.deepcopy(a)

مثال 1: ارجاع در مقابل کپی

a = [1, 2, 3] b = a c = a.copy() b.append(4) c.append(9) print("a", a) print("c", c)
خط ۲: b همان شیء a است.
خط ۳: c لیست جدا با همان مقادیر اولیه.
خط ۴: append روی b روی a هم اثر می‌گذارد.
خط ۵: append روی c فقط c را عوض می‌کند.

اشتباه رایج

a = [[1], [2]] b = a.copy() b[0].append(9) print(a)
چرا اشتباه است؟ copy سطحی است؛ لیست‌های داخلی هنوز مشترک‌اند.
چه می‌بینی؟ a هم تغییر می‌کند: [[1,9],[2]]
درست: import copy; b = copy.deepcopy(a)
معیار تمام‌شدن: بتوانی بدون نگاه به متن، یک مثال سه‌خطی دربارهٔ «کپی لیست» بنویسی و اجرا کنی.
جمع‌بندی
  • b=a ارجاع است.
  • copy و [:] کپی سطحی.
  • تودرتو → deepcopy.
  • قبل از تغییر، مطمئن شو روی کپی کار می‌کنی یا نه.

گام عملی

  1. تفاوت b=a و b=a.copy() را با append نشان بده.
  2. یک لیست تو در تو را با copy عوض کن و ببین اصل چه می‌شود.
  3. همان را با deepcopy تکرار کن.
