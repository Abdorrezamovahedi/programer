سؤال پرتکرار

آیا این دوره پایتون برای صفر مطلق مناسب است؟ بله؛ متن‌ها برای کسی نوشته شده که تازه می‌خواهد برنامه‌نویسی را شروع کند.

بعد از پایتون چه مسیری دارد؟ می‌توانی سراغ پروژه‌های کوچک، کار با فایل، یا مسیر وب با HTML و CSS بروی.
