انواع داده ساده در متغیر

هدف درس: بشناسی چهار نوع رایج را و با type نوع مقدار را بررسی کنی.

هر مقدار در پایتون نوعی دارد. عدد بدون اعشار int است، متن str است، عدد اعشاری float است و درست/غلط bool است. لازم نیست نوع را خودت بنویسی؛ پایتون از روی مقدار می‌فهمد.

age = 20 height = 1.75 name = "Mina" is_student = True print(type(age)) print(type(name))
توضیح خط‌به‌خط همین مثال
  1. خط 1age = 20عدد صحیح (int).
  2. خط 2height = 1.75عدد اعشاری (float).
  3. خط 3name = "Mina"متن (str).
  4. خط 4is_student = Trueمقدار بولین (bool).
  5. خط 5print(type(age))نوع age را نشان می‌دهد.
  6. خط 6print(type(name))نوع name را نشان می‌دهد.
  • True و False باید با حرف بزرگ نوشته شوند.
  • متن همیشه داخل نقل‌قول است.
