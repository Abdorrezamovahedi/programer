انواع داده ساده در پایتون

هدف این درس: انواع اصلی داده را بشناسی و با type() نوع را چک کنی.

a = 10 # int b = 3.14 # float c = "سلام" # str d = True # bool print(type(a)) print(type(c))
توضیح خط‌به‌خط همین مثال
  1. خط 1: a = 10 # int — یک مقدار را داخل «a» ذخیره می‌کند.
  2. خط 2: b = 3.14 # float — یک مقدار را داخل «b» ذخیره می‌کند.
  3. خط 3: c = "سلام" # str — یک مقدار را داخل «c» ذخیره می‌کند.
  4. خط 4: d = True # bool — یک مقدار را داخل «d» ذخیره می‌کند.
  5. خط 5: print(type(a)) — مقدار یا متن داخل print را در خروجی نشان می‌دهد.
  6. خط 6: print(type(c)) — مقدار یا متن داخل print را در خروجی نشان می‌دهد.
type() نوع داده را نشان می‌دهد.
معیار تمام‌شدن درس: چهار نوع داده اصلی را ساخته و type آن‌ها را چاپ کرده باشی.
