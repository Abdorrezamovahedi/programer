متغیرها در پایتون

متغیر برای ذخیره داده است. در این بخش در ۶ درس یاد می‌گیری متغیر بسازی، درست نام بگذاری، چند مقدار بدهی، دامنه را بفهمی، نوع را تبدیل کنی و تمرین کنی.

۱. متغیرهامفهوم و تعریف ۲. نام متغیرهاقواعد نام‌گذاری ۳. تخصیص چندتاییچند مقدار همزمان ۴. متغیرهای سراسریدامنه global ۵. تبدیل نوعint، str، float ۶. تمرین متغیرهاتمرین عملی

مسیر پیشنهادی

  1. اول مفهوم متغیر را بخوان و مثال را اجرا کن.
  2. بعد قواعد نام‌گذاری را یاد بگیر.
  3. سپس تخصیص چندتایی را تمرین کن.
  4. با متغیر سراسری دامنه را بفهم.
  5. تبدیل نوع را یاد بگیر.
  6. در پایان تمرین‌ها را حل کن.
