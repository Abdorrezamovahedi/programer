متغیرهای سراسری (Global Variables)

هدف: فرق متغیر بیرون تابع با داخل تابع را بدانی و فقط وقتی لازم است از global استفاده کنی.

درس معرفی «متغیرها»: اگر هنوز فهرست کامل این مبحث را نخوانده‌ای، اول برو به متغیرها (Variables) (همین پوشه — معمولاً اولین درس). آنجا همهٔ انواع/علامت‌ها یک‌جا معرفی شده‌اند.
پوشه: متغیرها  |  پیش‌نیاز: درس‌های قبلی «متغیرها».
ارتباط با قبل: این مبحث در پوشهٔ «متغیرها» بعد از مفاهیم قبلی همان موضوع می‌آید؛ قبل از پرش به درس بعدی، مثال را خودت یک‌بار تایپ کن.

مفهوم

متغیر تعریف‌شده در سطح فایل (بیرون تابع) سراسری است و داخل تابع معمولاً خوانده می‌شود. اگر بخواهی همان نام را از داخل تابع عوض کنی، باید با global اعلام کنی؛ وگرنه پایتون فکر می‌کند متغیر محلی جدیدی می‌سازی.

ساختار

x = 1 def f(): global x x = 2

مثال 1: خواندن سراسری بدون global

msg = "سلام" def show(): print(msg) show()
خط ۱: msg در سطح ماژول تعریف شده → سراسری.
خط ۲–۳: داخل تابع فقط خوانده می‌شود؛ برای خواندن global لازم نیست.
خط ۴: تابع را صدا می‌زنیم؛ «سلام» چاپ می‌شود.

مثال 2: تغییر سراسری با global

count = 0 def inc(): global count count = count + 1 inc() inc() print(count)
خط ۱: شمارنده از صفر.
خط ۳: بدون این خط، count = ... یک متغیر محلی می‌ساخت و سراسری عوض نمی‌شد.
خط ۴: مقدار سراسری یکی زیاد می‌شود.
خط ۵–۶: دو بار صدا → count برابر ۲.
خط ۷: ۲ چاپ می‌شود.

اشتباه رایج

n = 1 def bad(): n = n + 1 bad()
چرا اشتباه است؟ پایتون n = را محلی فرض می‌کند، اما در همان خط n سمت راست هنوز محلی تعریف نشده.
چه می‌بینی؟ UnboundLocalError
درست: یا global n بگذار، یا مقدار را به عنوان آرگومان بده و return کن (روش تمیزتر).
معیار تمام‌شدن: بتوانی بدون نگاه به متن، یک مثال سه‌خطی دربارهٔ «متغیرهای سراسری» بنویسی و اجرا کنی.
جمع‌بندی
  • خواندن سراسری معمولاً آزاد است.
  • نوشتن روی سراسری داخل تابع → global.
  • زیاد از global استفاده نکن؛ return و آرگومان معمولاً بهترند.
  • UnboundLocalError نشانهٔ قاطی شدن محلی/سراسری است.

گام عملی

  1. یک شمارنده سراسری بساز و با تابع زیادش کن.
  2. همان کار را بدون global با return بازنویسی کن.
  3. عمداً UnboundLocalError بساز و پیام را بخوان.

اگر گیر کردی: فقط همان خط خطا را با بخش «اشتباه رایج» و توضیح خط‌به‌خط مقایسه کن؛ کل درس را از صفر حفظ نکن.
