نام متغیرها (Variable Names)

هدف: بتوانی نام معتبر بسازی و بفهمی چرا بعضی نام‌ها SyntaxError می‌دهند.

درس معرفی «متغیرها»: اگر هنوز فهرست کامل این مبحث را نخوانده‌ای، اول برو به متغیرها (Variables) (همین پوشه — معمولاً اولین درس). آنجا همهٔ انواع/علامت‌ها یک‌جا معرفی شده‌اند.
پوشه: متغیرها  |  پیش‌نیاز: درس‌های قبلی «متغیرها».
ارتباط با قبل: این مبحث در پوشهٔ «متغیرها» بعد از مفاهیم قبلی همان موضوع می‌آید؛ قبل از پرش به درس بعدی، مثال را خودت یک‌بار تایپ کن.

مفهوم

نام متغیر شناسه‌ای است که پایتون با آن مقدار را پیدا می‌کند. باید با حرف یا _ شروع شود، فاصله و - نداشته باشد، و کلمهٔ کلیدی (مثل for یا class) نباشد. خوانایی مهم است: total_price بهتر از tp است.

ساختار

user_name = "..." # حروف، عدد، _ # 2x = 1 # غیرمجاز # my-name = 1 # غیرمجاز

مثال 1: نام‌های درست

user_name = "سارا" total_price = 150000 is_active = True print(user_name, total_price, is_active)
خط ۱: user_name با حرف شروع شده و کلمات با _ جدا شده‌اند (سبک رایج پایتون).
خط ۲: total_price معنی دارد: خواننده می‌فهمد این قیمت کل است.
خط ۳: is_active برای بولین رایج است؛ True/False بدون " (دابل‌کوتیشن) نوشته می‌شوند.
خط ۴: سه مقدار چاپ می‌شوند تا ببینی انتساب درست بوده.

مثال 2: نام‌های غیرمجاز (اجرا نکن؛ فقط برای فهم خطا)

# 2name = "بد" # شروع با عدد # my-name = "بد" # خط تیره # class = 1 # کلمهٔ کلیدی
توضیح: هر کدام اگر از حالت کامنت خارج شوند SyntaxError می‌دهند. class برای تعریف کلاس رزرو شده است.

اشتباه رایج

for = 10 print(for)
چرا اشتباه است؟ for کلمهٔ کلیدی حلقه است؛ نمی‌تواند نام متغیر باشد.
چه می‌بینی؟ SyntaxError: invalid syntax
درست: for_count = 10 print(for_count)
معیار تمام‌شدن: بتوانی بدون نگاه به متن، یک مثال سه‌خطی دربارهٔ «نام متغیرها» بنویسی و اجرا کنی.
جمع‌بندی
  • شروع با حرف یا _؛ عدد فقط بعد از آن.
  • فاصله و - ممنوع؛ از _ استفاده کن.
  • کلمات کلیدی را نام متغیر نگذار.
  • نام معنی‌دار بنویس تا کد خوانا بماند.

گام عملی

  1. سه متغیر با نام خوانا برای سن، قد و شهر بساز و چاپ کن.
  2. عمداً نامی با عدد اول بساز و پیام SyntaxError را بخوان.
  3. یک نام تک‌حرفی را با نام توصیفی عوض کن و ببین خوانایی چه فرقی کرد.

اگر گیر کردی: فقط همان خط خطا را با بخش «اشتباه رایج» و توضیح خط‌به‌خط مقایسه کن؛ کل درس را از صفر حفظ نکن.
