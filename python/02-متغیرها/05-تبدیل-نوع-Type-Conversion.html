تبدیل نوع در پایتون

هدف درس: بتوانی در مواقع لازم نوع مقدار را عوض کنی؛ مثلاً متن عددی را به int تبدیل کنی.

گاهی ورودی به‌صورت متن می‌آید ولی تو می‌خواهی حساب کنی. آن وقت باید نوع را عوض کنی. int() متن عددی را عدد می‌کند و str() عدد را متن می‌کند.

a = "7" b = int(a) c = b + 3 print(c) print(str(c) + " امتیاز")
توضیح خط‌به‌خط همین مثال
  1. خط 1a = "7"این مقدار متن است نه عدد.
  2. خط 2b = int(a)متن 7 به عدد صحیح تبدیل می‌شود.
  3. خط 3c = b + 3حالا جمع عددی ممکن است: 10.
  4. خط 4print(c)عدد 10 چاپ می‌شود.
  5. خط 5print(str(c) + " امتیاز")عدد به متن تبدیل و به رشته وصل می‌شود.
