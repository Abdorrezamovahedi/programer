نام‌گذاری متغیر در پایتون

هدف این درس: قواعد نام‌گذاری درست متغیر را بدانی.

user_name = "علی" # درست age2 = 25 # درست # 2age = 25 # اشتباه - با عدد شروع نشود # user-name = "علی" # اشتباه - خط تیره مجاز نیست
نام متغیر باید با حرف یا _ شروع شود و می‌تواند شامل حرف، عدد و _ باشد. از فاصله و خط تیره استفاده نکن.
معیار تمام‌شدن درس: چند متغیر با نام‌های خوانا و صحیح ساخته باشی.
جمع‌بندی
  • با حرف یا _ شروع کن
  • از فاصله و - استفاده نکن
  • نام‌های معنادار و خوانا انتخاب کن (مثل user_name)

گام عملی

  1. سه متغیر با نام‌های معنادار بساز و چاپ کن.
