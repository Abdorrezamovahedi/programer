نام‌گذاری متغیر در پایتون

هدف درس: بتوانی برای متغیر نام درست و خوانا انتخاب کنی و از نام‌های غیرمجاز پرهیز کنی.

مفهوم به زبان ساده

نام متغیر آدرس جعبه است. اگر نام گیج‌کننده باشد، بعداً خودت هم سردرگم می‌شوی. پایتون چند قانون ساده دارد: نام نباید با عدد شروع شود، فاصله نگیرد، و بعضی کلمه‌های رزرو شده مثل if را نمی‌توانی استفاده کنی.

student_name = "Ali" score1 = 20 print(student_name) print(score1)
توضیح خط‌به‌خط همین مثال
  1. خط 1student_name = "Ali"نام خوانا با زیرخط؛ معنی‌دار است.
  2. خط 2score1 = 20عدد در وسط یا آخر نام مجاز است.
  3. خط 3print(student_name)چاپ نام دانش‌آموز.
  4. خط 4print(score1)چاپ نمره.
  • به‌جای a و b از نام‌های واضح مثل age یا total استفاده کن.
  • نام‌هایی مثل 1name اشتباه‌اند.
  • حروف بزرگ و کوچک فرق دارند: Age با age یکی نیست.
