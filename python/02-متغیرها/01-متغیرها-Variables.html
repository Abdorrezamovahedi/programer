متغیر در پایتون چیست؟

هدف: بفهمی متغیر مثل یک جعبه نام‌دار برای نگه‌داشتن مقدار است.

مفهوم ساده

وقتی می‌خواهی عددی یا متنی را نگه داری تا بعداً استفاده کنی، آن را داخل متغیر می‌گذاری. در پایتون لازم نیست نوع متغیر را از قبل اعلام کنی؛ با یک انتساب ساده ساخته می‌شود.

name = "Ali" age = 20 print(name) print(age)
توضیح خط‌به‌خط همین مثال
  1. خط 1name = "Ali"متغیر name با مقدار متنی Ali ساخته می‌شود.
  2. خط 2age = 20متغیر age با عدد 20 ساخته می‌شود.
  3. خط 3print(name)مقدار name را چاپ می‌کند.
  4. خط 4print(age)مقدار age را چاپ می‌کند.
تمرین: یک متغیر برای نام خودت و یک متغیر برای سن بساز و چاپ کن.
جمع‌بندی
  • متغیر نامی برای یک مقدار است.
  • با = مقدار می‌دهیم.
  • می‌توانی بعداً مقدار را عوض کنی.
