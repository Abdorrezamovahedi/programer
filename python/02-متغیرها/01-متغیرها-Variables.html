متغیر در پایتون چیست؟

هدف درس: بفهمی متغیر مثل یک جعبه نام‌دار برای نگه‌داشتن مقدار است و بتوانی مقدار را ذخیره و چاپ کنی.

پیش‌نیاز: آشنایی خیلی کوتاه با print از بخش شروع و مبانی.

مفهوم به زبان ساده

وقتی می‌خواهی عددی یا متنی را نگه داری تا بعداً استفاده کنی، آن را داخل متغیر می‌گذاری. در پایتون لازم نیست از قبل بگویی نوع متغیر چیست؛ فقط نام می‌گذاری و با علامت = مقدار می‌دهی.

مثال

name = "Sara" age = 18 print(name) print(age)
توضیح خط‌به‌خط همین مثال
  1. خط 1name = "Sara"متغیر name ساخته می‌شود و متن Sara داخلش قرار می‌گیرد.
  2. خط 2age = 18متغیر age با عدد 18 ساخته می‌شود.
  3. خط 3print(name)مقدار name را روی صفحه نشان می‌دهد.
  4. خط 4print(age)مقدار age را نشان می‌دهد.

نکته‌های مهم

  • نام متغیر را خودت انتخاب می‌کنی؛ بهتر است معنادار باشد.
  • مقدار متغیر را بعداً می‌توانی عوض کنی.
  • متن را بین علامت نقل‌قول بنویس.
جمع‌بندی
  • متغیر نامی برای یک مقدار است.
  • با = مقدار می‌دهیم.
  • با print می‌توانی مقدار را ببینی.
