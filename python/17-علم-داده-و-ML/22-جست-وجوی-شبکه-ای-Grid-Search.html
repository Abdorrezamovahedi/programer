جست وجوی شبکه ای (Grid Search)

هدف: ایدهٔ اصلی «جست وجوی شبکه ای (Grid Search)» را با یک پیاده‌سازی کوچک در پایتون ببینی.

پوشه: علم داده و ML  |  پیش‌نیاز: درس‌های قبلی «علم داده و ML».
ارتباط با قبل: همان list که قبلاً دیدی، اینجا نقش ساختار دادهٔ خاص را بازی می‌کند.

مفهوم

ساختار داده نحوهٔ چیدن اطلاعات است؛ الگوریتم نحوهٔ پردازش آن. با list می‌توان بسیاری از ایده‌ها را ساده شبیه‌سازی کرد تا مفهوم جا بیفتد.

مثال 1: پشته با list (LIFO)

stack = [] stack.append("A") stack.append("B") print(stack.pop()) print(stack)
append: ورود به بالای پشته.
pop: خروج از بالا → B؛ LIFO.
باقی‌مانده: فقط A می‌ماند.

اشتباه رایج

stack = [] stack.pop()
چرا اشتباه است؟ پشته خالی است.
چه می‌بینی؟ IndexError
درست: قبل از pop چک کن if stack:
معیار تمام‌شدن: سه عنصر push کن، یکی pop کن و محتویات باقی‌مانده را چاپ کنی.
جمع‌بندی
  • مفهوم مهم‌تر از کتابخانهٔ پیچیده
  • list برای آموزش اولیه کافی است
  • خالی بودن را چک کن

گام عملی

  1. صف ساده با append و pop(0) بساز و بگو چرا کند است.
  2. جستجوی خطی یک عدد در لیست بنویس.

اگر گیر کردی: فقط همان خط خطا را با بخش «اشتباه رایج» و توضیح خط‌به‌خط مقایسه کن؛ کل درس را از صفر حفظ نکن.
