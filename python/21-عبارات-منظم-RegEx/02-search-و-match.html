search و match

search الگو را در هر جای متن می‌گردد. match فقط از اول متن چک می‌کند. اگر پیدا نشود، None برمی‌گردد.

import re s = "abc123xyz" print(re.search(r"\d+", s)) print(re.match(r"\d+", s)) print(re.match(r"abc", s))
توضیح خط‌به‌خط
  1. خط 3re.search(r"\d+", s)رقم‌ها را وسط متن پیدا می‌کند.
  2. خط 4re.match(r"\d+", s)چون با رقم شروع نشده، None.
  3. خط 5re.match(r"abc", s)از اول متن جور است.
