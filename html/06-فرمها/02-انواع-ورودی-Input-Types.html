انواع ورودی (Input Types)

هدف این درس: فرم ساده با label و input و دکمه بسازی.

پوشه: فرم‌ها  |  نقش: درس معرفی مبحث

مفهوم به زبان ساده

فرم داده را از کاربر می‌گیرد. name نام فیلد در ارسال است. label دسترسی را بهتر می‌کند.

فهرست معرفی: فرم

همهٔ موارد این مبحث را یک‌جا در کد ببین. هر خط با کامنت توضیح داده شده است.

<!-- اجزای فرم --> <form action="/send" method="get"> <!-- ظرف ارسال --> <label for="n">نام</label> <!-- برچسب فیلد --> <input id="n" name="n" type="text" required> <!-- ورودی؛ name کلید داده --> <button type="submit">ارسال</button> <!-- دکمهٔ ارسال --> </form>
توضیح خط‌به‌خط همین مثال
  1. خط 1: <!-- اجزای فرم --> — این خط توضیح (کامنت) است و اجرا نمی‌شود.
  2. خط 2: <form action="/send" method="get"> <!-- ظرف ارسال --> — شروع یا استفاده از تگ form در ساختار صفحه.
  3. خط 3: <label for="n">نام</label> <!-- برچسب فیلد --> — شروع یا استفاده از تگ label در ساختار صفحه.
  4. خط 4: <input id="n" name="n" type="text" required> <!-- ورودی؛ name کلید داده --> — شروع یا استفاده از تگ input در ساختار صفحه.
  5. خط 5: <button type="submit">ارسال</button> <!-- دکمهٔ ارسال --> — شروع یا استفاده از تگ button در ساختار صفحه.
  6. خط 6: </form> — پایان تگ form.

مثال 1: فرم نام

<form action="/x" method="get"> <label for="name">نام</label> <input id="name" name="name" type="text" required> <button type="submit">برو</button> </form>
توضیح خط‌به‌خط همین مثال
  1. خط 1: <form action="/x" method="get"> — شروع یا استفاده از تگ form در ساختار صفحه.
  2. خط 2: <label for="name">نام</label> — شروع یا استفاده از تگ label در ساختار صفحه.
  3. خط 3: <input id="name" name="name" type="text" required> — شروع یا استفاده از تگ input در ساختار صفحه.
  4. خط 4: <button type="submit">برو</button> — شروع یا استفاده از تگ button در ساختار صفحه.
  5. خط 5: </form> — پایان تگ form.
خط ۱: فرم با ارسال get.
خط ۲: برچسب وصل به id=name.
خط ۳: فیلد متنی اجباری.
خط ۴: دکمهٔ ارسال.

اشتباه رایج مبتدی‌ها

<input type="text">
توضیح خط‌به‌خط همین مثال
  1. خط 1: <input type="text"> — شروع یا استفاده از تگ input در ساختار صفحه.
چرا اشتباه است؟ بدون name و label.
چه می‌بینی؟ داده/دسترسی ضعیف
درست: name و label را بگذار
معیار تمام‌شدن درس: فرم را submit کنی و اثر را در آدرس ببینی (حتی اگر 404 شد).
جمع‌بندی
  • name برای داده
  • label برای انسان
  • required اختیاری مفید

گام عملی — همین الان

  1. type=email بگذار.

اگر گیر کردی، همان خط کد را با توضیح زیر مثال مقایسه کن.
