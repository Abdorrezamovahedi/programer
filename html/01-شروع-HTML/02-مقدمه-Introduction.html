HTML چیست؟

هدف این درس: بفهمی HTML چیست و نقش آن در ساخت صفحات وب چیست.

مفهوم به زبان خیلی ساده

HTML اسکلت صفحه وب است. با HTML می‌گویی «اینجا یک عنوان است»، «اینجا یک بند متن است»، «اینجا یک تصویر است». ظاهر (رنگ و فونت) کار CSS است. تعامل (کلیک و حرکت) کار JavaScript است. HTML فقط ساختار را مشخص می‌کند.

تگ چیست؟

تقریباً همه چیز در HTML داخل تگ نوشته می‌شود. تگ‌ها معمولاً دوتایی هستند:

<p>این یک بند متن است</p>
توضیح خط‌به‌خط همین مثال
  1. خط 1<p>این یک بند متن است</p>تگ p یک بند متن (پاراگراف) را مشخص می‌کند؛ متن بین باز و بسته قرار می‌گیرد.

ساده‌ترین صفحه HTML

<!DOCTYPE html> <html> <head> <title>صفحه من</title> </head> <body> <h1>سلام دنیا</h1> <p>این اولین صفحه‌ام است.</p> </body> </html>
توضیح خط‌به‌خط همین مثال
  1. خط 1<!DOCTYPE html>به مرورگر می‌گوید این سند از نوع HTML5 است.
  2. خط 2<html>ریشهٔ کل صفحه؛ همه چیز داخل این تگ قرار می‌گیرد.
  3. خط 3<head>اطلاعات صفحه (مثل عنوان تب) اینجا نوشته می‌شود.
  4. خط 4<title>صفحه من</title>عنوان صفحه را برای تب مرورگر مشخص می‌کند.
  5. خط 5</head>پایان بخش head.
  6. خط 6<body>محتوای قابل‌مشاهده صفحه از اینجا شروع می‌شود.
  7. خط 7<h1>سلام دنیا</h1>بزرگ‌ترین عنوان صفحه؛ موضوع اصلی را نشان می‌دهد.
  8. خط 8<p>این اولین صفحه‌ام است.</p>یک بند متن ساده برای کاربر.
  9. خط 9</body>پایان محتوای قابل‌مشاهده.
  10. خط 10</html>پایان کل سند HTML.
معیار تمام‌شدن درس: بتوانی با زبان خودت بگویی HTML چیست و یک تگ ساده بنویسی.
جمع‌بندی
  • HTML ساختار صفحه وب را مشخص می‌کند.
  • تقریباً همه چیز داخل تگ نوشته می‌شود.
  • تگ‌ها معمولاً باز و بسته دارند.
  • body محل محتوای اصلی صفحه است.
