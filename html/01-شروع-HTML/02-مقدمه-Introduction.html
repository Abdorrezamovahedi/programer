HTML چیست؟

هدف این درس: بفهمی HTML چیست و نقش آن در ساخت صفحات وب چیست.

مفهوم به زبان خیلی ساده

HTML اسکلت صفحه وب است. با HTML می‌گویی «اینجا یک عنوان است»، «اینجا یک بند متن است»، «اینجا یک تصویر است».
ظاهر (رنگ و فونت) کار CSS است. تعامل (کلیک و حرکت) کار JavaScript است. HTML فقط ساختار را مشخص می‌کند.

تگ چیست؟

تقریباً همه چیز در HTML داخل تگ نوشته می‌شود. تگ‌ها معمولاً دوتایی هستند:

<p>این یک بند متن است</p>
<p> شروع بند
</p> پایان بند
متن بین این دو قرار می‌گیرد.

ساده‌ترین صفحه HTML

<!DOCTYPE html> <html> <head> <title>صفحه من</title> </head> <body> <h1>سلام دنیا</h1> <p>این اولین صفحه‌ام است.</p> </body> </html>
DOCTYPE می‌گوید این یک سند HTML5 است.
head اطلاعات صفحه (مثل عنوان تب مرورگر)
body محتوای قابل مشاهده صفحه
معیار تمام‌شدن درس: بتوانی با زبان خودت بگویی HTML چیست و یک تگ ساده بنویسی.
جمع‌بندی
  • HTML ساختار صفحه وب را مشخص می‌کند
  • تقریباً همه چیز داخل تگ نوشته می‌شود
  • تگ‌ها معمولاً باز و بسته دارند
  • body محل محتوای اصلی صفحه است

گام عملی

  1. یک فایل HTML خیلی ساده با یک عنوان و یک بند بساز.
  2. آن را در مرورگر باز کن و نتیجه را ببین.
