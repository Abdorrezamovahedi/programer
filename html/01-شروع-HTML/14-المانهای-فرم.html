المان‌های فرم

هدف این درس: فرم ساده با label و input و دکمه بسازی.

پوشه: شروع HTML  |  نقش: درس معرفی مبحث

مفهوم به زبان ساده

فرم داده را از کاربر می‌گیرد. name نام فیلد در ارسال است. label دسترسی را بهتر می‌کند.

فهرست معرفی: فرم

همهٔ موارد این مبحث را یک‌جا در کد ببین. هر خط با کامنت توضیح داده شده است.

<!-- اجزای فرم --> <form action="/send" method="get"> <!-- ظرف ارسال --> <label for="n">نام</label> <!-- برچسب فیلد --> <input id="n" name="n" type="text" required> <!-- ورودی؛ name کلید داده --> <button type="submit">ارسال</button> <!-- دکمهٔ ارسال --> </form>

مثال 1: فرم نام

<form action="/x" method="get"> <label for="name">نام</label> <input id="name" name="name" type="text" required> <button type="submit">برو</button> </form>
خط ۱: فرم با ارسال get.
خط ۲: برچسب وصل به id=name.
خط ۳: فیلد متنی اجباری.
خط ۴: دکمهٔ ارسال.

اشتباه رایج مبتدی‌ها

<input type="text">
چرا اشتباه است؟ بدون name و label.
چه می‌بینی؟ داده/دسترسی ضعیف
درست: name و label را بگذار
معیار تمام‌شدن درس: فرم را submit کنی و اثر را در آدرس ببینی (حتی اگر 404 شد).
جمع‌بندی
  • name برای داده
  • label برای انسان
  • required اختیاری مفید

گام عملی — همین الان

  1. type=email بگذار.

اگر گیر کردی، همان خط کد را با توضیح زیر مثال مقایسه کن.
