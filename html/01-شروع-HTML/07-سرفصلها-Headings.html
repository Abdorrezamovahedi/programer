سرفصل‌ها در HTML (h1 تا h6)

هدف: بدانی از چه تگی برای عنوان اصلی و عنوان‌های فرعی استفاده کنی.

مفهوم ساده

سرفصل‌ها عنوان بخش‌های صفحه هستند. h1 مهم‌ترین عنوان صفحه است؛ h2 تا h6 برای زیرعنوان‌ها. معمولاً در هر صفحه یک h1 کافی است.

<h1>عنوان اصلی صفحه</h1> <h2>بخش اول</h2> <p>توضیح بخش اول.</p> <h2>بخش دوم</h2> <h3>زیربخش</h3>
توضیح خط‌به‌خط همین مثال
  1. خط 1<h1>عنوان اصلی صفحه</h1>بزرگ‌ترین عنوان صفحه؛ موضوع اصلی را نشان می‌دهد.
  2. خط 2<h2>بخش اول</h2>عنوان یک بخش فرعی زیر h1.
  3. خط 3<p>توضیح بخش اول.</p>متن توضیحی همان بخش داخل پاراگراف.
  4. خط 4<h2>بخش دوم</h2>عنوان بخش بعدی هم‌سطح با بخش اول.
  5. خط 5<h3>زیربخش</h3>عنوان جزئی‌تر زیر یک h2.
جمع‌بندی
  • از h1 برای موضوع اصلی صفحه استفاده کن.
  • h2 و h3 را برای ساختار منطقی بخش‌ها به کار ببر.
  • سرفصل فقط برای «بزرگ‌کردن متن» نیست؛ معنا و ساختار دارد.
