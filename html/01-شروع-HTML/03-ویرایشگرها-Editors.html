ویرایشگرهای کد

هدف این درس: بدانی برای نوشتن کد از چه برنامه‌ای استفاده کنی.

مفهوم به زبان ساده

می‌توانی HTML را در Notepad هم بنویسی، اما ویرایشگرهای مخصوص کدنویسی کار را خیلی راحت‌تر می‌کنند: رنگ‌بندی کد، پیشنهاد خودکار و تشخیص خطا.

پیشنهاد اصلی: Visual Studio Code

  • رایگان و قدرتمند
  • برای HTML، CSS، JavaScript و Python عالی است
  • افزونه‌های زیادی دارد

از سایت رسمی code.visualstudio.com دانلود کن.

معیار تمام‌شدن درس: یک ویرایشگر نصب کرده باشی و یک فایل HTML در آن ساخته باشی.
جمع‌بندی
  • ویرایشگر مخصوص کدنویسی بهتر از Notepad است
  • VS Code انتخاب محبوب و مناسب مبتدیان است
  • فایل را با پسوند .html ذخیره کن

گام عملی

  1. VS Code (یا ویرایشگر دلخواه) را نصب کن.
  2. یک فایل جدید با پسوند .html بساز و اسکلت ساده HTML را در آن بنویس.
