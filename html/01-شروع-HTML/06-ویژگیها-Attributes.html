ویژگی‌ها (Attributes) در HTML

هدف این درس: بفهمی ویژگی چیست و بتوانی از مهم‌ترین ویژگی‌ها مثل href، src، alt، class و id استفاده کنی.

مفهوم به زبان ساده

ویژگی اطلاعات اضافی به تگ می‌دهد. مثل این که بگویی این لینک به کجا برود، یا این تصویر چه فایلی است.

<a href="https://example.com">متن لینک</a> <img src="photo.jpg" alt="توضیح تصویر">
href آدرس لینک را مشخص می‌کند.
src مسیر فایل تصویر را می‌گوید.
alt متن جایگزین تصویر است (برای دسترسی‌پذیری و سئو مهم است).

class و id

<p class="note">این یک نکته است.</p> <h1 id="main-title">عنوان اصلی</h1>
class برای گروه‌بندی عناصر (می‌تواند روی چند عنصر باشد).
id برای یک عنصر یکتا در صفحه.
معیار تمام‌شدن درس: بتوانی یک لینک و یک تصویر با ویژگی‌های درست بنویسی.
جمع‌بندی
  • ویژگی اطلاعات اضافی به تگ می‌دهد
  • href برای لینک، src و alt برای تصویر
  • class برای گروه، id برای عنصر یکتا

گام عملی

  1. یک لینک به سایت دلخواه با متن مناسب بساز.
  2. یک تصویر با src و alt بنویس (حتی اگر فایل واقعی نداشته باشی).
