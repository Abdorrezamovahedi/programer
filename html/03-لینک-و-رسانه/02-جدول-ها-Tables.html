جدول‌ها در HTML

هدف این درس: بتوانی یک جدول ساده بسازی.

<table> <tr> <th>نام</th> <th>سن</th> </tr> <tr> <td>علی</td> <td>۲۵</td> </tr> </table>
tr ردیف، th سلول عنوان، td سلول داده است.
معیار تمام‌شدن درس: یک جدول دو ستونی با یک ردیف عنوان و یک ردیف داده ساخته باشی.
جمع‌بندی
  • table ظرف اصلی جدول است
  • tr برای هر ردیف
  • th برای عنوان ستون، td برای داده

گام عملی

  1. یک جدول ساده از نام و نمره سه نفر بساز.
