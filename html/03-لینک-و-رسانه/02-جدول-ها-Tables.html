جدول‌ها در HTML

هدف این درس: بتوانی یک جدول ساده بسازی.

<table> <tr> <th>نام</th> <th>سن</th> </tr> <tr> <td>علی</td> <td>۲۵</td> </tr> </table>
توضیح خط‌به‌خط همین مثال
  1. خط 1: <table> — شروع یا استفاده از تگ table در ساختار صفحه.
  2. خط 2: <tr> — شروع یا استفاده از تگ tr در ساختار صفحه.
  3. خط 3: <th>نام</th> — شروع یا استفاده از تگ th در ساختار صفحه.
  4. خط 4: <th>سن</th> — شروع یا استفاده از تگ th در ساختار صفحه.
  5. خط 5: </tr> — پایان تگ tr.
  6. خط 6: <tr> — شروع یا استفاده از تگ tr در ساختار صفحه.
  7. خط 7: <td>علی</td> — شروع یا استفاده از تگ td در ساختار صفحه.
  8. خط 8: <td>۲۵</td> — شروع یا استفاده از تگ td در ساختار صفحه.
  9. خط 9: </tr> — پایان تگ tr.
  10. خط 10: </table> — پایان تگ table.
tr ردیف، th سلول عنوان، td سلول داده است.
معیار تمام‌شدن درس: یک جدول دو ستونی با یک ردیف عنوان و یک ردیف داده ساخته باشی.
جمع‌بندی
  • table ظرف اصلی جدول است
  • tr برای هر ردیف
  • th برای عنوان ستون، td برای داده

گام عملی

  1. یک جدول ساده از نام و نمره سه نفر بساز.
