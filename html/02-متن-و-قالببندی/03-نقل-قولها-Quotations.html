مفهوم به زبان ساده

HTML می‌گوید «این یک بند است». رنگ و اندازه کار CSS است. فعلاً یک نمونهٔ کوچک داخل صفحه کافی است؛ جزئیات کامل در بخش CSS می‌آید.

ساختار (Syntax)

<style> p { color: #333; } </style>

مثال 1: رنگ بند

<style> p { color: #1e293b; line-height: 1.8; } </style> <p>این متن با استایل خواناتر است.</p>
style: قوانین ظاهر در همین صفحه.
p { ... }: همهٔ بندها را هدف می‌گیرد.
color: رنگ متن.

اشتباه رایج مبتدی‌ها

<font color="red">قدیمی</font>
چرا اشتباه است؟ روش قدیمی و منسوخ است.
چه می‌بینی؟ کد تاریخ‌گذشته
درست: از CSS استفاده کن
معیار تمام‌شدن درس: رنگ یک بند را با style عوض کنی و در مرورگر ببینی.
