صدا (Audio)

در HTML، «صدا» بخشی از اسکلت صفحه است. HTML می‌گوید هر چیز چیست؛ ظاهر را CSS می‌دهد.

کجا به درد می‌خورد؟ صفحه وب، فرم، مقاله، تصویر، لینک.

تصویر

src آدرس فایل، alt توضیح.

<img src="photo.jpg" alt="کوه در غروب" width="300">
خط 1: تگ «img»: تصویر؛ src آدرس فایل و alt توضیح است. ویژگی‌ها: src (آدرس فایل) = "photo.jpg"؛ alt (توضیح تصویر اگر نیامد یا برای خوانش صفحه) = "کوه در غروب"؛ width (عرض) = "300".

لینک روی تصویر

img داخل a.

<a href="/gallery"><img src="t.jpg" alt="گالری"></a>
خط 1: تگ «a»: لینک؛ href می‌گوید کجا برود. ویژگی‌ها: href (آدرس مقصد لینک) = "/gallery".

ویدیو

controls دکمه‌ها را می‌آورد.

<video controls width="400"> <source src="a.mp4" type="video/mp4"> مرورگر ویدیو ندارد. </video>
خط 1: تگ «video»: پخش ویدیو. ویژگی‌ها: controls (دکمه‌های پخش را نشان بده) = بدون مقدار؛ width (عرض) = "400".
خط 2: تگ «source»: عنصر source. ویژگی‌ها: src (آدرس فایل) = "a.mp4"؛ type (نوع فیلد یا دکمه) = "video/mp4".
خط 3: متن داخل صفحه است و کاربر همان را می‌بیند: «مرورگر ویدیو ندارد.».
خط 4: تگ بسته «video» یعنی جعبهٔ video تمام شد. بدون بستن، تگ بعدی ممکن است قاطی شود.

صدا

مشابه ویدیو.

<audio controls src="a.mp3">صدا پشتیبانی نمی‌شود</audio>
خط 1: تگ «audio»: پخش صدا. ویژگی‌ها: controls (دکمه‌های پخش را نشان بده) = بدون مقدار؛ src (آدرس فایل) = "a.mp3". متن داخل تگ که کاربر می‌بیند: «صدا پشتیبانی نمی‌شود».

figure

تصویر با زیرنویس.

<figure> <img src="c.jpg" alt="نمودار فروش"> <figcaption>فروش ۱۴۰۴</figcaption> </figure>
خط 1: تگ «figure»: عنصر figure.
خط 2: تگ «img»: تصویر؛ src آدرس فایل و alt توضیح است. ویژگی‌ها: src (آدرس فایل) = "c.jpg"؛ alt (توضیح تصویر اگر نیامد یا برای خوانش صفحه) = "نمودار فروش".
خط 3: تگ «figcaption»: عنصر figcaption. متن داخل تگ که کاربر می‌بیند: «فروش ۱۴۰۴».
خط 4: تگ بسته «figure» یعنی جعبهٔ figure تمام شد. بدون بستن، تگ بعدی ممکن است قاطی شود.
تگ‌ها را تودرتوی درست ببند. متن غلط است.

اگر این درس سخت بود، درس قبلی همان زبان را یک‌بار دیگر بخوان. بعد همین «صدا» را با تغییر عدد یا متن مثال دوباره اجرا کن.

جمع‌بندی سریع
  • HTML ساختار است؛ «صدا» یک قطعه از آن.
  • تگ باز معمولاً بسته هم دارد.
  • ویژگی مثل href و alt معنی می‌دهند.
  • صفحه را در مرورگر باز کن نه فقط در ذهن.
  • ظاهر را بعداً با CSS بده.
