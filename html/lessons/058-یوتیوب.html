یوتیوب

در HTML، «یوتیوب» بخشی از اسکلت صفحه است. HTML می‌گوید هر چیز چیست؛ ظاهر را CSS می‌دهد.

کجا به درد می‌خورد؟ صفحه وب، فرم، مقاله، تصویر، لینک.

یوتیوب چیست

این درس درباره «یوتیوب» در HTML است. تگ می‌گوید این قطعه چه نقشی دارد.

<!DOCTYPE html> <html lang="fa" dir="rtl"> <body> <h1>یوتیوب</h1> <p>متن نمونه برای این درس.</p> </body> </html>
خط 1: به مرورگر می‌گوید این سند HTML5 است تا با قوانین قدیمی اشتباه گرفته نشود.
خط 2: تگ «html»: ریشه کل صفحه. ویژگی‌ها: lang (زبان صفحه) = "fa"؛ dir (جهت متن؛ rtl برای فارسی) = "rtl".
خط 3: تگ «body»: هر چیزی که کاربر می‌بیند داخل body است.
خط 4: تگ «h1»: بزرگ‌ترین عنوان صفحه؛ معمولاً یکی در هر صفحه. متن داخل تگ که کاربر می‌بیند: «یوتیوب».
خط 5: تگ «p»: یک پاراگراف متن. متن داخل تگ که کاربر می‌بیند: «متن نمونه برای این درس.».
خط 6: تگ بسته «body» یعنی جعبهٔ body تمام شد. بدون بستن، تگ بعدی ممکن است قاطی شود.
خط 7: تگ بسته «html» یعنی جعبهٔ html تمام شد. بدون بستن، تگ بعدی ممکن است قاطی شود.

مثال با چند تگ

عنوان، پاراگراف، لینک، فهرست.

<h2>فهرست کارها</h2> <ul> <li>خواندن درس</li> <li><a href="#ex">مثال</a></li> </ul>
خط 1: تگ «h2»: عنوان بخش. متن داخل تگ که کاربر می‌بیند: «فهرست کارها».
خط 2: تگ «ul»: فهرست نقطه‌ای.
خط 3: تگ «li»: یک آیتم فهرست. متن داخل تگ که کاربر می‌بیند: «خواندن درس».
خط 4: تگ «li»: یک آیتم فهرست.
خط 5: تگ بسته «ul» یعنی جعبهٔ ul تمام شد. بدون بستن، تگ بعدی ممکن است قاطی شود.

ویژگی‌های رایج

class برای CSS، id برای پرش و اسکریپت.

<div id="box" class="card">محتوا</div> <p hidden>مخفی</p>
خط 1: تگ «div»: جعبه عمومی برای چیدمان. ویژگی‌ها: id (شناسه یکتا در صفحه) = "box"؛ class (گروه برای استایل CSS) = "card". متن داخل تگ که کاربر می‌بیند: «محتوا».
خط 2: تگ «p»: یک پاراگراف متن. ویژگی‌ها: hidden (ویژگی hidden) = بدون مقدار. متن داخل تگ که کاربر می‌بیند: «مخفی».

متن معنایی

تگ درست به معنی کمک می‌کند نه فقط ظاهر.

<header>سرصفحه</header> <main> <article>مقاله</article> </main> <footer>پاورقی</footer>
خط 1: تگ «header»: سرصفحه معنایی. متن داخل تگ که کاربر می‌بیند: «سرصفحه».
خط 2: تگ «main»: محتوای اصلی.
خط 3: تگ «article»: یک مطلب مستقل. متن داخل تگ که کاربر می‌بیند: «مقاله».
خط 4: تگ بسته «main» یعنی جعبهٔ main تمام شد. بدون بستن، تگ بعدی ممکن است قاطی شود.
خط 5: تگ «footer»: پاورقی. متن داخل تگ که کاربر می‌بیند: «پاورقی».

لیست و جدول کوچک

داده را ساخت‌یافته بگذار.

<table> <tr><th>نام</th><th>نمره</th></tr> <tr><td>علی</td><td>18</td></tr> </table>
خط 1: تگ «table»: جدول.
خط 2: تگ «tr»: یک ردیف جدول.
خط 3: تگ «tr»: یک ردیف جدول.
خط 4: تگ بسته «table» یعنی جعبهٔ table تمام شد. بدون بستن، تگ بعدی ممکن است قاطی شود.

اشتباه رایج

تگ را نبند یا dir را نگذار؛ فارسی به‌هم می‌ریزد.

<html lang="fa" dir="rtl"> <body><p>متن راست‌چین</p></body> </html>
خط 1: تگ «html»: ریشه کل صفحه. ویژگی‌ها: lang (زبان صفحه) = "fa"؛ dir (جهت متن؛ rtl برای فارسی) = "rtl".
خط 2: تگ «body»: هر چیزی که کاربر می‌بیند داخل body است.
خط 3: تگ بسته «html» یعنی جعبهٔ html تمام شد. بدون بستن، تگ بعدی ممکن است قاطی شود.
تگ‌ها را تودرتوی درست ببند. متن غلط است.

اگر این درس سخت بود، درس قبلی همان زبان را یک‌بار دیگر بخوان. بعد همین «یوتیوب» را با تغییر عدد یا متن مثال دوباره اجرا کن.

جمع‌بندی سریع
  • HTML ساختار است؛ «یوتیوب» یک قطعه از آن.
  • تگ باز معمولاً بسته هم دارد.
  • ویژگی مثل href و alt معنی می‌دهند.
  • صفحه را در مرورگر باز کن نه فقط در ذهن.
  • ظاهر را بعداً با CSS بده.
