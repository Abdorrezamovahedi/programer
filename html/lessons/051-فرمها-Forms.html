فرم‌ها (Forms)

در HTML، «فرم‌ها» بخشی از اسکلت صفحه است. HTML می‌گوید هر چیز چیست؛ ظاهر را CSS می‌دهد.

کجا به درد می‌خورد؟ صفحه وب، فرم، مقاله، تصویر، لینک.

فرم چیست

جعبهٔ گرفتن داده از کاربر.

<form action="/save" method="post"> <label>نام <input name="name" required></label> <button>ارسال</button> </form>
خط 1: تگ «form»: فرم فرستادن داده. ویژگی‌ها: action (کجا فرم فرستاده شود) = "/save"؛ method (روش ارسال get یا post) = "post".
خط 2: تگ «label»: برچسب فیلد؛ کلیک روی آن فیلد را انتخاب می‌کند. متن داخل تگ که کاربر می‌بیند: «نام ».
خط 3: تگ «button»: دکمه. متن داخل تگ که کاربر می‌بیند: «ارسال».
خط 4: تگ بسته «form» یعنی جعبهٔ form تمام شد. بدون بستن، تگ بعدی ممکن است قاطی شود.

انواع input

type رفتار را عوض می‌کند.

<input type="text"> <input type="email"> <input type="password"> <input type="number" min="1">
خط 1: تگ «input»: فیلد ورودی کاربر. ویژگی‌ها: type (نوع فیلد یا دکمه) = "text".
خط 2: تگ «input»: فیلد ورودی کاربر. ویژگی‌ها: type (نوع فیلد یا دکمه) = "email".
خط 3: تگ «input»: فیلد ورودی کاربر. ویژگی‌ها: type (نوع فیلد یا دکمه) = "password".
خط 4: تگ «input»: فیلد ورودی کاربر. ویژگی‌ها: type (نوع فیلد یا دکمه) = "number"؛ min (ویژگی min) = "1".

انتخاب

radio یکی، checkbox چندتا.

<label><input type="radio" name="sex" value="f"> زن</label> <label><input type="checkbox" name="ok"> موافقم</label>
خط 1: تگ «label»: برچسب فیلد؛ کلیک روی آن فیلد را انتخاب می‌کند.
خط 2: تگ «label»: برچسب فیلد؛ کلیک روی آن فیلد را انتخاب می‌کند.

textarea و select

متن بلند و منو.

<textarea name="msg" rows="4"></textarea> <select name="city"> <option value="th">تهران</option> </select>
خط 1: تگ «textarea»: جعبه متن چندخطی. ویژگی‌ها: name (کلید داده وقتی فرم ارسال می‌شود) = "msg"؛ rows (ویژگی rows) = "4".
خط 2: تگ «select»: منوی کشویی. ویژگی‌ها: name (کلید داده وقتی فرم ارسال می‌شود) = "city".
خط 3: تگ «option»: یک گزینه منو. ویژگی‌ها: value (مقدار ارسالی یا اولیه) = "th". متن داخل تگ که کاربر می‌بیند: «تهران».
خط 4: تگ بسته «select» یعنی جعبهٔ select تمام شد. بدون بستن، تگ بعدی ممکن است قاطی شود.

دسترسی

label را به id وصل کن.

<label for="e">ایمیل</label> <input id="e" type="email" name="email">
خط 1: تگ «label»: برچسب فیلد؛ کلیک روی آن فیلد را انتخاب می‌کند. ویژگی‌ها: for (این برچسب مال کدام id است) = "e". متن داخل تگ که کاربر می‌بیند: «ایمیل».
خط 2: تگ «input»: فیلد ورودی کاربر. ویژگی‌ها: id (شناسه یکتا در صفحه) = "e"؛ type (نوع فیلد یا دکمه) = "email"؛ name (کلید داده وقتی فرم ارسال می‌شود) = "email".
تگ‌ها را تودرتوی درست ببند. متن غلط است.

اگر این درس سخت بود، درس قبلی همان زبان را یک‌بار دیگر بخوان. بعد همین «فرم‌ها» را با تغییر عدد یا متن مثال دوباره اجرا کن.

جمع‌بندی سریع
  • HTML ساختار است؛ «فرم‌ها» یک قطعه از آن.
  • تگ باز معمولاً بسته هم دارد.
  • ویژگی مثل href و alt معنی می‌دهند.
  • صفحه را در مرورگر باز کن نه فقط در ذهن.
  • ظاهر را بعداً با CSS بده.
