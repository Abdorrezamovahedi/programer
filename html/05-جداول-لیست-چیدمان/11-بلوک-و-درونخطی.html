بلوک و درون‌خطی

هدف این درس: با class و id به بخش‌ها نام بدهی و اسکلت معنایی صفحه را بشناسی.

پوشه: جداول لیست چیدمان  |  پیش‌نیاز: درس‌های قبلی همین پوشه («جداول لیست چیدمان») را با تایپ و اجرا خوانده باشی.

مفهوم به زبان ساده

class برچسبی است که می‌توانی روی چند عنصر بگذاری (برای استایل مشترک). id نام یکتای یک عنصر در صفحه است. بهتر است به‌جای جعبهٔ بی‌معنی، از تگ‌هایی مثل header و main استفاده کنی که نقش بخش را می‌گویند.

ساختار (Syntax)

class="card" id="main" <header> <main> <footer>

مثال 1: اسکلت صفحه

<header><h1>سایت من</h1></header> <nav><a href="/">خانه</a></nav> <main id="content"><p class="intro">متن خوش‌آمد</p></main> <footer>پایان صفحه</footer>
header: بالای صفحه.
nav: لینک‌های جابه‌جایی.
main: محتوای اصلی.
class=intro: برچسب برای استایل بعدی.
id=content: نام یکتا برای هدف لینک یا اسکریپت.

اشتباه رایج مبتدی‌ها

<div id="x"></div><div id="x"></div>
چرا اشتباه است؟ id نباید تکرار شود.
چه می‌بینی؟ رفتار لینک و اسکریپت مبهم می‌شود
درست: هر id فقط یک‌بار؛ برای گروه از class استفاده کن
معیار تمام‌شدن درس: اسکلت header / main / footer با یک class روی یک بند بنویسی.
جمع‌بندی
  • class قابل تکرار
  • id یکتا
  • تگ معنایی بهتر از div خالی

گام عملی — همین الان

  1. از یک لینک #content به main بپر.
