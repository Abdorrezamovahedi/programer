خانه تمرین

تمرین‌های عملی

هر تمرین صورت‌مسئله، مثال، خروجی مورد انتظار و راهنمای مرحله‌ای دارد. جواب آماده وجود ندارد.

Python ۲۵ تمرین HTML ۱۰ تمرین CSS ۸ تمرین JavaScript ۱۰ تمرین PHP ۸ تمرین

چطور از تمرین‌ها استفاده کنم؟

  1. زبان مورد نظرت را انتخاب کن.
  2. یک تمرین را باز کن و صورت مسئله را بخوان.
  3. به بخش مثال و خروجی مورد انتظار نگاه کن تا دقیقاً بفهمی چه چیزی باید بسازی.
  4. خودت حل کن. اگر گیر کردی، راهنماهای مرحله‌ای را باز کن.

چطور یک تمرین را ویرایش کنم؟ (برای مدیر سایت)

  1. پوشه زبان را باز کن، مثلاً tamrin/python/
  2. فایل مربوط به همان تمرین را پیدا کن.
  3. متن صورت‌مسئله، مثال یا راهنماها را مستقیم در HTML عوض کن.

نیازی به دانستن جاوااسکریپت نیست.
