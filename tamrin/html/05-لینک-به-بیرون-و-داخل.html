صورت مسئله

دو لینک بگذار: یکی به یک سایت واقعی (مثلاً example.com) و یکی به بخش پایین همین صفحه با #. برای بخش پایین یک id بگذار تا لینک جایی برای پریدن داشته باشد.

لینک داخلی و خارجی

حداقل دو لینک کار کند.

راهنماهای مرحله‌ای (ابتدا خودت تلاش کن)
  1. برای لینک خارجی، آدرس کامل را در href بگذار و متن قابل‌کلیک را بین تگ a بنویس.
  2. برای پرش داخل صفحه، یک id روی مقصد بگذار و لینک را به #همان_id وصل کن.
  3. اگر لینک داخلی کار نکرد، املای id و href را حرف‌به‌حرف یکی کن.
