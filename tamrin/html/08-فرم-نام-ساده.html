8. فرم نام ساده

آسان  |  موضوع: فرم  |  شناسه: html-8

صورت مسئله

فرمی بساز که یک فیلد نام داشته باشد، label درست به آن وصل باشد، و دکمهٔ ارسال هم دیده شود. روی input حتماً name بگذار تا اگر فرم ارسال شد، داده اسم داشته باشد.

راهنماهای مرحله‌ای (ابتدا خودت تلاش کن)
  1. label را با for به id همان input وصل کن تا کلیک روی متن هم فیلد را فعال کند.
  2. name روی input برای این است که داده در ارسال، اسم داشته باشد.
  3. دکمه را type=submit بگذار اگر می‌خواهی نقش «ارسال» داشته باشد.
