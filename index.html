    3. وقتی آماده بودی برو سراغ تمرین‌ها.

    📌 درس‌های پین‌شده

    MCD Code Up مجموعه‌ای از آموزش‌های رایگان فارسی برای یادگیری برنامه‌نویسی است. درس‌ها بر اساس موضوع دسته‌بندی شده‌اند تا بتوانی از مبانی شروع کنی، نمونه‌کدها را با توضیح خط‌به‌خط بررسی کنی و آموخته‌هایت را در بخش تمرین محک بزنی.

    مطالب این سایت دربارهٔ Python، HTML، CSS، JavaScript و PHP است. برای شروع، یک مسیر یادگیری را انتخاب کن و درس‌ها را به‌ترتیب پیش ببر. همهٔ متن‌ها طوری نوشته شده‌اند که حتی اگر تازه با کامپیوتر آشنا شده باشی، بتوانی مفهوم را کامل بفهمی.
