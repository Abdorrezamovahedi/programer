1. حاشیه

حاشیه (Border) در CSS

هدف این درس: بتوانی حاشیه به عناصر اضافه کنی.

.box { border-width: 2px; border-style: solid; border-color: #0f172a; } /* یا کوتاه‌نویسی: */ .box2 { border: 2px solid #0f172a; }
سه ویژگی اصلی: ضخامت، سبک (solid, dashed, dotted) و رنگ.
معیار تمام‌شدن درس: یک جعبه با حاشیه ساخته باشی.
جمع‌بندی
  • border-width ضخامت
  • border-style سبک خط
  • border-color رنگ
  • می‌توان با یک ویژگی border همه را نوشت

گام عملی

  1. یک div با حاشیه solid و یک div با حاشیه dashed بساز.
