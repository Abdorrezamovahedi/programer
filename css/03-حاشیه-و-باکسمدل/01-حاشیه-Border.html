1. حاشیه

حاشیه (Border) در CSS

هدف این درس: بتوانی حاشیه به عناصر اضافه کنی.

.box { border-width: 2px; border-style: solid; border-color: #0f172a; } /* یا کوتاه‌نویسی: */ .box2 { border: 2px solid #0f172a; }
توضیح خط‌به‌خط همین مثال
  1. خط 1: .box { — یک انتخابگر را باز می‌کند تا استایل‌هایش را بنویسیم.
  2. خط 2: border-width: 2px; — ویژگی «border-width» را مقداردهی می‌کند.
  3. خط 3: border-style: solid; — ویژگی «border-style» را مقداردهی می‌کند.
  4. خط 4: border-color: #0f172a; — ویژگی «border-color» را مقداردهی می‌کند.
  5. خط 5: } — پایان بلوک استایل.
  6. خط 6: /* یا کوتاه‌نویسی: */ — این خط توضیح (کامنت) است و اجرا نمی‌شود.
  7. خط 7: .box2 { — یک انتخابگر را باز می‌کند تا استایل‌هایش را بنویسیم.
  8. خط 8: border: 2px solid #0f172a; — ویژگی «border» را مقداردهی می‌کند.
  9. خط 9: } — پایان بلوک استایل.
سه ویژگی اصلی: ضخامت، سبک (solid, dashed, dotted) و رنگ.
معیار تمام‌شدن درس: یک جعبه با حاشیه ساخته باشی.
جمع‌بندی
  • border-width ضخامت
  • border-style سبک خط
  • border-color رنگ
  • می‌توان با یک ویژگی border همه را نوشت

گام عملی

  1. یک div با حاشیه solid و یک div با حاشیه dashed بساز.
