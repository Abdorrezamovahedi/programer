حاشیه خارجی (Margin)

هدف این درس: بتوانی فاصله خارجی بین عناصر ایجاد کنی.

.box { margin: 1rem; } .card { margin-bottom: 1.5rem; }
توضیح خط‌به‌خط همین مثال
  1. خط 1: .box { — یک انتخابگر را باز می‌کند تا استایل‌هایش را بنویسیم.
  2. خط 2: margin: 1rem; — ویژگی «margin» را مقداردهی می‌کند.
  3. خط 3: } — پایان بلوک استایل.
  4. خط 4: .card { — یک انتخابگر را باز می‌کند تا استایل‌هایش را بنویسیم.
  5. خط 5: margin-bottom: 1.5rem; — ویژگی «margin-bottom» را مقداردهی می‌کند.
  6. خط 6: } — پایان بلوک استایل.
margin فاصله بیرون از حاشیه عنصر است و عناصر را از هم جدا می‌کند.
معیار تمام‌شدن درس: چند عنصر با margin از هم جدا کرده باشی.
جمع‌بندی
  • margin فاصله خارجی است
  • padding فاصله داخلی است
  • می‌توان برای هر طرف جداگانه مقدار داد

گام عملی

  1. دو جعبه بساز و با margin بین آن‌ها فاصله ایجاد کن.
