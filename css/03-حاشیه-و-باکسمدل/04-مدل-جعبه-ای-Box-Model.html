مدل جعبه‌ای (Box Model)

هدف این درس: بفهمی هر عنصر از چه لایه‌هایی تشکیل شده است.

هر عنصر مثل یک جعبه است با این لایه‌ها از داخل به خارج:

  • content — محتوا (متن یا تصویر)
  • padding — فاصله داخلی
  • border — حاشیه
  • margin — فاصله خارجی
.box { width: 200px; padding: 20px; border: 5px solid #333; margin: 10px; }
معیار تمام‌شدن درس: بتوانی تفاوت padding و margin را توضیح بدهی.
جمع‌بندی
  • مدل جعبه‌ای پایه درک اندازه و فاصله عناصر است
  • عرض نهایی = content + padding + border (+ گاهی margin)

گام عملی

  1. یک جعبه با هر چهار لایه بساز و در مرورگر Inspect کن.
