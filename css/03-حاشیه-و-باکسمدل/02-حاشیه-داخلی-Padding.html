حاشیه داخلی (Padding)

هدف این درس: بفهمی padding چیست و بتوانی فاصله داخلی ایجاد کنی.

.card { padding: 1rem; border: 1px solid #cbd5e1; } .box { padding: 10px 20px; /* بالا-پایین | چپ-راست */ }
توضیح خط‌به‌خط همین مثال
  1. خط 1: .card { — یک انتخابگر را باز می‌کند تا استایل‌هایش را بنویسیم.
  2. خط 2: padding: 1rem; — ویژگی «padding» را مقداردهی می‌کند.
  3. خط 3: border: 1px solid #cbd5e1; — ویژگی «border» را مقداردهی می‌کند.
  4. خط 4: } — پایان بلوک استایل.
  5. خط 5: .box { — یک انتخابگر را باز می‌کند تا استایل‌هایش را بنویسیم.
  6. خط 6: padding: 10px 20px; /* بالا-پایین | چپ-راست */ — ویژگی «padding» را مقداردهی می‌کند.
  7. خط 7: } — پایان بلوک استایل.
padding فاصله بین محتوا و لبه (یا حاشیه) عنصر است.
معیار تمام‌شدن درس: یک جعبه با padding مناسب ساخته باشی.
جمع‌بندی
  • padding فاصله داخلی است
  • می‌توان یک مقدار یا چهار مقدار (بالا راست پایین چپ) داد

گام عملی

  1. یک کارت با padding و border بساز.
