عرض و ارتفاع در CSS

هدف این درس: بتوانی عرض و ارتفاع عناصر را تنظیم کنی.

.box { width: 300px; height: 150px; background: #e2e8f0; }
توضیح خط‌به‌خط همین مثال
  1. خط 1: .box { — یک انتخابگر را باز می‌کند تا استایل‌هایش را بنویسیم.
  2. خط 2: width: 300px; — ویژگی «width» را مقداردهی می‌کند.
  3. خط 3: height: 150px; — ویژگی «height» را مقداردهی می‌کند.
  4. خط 4: background: #e2e8f0; — ویژگی «background» را مقداردهی می‌کند.
  5. خط 5: } — پایان بلوک استایل.
می‌توان از px، % یا واحدهای دیگر استفاده کرد.
معیار تمام‌شدن درس: یک جعبه با عرض و ارتفاع مشخص ساخته باشی.
جمع‌بندی
  • width عرض را مشخص می‌کند
  • height ارتفاع را مشخص می‌کند
