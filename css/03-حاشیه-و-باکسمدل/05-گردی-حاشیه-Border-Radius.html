حاشیه و باکس‌مدل

4. مدل جعبه‌ای 5. Border Radius

گرد کردن گوشه‌ها (Border Radius)

هدف این درس: بتوانی گوشه‌های عناصر را گرد کنی.

.card { border-radius: 8px; } .circle { border-radius: 50%; width: 80px; height: 80px; }
با ۵۰٪ می‌توانی شکل دایره بسازی (اگر عرض و ارتفاع برابر باشند).
معیار تمام‌شدن درس: یک کارت با گوشه گرد و یک دایره ساخته باشی.
جمع‌بندی
  • border-radius گوشه‌ها را گرد می‌کند
  • می‌توان برای هر گوشه مقدار جدا داد
  • ۵۰٪ برای دایره کامل مفید است

گام عملی

  1. یک دکمه با گوشه‌های گرد بساز.
