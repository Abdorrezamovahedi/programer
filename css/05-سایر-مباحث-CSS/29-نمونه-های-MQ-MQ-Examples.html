مفهوم به زبان ساده

در این درس فقط «نمونه های MQ» را تمرین می‌کنی. یک کلاس بساز، مقدار را عوض کن، نتیجه را در مرورگر ببین. ابزار توسعه‌دهنده (F12) بهترین دوست توست.

ساختار (Syntax)

selector { property: value; }

مثال 1: جعبهٔ آزمایش

.demo { /* نمونه های MQ */ padding: 0.75rem; border-radius: 8px; border: 1px solid #cbd5e1; }

padding: فاصله داخلی قابل‌دیدن.
radius: گوشه گرد.
