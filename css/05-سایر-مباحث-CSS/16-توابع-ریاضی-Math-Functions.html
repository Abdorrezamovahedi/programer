توابع ریاضی (Math Functions)

هدف این درس: ویژگی مربوط به «توابع ریاضی» را روی یک بخش صفحه آزمایش کنی.

پوشه: سایر مباحث CSS  |  پیش‌نیاز: درس‌های قبلی همین پوشه («سایر مباحث CSS») را با تایپ و اجرا خوانده باشی.

مفهوم به زبان ساده

در این درس فقط «توابع ریاضی» را تمرین می‌کنی. یک کلاس بساز، مقدار را عوض کن، نتیجه را در مرورگر ببین. ابزار توسعه‌دهنده (F12) بهترین دوست توست.

ساختار (Syntax)

selector { property: value; }

مثال 1: جعبهٔ آزمایش

.demo { /* توابع ریاضی */ padding: 0.75rem; border-radius: 8px; border: 1px solid #cbd5e1; }
توضیح خط‌به‌خط همین مثال
  1. خط 1: .demo { — یک انتخابگر را باز می‌کند تا استایل‌هایش را بنویسیم.
  2. خط 2: /* توابع ریاضی */ — این خط توضیح (کامنت) است و اجرا نمی‌شود.
  3. خط 3: padding: 0.75rem; — ویژگی «padding» را مقداردهی می‌کند.
  4. خط 4: border-radius: 8px; — ویژگی «border-radius» را مقداردهی می‌کند.
  5. خط 5: border: 1px solid #cbd5e1; — ویژگی «border» را مقداردهی می‌کند.
  6. خط 6: } — پایان بلوک استایل.
.demo: هدف تمرین.
padding: فاصله داخلی قابل‌دیدن.
radius: گوشه گرد.
