توضیحات (کامنت) در CSS

هدف این درس: یاد بگیری چطور در CSS توضیح بنویسی تا کد خواناتر شود و بعداً خودت یا دیگران آن را بفهمید.

مفهوم به زبان ساده

کامنت مثل یادداشت کنار دفتر است. مرورگر آن را نمی‌خواند و هیچ تأثیری روی ظاهر صفحه ندارد. فقط برای انسان نوشته می‌شود.

شکل نوشتن کامنت در CSS

/* این یک توضیح است */ p { color: #1e293b; /* رنگ متن تیره */ /* line-height: 1.8; این خط فعلاً غیرفعال است */ }
شروع کامنت: با /*
پایان کامنت: با */
هر چیزی بین این دو علامت نادیده گرفته می‌شود.

چرا کامنت می‌نویسیم؟

  • یادآوری برای خودت بعد از چند ماه
  • توضیح بخش‌های پیچیده برای دیگران
  • غیرفعال کردن موقت یک خط بدون پاک کردن آن

اشتباه رایج

// این کامنت در CSS کار نمی‌کند p { color: red; }
مشکل: علامت // مخصوص JavaScript و برخی زبان‌های دیگر است. در CSS کار نمی‌کند و ممکن است باعث خطا شود.
درست: همیشه از /* ... */ استفاده کن.
معیار تمام‌شدن درس: بتوانی حداقل دو کامنت مفید در یک فایل CSS بنویسی.
جمع‌بندی
  • کامنت با /* شروع و با */ تمام می‌شود
  • مرورگر کامنت را نادیده می‌گیرد
  • برای توضیح و غیرفعال کردن موقت کد عالی است
  • از // در CSS استفاده نکن

گام عملی

  1. بالای یک قانون CSS یک کامنت بنویس که بگوید این قانون برای چیست.
  2. یک ویژگی را با کامنت موقتاً غیرفعال کن و ببین چه تغییری در صفحه ایجاد می‌شود.
