توضیحات (Comments)

هدف این درس: با کامنت در CSS کد را برای خودت و دیگران قابل‌فهم‌تر کن.

پوشه: شروع CSS  |  نقش: درس معرفی مبحث

مفهوم به زبان ساده

کامنت متنی است که مرورگر نادیده می‌گیرد. فقط برای انسان نوشته می‌شود تا بداند این بخش کد چه کاری می‌کند. در CSS کامنت بین /* و */ قرار می‌گیرد.

فهرست معرفی: کامنت

/* این یک کامنت است و اجرا نمی‌شود */ .header { background: #0f172a; /* رنگ تیره برای هدر */ color: white; } /* کامنت چندخطی می‌تواند چند خط باشد */
/* ... */: هر چیزی بین این دو علامت نادیده گرفته می‌شود.
کاربرد: توضیح بخش‌ها، غیرفعال کردن موقت یک قانون، یادداشت برای آینده.

مثال 1: توضیح بخش‌های صفحه

/* ===== هدر ===== */ .header { padding: 1rem; } /* ===== محتوای اصلی ===== */ .main { max-width: 800px; } /* دکمه را فعلاً غیرفعال کردم .btn { background: red; } */
نکته: با کامنت می‌توانی موقتاً کدی را خاموش کنی بدون اینکه پاکش کنی.

اشتباه رایج مبتدی‌ها

// این کامنت جاوااسکریپت است .header { color: red; }
چرا اشتباه است؟ در CSS از // استفاده نمی‌شود.
چه می‌بینی؟ ممکن است کل قانون خراب شود.
درست: فقط از /* */ استفاده کن.
معیار تمام‌شدن درس: حداقل دو کامنت مفید در کد خودت بنویسی.
جمع‌بندی
  • کامنت با /* شروع و با */ تمام می‌شود
  • مرورگر کامنت را اجرا نمی‌کند
  • برای توضیح و غیرفعال کردن موقت مفید است

گام عملی — همین الان

  1. یک قانون CSS بنویس و بالای آن کامنت توضیح بگذار.
  2. یکی از ویژگی‌ها را با کامنت موقتاً خاموش کن.

اگر گیر کردی، همان خط کد را با توضیح زیر مثال مقایسه کن.
