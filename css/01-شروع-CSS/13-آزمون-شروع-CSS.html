آزمون شروع CSS

هدف: مفاهیم اصلی بخش شروع CSS را مرور و خودت را محک بزنی.

سؤالات مروری

  1. CSS چه کاری انجام می‌دهد؟
  2. ساختار یک قانون CSS چگونه است؟
  3. تفاوت انتخاب‌گر کلاس و آیدی چیست؟
  4. بهترین روش اتصال CSS به HTML کدام است؟
  5. چرا ; و } مهم هستند؟
اگر توانستی به این سؤالات پاسخ بدهی، بخش شروع CSS را خوب فهمیده‌ای و آماده رفتن به مباحث بعدی هستی.
