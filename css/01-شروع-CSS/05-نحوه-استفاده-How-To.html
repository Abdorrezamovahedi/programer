نحوه استفاده از CSS

هدف این درس: سه روش نوشتن CSS را بشناسی و بدانی کدام روش برای پروژه‌های واقعی بهتر است.

مفهوم به زبان ساده

CSS را می‌توانی به سه شکل به صفحه وصل کنی. مثل این است که رنگ خانه را از سه جا بخری: از فروشگاه جدا، از داخل خانه، یا فقط روی یک دیوار.

روش ۱: فایل خارجی (بهترین روش)

یک فایل جدا با پسوند .css می‌سازی و از HTML به آن لینک می‌دهی.

<!-- در فایل HTML --> <link rel="stylesheet" href="styles.css">
این روش تمیزترین و حرفه‌ای‌ترین است. یک فایل CSS را می‌توانی روی چندین صفحه استفاده کنی.

روش ۲: داخلی (Internal)

کد CSS را داخل تگ <style> در بخش head صفحه می‌نویسی.

<head> <style> p { color: #1e293b; } </style> </head>
برای صفحه‌های تک‌نفره یا تست سریع مناسب است، اما برای سایت بزرگ توصیه نمی‌شود.

روش ۳: درون‌خطی (Inline)

استایل را مستقیماً روی خود تگ می‌نویسی.

<p style="color: red; font-size: 1.2rem;">متن نمونه</p>
فقط برای تغییرات خیلی کوچک و موقت استفاده کن. در پروژه‌های واقعی کمتر از آن استفاده می‌شود.

کدام روش را انتخاب کنیم؟

  • پروژه واقعی و چندصفحه‌ای: همیشه فایل خارجی
  • تست سریع یک ایده: داخلی یا درون‌خطی
  • اولویت: خارجی > داخلی > درون‌خطی
معیار تمام‌شدن درس: بتوانی یک فایل CSS خارجی بسازی و آن را با تگ link به HTML وصل کنی.
جمع‌بندی
  • سه روش: خارجی، داخلی، درون‌خطی
  • فایل خارجی بهترین و تمیزترین روش است
  • با <link rel="stylesheet" href="..."> فایل را وصل می‌کنی
  • درون‌خطی را فقط در موارد خاص استفاده کن

گام عملی

  1. یک فایل به نام style.css بساز و یک قانون ساده در آن بنویس.
  2. آن را با تگ link به صفحه HTML وصل کن و نتیجه را ببین.
