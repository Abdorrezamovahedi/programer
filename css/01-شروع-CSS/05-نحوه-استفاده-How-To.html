نحوه استفاده (How To)

هدف این درس: اولین قانون CSS را بنویسی و رنگ متن را عوض کنی.

پوشه: شروع CSS  |  نقش: درس معرفی مبحث

مفهوم به زبان ساده

CSS ظاهر را کنترل می‌کند. HTML می‌گوید «این بند است»؛ CSS می‌گوید «چه شکلی باشد».

فهرست معرفی: قانون CSS

همهٔ موارد این مبحث را یک‌جا در کد ببین. هر خط با کامنت توضیح داده شده است.

/* یک قانون CSS = انتخاب‌گر + ویژگی‌ها */ p { /* همهٔ بندها */ color: #1e293b; /* رنگ متن */ line-height: 1.8; /* فاصلهٔ خطوط */ font-size: 1.05rem; /* اندازهٔ نوشته */ }
; و }: هر اعلام با ; تمام می‌شود؛ بلوک با } بسته می‌شود.

مثال 1: اعمال روی صفحه

p { color: #0f172a; background-color: #f8fafc; }
خط ۱: هدف: همهٔ pها.
خط ۲: رنگ متن تیره.
خط ۳: پس‌زمینه روشن برای خوانایی.

اشتباه رایج مبتدی‌ها

p { color: red
چرا اشتباه است؟ } یا ; ناقص است.
چه می‌بینی؟ استایل نمی‌آید
درست: p { color: red; }
معیار تمام‌شدن درس: رنگ یک بند را در مرورگر عوض‌شده ببینی.
جمع‌بندی
  • انتخاب‌گر + بلوک
  • color برای متن
  • کامل بنویس

گام عملی — همین الان

  1. font-size را بزرگ‌تر کن.

اگر گیر کردی، همان خط کد را با توضیح زیر مثال مقایسه کن.
