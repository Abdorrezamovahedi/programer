نحو نگارش CSS (Syntax)

هدف این درس: ساختار درست یک قانون CSS را کامل بفهمی و بتوانی بدون اشتباه بنویسی.

پوشه: شروع CSS  |  نقش: یادگیری ساختار رسمی قانون

مفهوم به زبان ساده

نحو نگارش یعنی «قوانین نوشتن». مثل دستور زبان در فارسی. اگر نقطه یا ویرگول را اشتباه بگذاری، جمله معنی‌اش را از دست می‌دهد. در CSS هم اگر نقطه‌ویرگول یا آکولاد را فراموش کنی، مرورگر قانون را نادیده می‌گیرد.

ساختار کامل یک قانون CSS

هر قانون CSS دقیقاً از این قسمت‌ها تشکیل شده:

انتخاب‌گر { ویژگی: مقدار; ویژگی: مقدار; }
  • انتخاب‌گر — مشخص می‌کند روی کدام عنصر کار می‌کنی (مثلاً p یا h1)
  • آکولاد باز { — شروع بلوک ویژگی‌ها
  • ویژگی: مقدار; — هر تغییر یک خط است و با ; تمام می‌شود
  • آکولاد بسته } — پایان بلوک

مثال کامل با توضیح خط‌به‌خط

h1 { /* انتخاب‌گر: همه عنوان‌های اصلی */ color: #0f172a; /* رنگ متن تیره */ font-size: 2rem; /* اندازه بزرگ */ margin-bottom: 1rem; /* فاصله از پایین */ }
خط ۱: انتخاب‌گر h1 می‌گوید «روی همه تگ‌های h1 کار کن».
خط ۲: ویژگی color رنگ متن را عوض می‌کند.
خط ۳: ویژگی font-size اندازه نوشته را تعیین می‌کند.
خط ۴: ویژگی margin-bottom فاصله از عنصر بعدی را مشخص می‌کند.
توجه: بعد از هر مقدار حتماً ; بگذار و در پایان } را فراموش نکن.

چند قانون پشت سر هم

می‌توانی چندین قانون را پشت سر هم بنویسی:

h1 { color: navy; } p { color: #334155; line-height: 1.7; } a { color: #0369a1; text-decoration: none; }
هر بلوک مستقل است. مرورگر از بالا به پایین می‌خواند و هر قانون را روی عناصر مربوطه اعمال می‌کند.

اشتباه‌های رایج نحو نگارش

p { color: red font-size: 18px }
مشکل: بعد از red و بعد از 18px علامت ; جا افتاده.
نتیجه: معمولاً هیچ‌کدام از ویژگی‌ها درست اعمال نمی‌شوند.
شکل درست:
p { color: red; font-size: 18px; }
معیار تمام‌شدن درس:
باید بتوانی یک قانون کامل با انتخاب‌گر، دو ویژگی و ; و } درست بنویسی و نتیجه را در مرورگر ببینی.
جمع‌بندی
  • ساختار ثابت است: انتخاب‌گر { ویژگی: مقدار; }
  • هر ویژگی با ; تمام می‌شود
  • بلوک با } بسته می‌شود
  • چند قانون را می‌توان پشت سر هم نوشت
  • کوچک‌ترین اشتباه نحوی باعث می‌شود استایل اعمال نشود

گام عملی — همین الان

  1. یک قانون برای تگ h2 بنویس که رنگ متن و اندازه فونت را تغییر دهد.
  2. یک قانون برای p بنویس که سه ویژگی داشته باشد (رنگ، فاصله خطوط و اندازه).

اگر نتیجه ندیدی، اول ; و } را چک کن. بیشتر خطاهای مبتدیان از همین دو علامت است.
