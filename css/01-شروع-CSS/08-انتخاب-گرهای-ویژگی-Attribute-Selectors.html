انتخاب‌گرهای ویژگی در CSS

هدف این درس: یاد بگیری چطور عنصرهایی که یک ویژگی خاص دارند را هدف بگیری.

مفهوم به زبان ساده

گاهی می‌خواهی فقط لینک‌هایی که به سایت خارجی می‌روند یا فقط inputهای از نوع text را استایل بدهی. انتخاب‌گر ویژگی دقیقاً برای همین کار است.

شکل کلی

[attribute] { /* استایل */ } [attribute="value"] { /* استایل */ }

مثال ۱: همه عنصرهایی که title دارند

[title] { border-bottom: 1px dotted #666; }
هر عنصری که ویژگی title داشته باشد، یک خط نقطه‌چین زیرش می‌گیرد.

مثال ۲: لینک‌های خارجی

a[href^="https"] { color: #0369a1; }
^= یعنی «با این مقدار شروع شود». فقط لینک‌هایی که با https شروع می‌شوند هدف قرار می‌گیرند.

مثال ۳: inputهای متنی

input[type="text"] { padding: 0.5rem; border: 1px solid #cbd5e1; }
فقط فیلدهای متنی این استایل را می‌گیرند.
معیار تمام‌شدن درس: بتوانی یک انتخاب‌گر ویژگی ساده بنویسی و نتیجه را ببینی.
جمع‌بندی
  • با [attribute] عنصرهایی که آن ویژگی را دارند انتخاب می‌شوند
  • با [attribute="value"] مقدار دقیق را مشخص می‌کنی
  • برای لینک‌ها، فرم‌ها و حالت‌های خاص بسیار مفید است

گام عملی

  1. همه لینک‌هایی که href دارند را با یک رنگ خاص مشخص کن.
  2. inputهای type="email" را با حاشیه رنگی متمایز کن.
