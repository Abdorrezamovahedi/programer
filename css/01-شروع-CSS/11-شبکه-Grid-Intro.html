شبکه (Grid Intro)

هدف این درس: با CSS Grid صفحه را به ستون‌ها و ردیف‌های منظم تقسیم کن.

پوشه: شروع CSS  |  نقش: درس معرفی مبحث

مفهوم به زبان ساده

گرید برای چیدمان دوبعدی است (هم ردیف و هم ستون). با تعریف تعداد ستون‌ها و عرضشان، آیتم‌ها خودشان در خانه‌های شبکه جای می‌گیرند. برای صفحه‌آرایی کامل معمولاً از Grid استفاده می‌شود.

فهرست معرفی: Grid

همهٔ موارد این مبحث را یک‌جا در کد ببین. هر خط با کامنت توضیح داده شده است.

.grid { display: grid; grid-template-columns: 1fr 1fr 1fr; /* سه ستون برابر */ gap: 1rem; /* فاصله بین خانه‌ها */ }
display: grid: ظرف را به شبکه تبدیل می‌کند.
grid-template-columns: تعداد و عرض ستون‌ها را مشخص می‌کند.
1fr: یعنی یک واحد از فضای باقی‌مانده (Fraction).

مثال 1: چهار کارت در دو ستون

.gallery { display: grid; grid-template-columns: repeat(2, 1fr); gap: 16px; } .item { background: #e2e8f0; padding: 1.5rem; }
repeat(2, 1fr): دو ستون با عرض مساوی.
gap: فاصله افقی و عمودی بین آیتم‌ها.

اشتباه رایج مبتدی‌ها

.grid { display: grid; grid-template-columns: 1fr 1fr 1fr }
چرا اشتباه است؟ ; در پایان ویژگی جا افتاده.
چه می‌بینی؟ ممکن است کل قانون نادیده گرفته شود.
درست: بعد از 1fr آخر ; بگذار.
معیار تمام‌شدن درس: یک شبکهٔ دو یا سه ستونه بسازی و فاصله بین خانه‌ها را تنظیم کنی.
جمع‌بندی
  • display: grid ظرف را شبکه می‌کند
  • grid-template-columns ستون‌ها را تعریف می‌کند
  • 1fr واحد نسبی فضای باقی‌مانده است
  • gap فاصله بین خانه‌هاست

گام عملی — همین الان

  1. یک ظرف با چهار فرزند بساز و آن را به grid سه ستونه تبدیل کن.
  2. gap را تغییر بده و نتیجه را ببین.

اگر گیر کردی، همان خط کد را با توضیح زیر مثال مقایسه کن.
