واکنش گرا (RWD Intro)

هدف این درس: با Media Query استایل صفحه را برای موبایل و دسکتاپ متفاوت کن.

پوشه: شروع CSS  |  نقش: درس معرفی مبحث

مفهوم به زبان ساده

صفحهٔ واکنش‌گرا یعنی ظاهر سایت روی موبایل و کامپیوتر فرق می‌کند. با @media می‌گویی «اگر عرض صفحه از فلان مقدار کمتر/بیشتر بود، این قوانین را اعمال کن».

فهرست معرفی: Media Query

همهٔ موارد این مبحث را یک‌جا در کد ببین. هر خط با کامنت توضیح داده شده است.

/* حالت پیش‌فرض (موبایل اول) */ .container { padding: 1rem; } /* وقتی عرض حداقل ۷۶۸ پیکسل شد (تبلت و بالاتر) */ @media (min-width: 768px) { .container { padding: 2rem; max-width: 960px; margin: 0 auto; } }
@media: شرط برای اعمال استایل.
min-width: وقتی عرض از این مقدار بیشتر شد.
max-width: وقتی عرض از این مقدار کمتر شد.

مثال 1: تغییر تعداد ستون‌ها

.grid { display: grid; grid-template-columns: 1fr; /* موبایل: یک ستون */ gap: 1rem; } @media (min-width: 600px) { .grid { grid-template-columns: 1fr 1fr; /* تبلت: دو ستون */ } } @media (min-width: 900px) { .grid { grid-template-columns: 1fr 1fr 1fr; /* دسکتاپ: سه ستون */ } }
ایده: از کوچک شروع کن و با بزرگ‌تر شدن صفحه ستون اضافه کن.

اشتباه رایج مبتدی‌ها

@media min-width: 768px { .box { color: red; } }
چرا اشتباه است؟ شرط باید داخل پرانتز باشد.
چه می‌بینی؟ استایل اعمال نمی‌شود.
درست: @media (min-width: 768px) { ... }
معیار تمام‌شدن درس: یک استایل بنویسی که روی عرض کمتر از ۶۰۰ پیکسل فرق کند.
جمع‌بندی
  • @media شرط اعمال استایل است
  • min-width و max-width رایج‌ترین شرط‌ها هستند
  • رویکرد Mobile-first توصیه می‌شود

گام عملی — همین الان

  1. یک قانون بنویس که فقط وقتی عرض بیشتر از ۷۰۰ پیکسل است رنگ پس‌زمینه عوض شود.
  2. پنجره مرورگر را کوچک و بزرگ کن و نتیجه را ببین.

اگر گیر کردی، همان خط کد را با توضیح زیر مثال مقایسه کن.
