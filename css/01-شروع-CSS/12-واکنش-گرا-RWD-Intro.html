طراحی واکنش‌گرا (RWD)

هدف این درس: بفهمی طراحی واکنش‌گرا چیست و چرا مهم است.

مفهوم به زبان ساده

صفحه باید در موبایل، تبلت و کامپیوتر خوب دیده شود. به این کار طراحی واکنش‌گرا می‌گویند. یعنی ظاهر صفحه به اندازه صفحه نمایش واکنش نشان می‌دهد.

اولین قدم ضروری

<meta name="viewport" content="width=device-width, initial-scale=1.0">
این خط را باید در head همه صفحات داشته باشی. بدون آن، صفحه در موبایل درست مقیاس نمی‌شود.

ایده media query (خیلی ساده)

/* برای صفحه‌های کوچک‌تر از ۶۰۰ پیکسل */ @media (max-width: 600px) { body { font-size: 14px; } }
وقتی عرض صفحه کمتر از ۶۰۰ پیکسل شود، این استایل‌ها اعمال می‌شوند.
معیار تمام‌شدن درس: بدانی viewport چیست و یک media query ساده نوشته باشی.
جمع‌بندی
  • طراحی واکنش‌گرا یعنی سازگاری با اندازه‌های مختلف صفحه
  • تگ viewport ضروری است
  • media query برای تغییر استایل در اندازه‌های مختلف استفاده می‌شود

گام عملی

  1. تگ viewport را در یک صفحه HTML بررسی کن.
  2. یک media query ساده بنویس که در موبایل اندازه فونت را کوچک‌تر کند.
