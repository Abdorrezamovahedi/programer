انتخاب‌گرها در CSS

هدف این درس: بفهمی انتخاب‌گر چیست و بتوانی با تگ، کلاس و آیدی عنصرهای صفحه را هدف بگیری.

پیش‌نیاز: نحو نگارش CSS را بلد باشی.

مفهوم به زبان ساده

انتخاب‌گر مثل آدرس است. به CSS می‌گوید «روی کدام عنصر کار کن».
اگر آدرس را اشتباه بنویسی، استایل به عنصر دیگری می‌رود یا اصلاً اعمال نمی‌شود.

۱. انتخاب‌گر تگ (Element Selector)

ساده‌ترین نوع: نام تگ HTML را می‌نویسی.

p { color: #1e293b; } h1 { color: navy; }
خط ۱–۳: همه تگ‌های p رنگ تیره‌ای می‌گیرند.
خط ۴–۶: همه عنوان‌های h1 آبی تیره می‌شوند.

۲. انتخاب‌گر کلاس (Class Selector)

با نقطه شروع می‌شود. روی عنصرهایی که آن کلاس را دارند اعمال می‌شود.

.highlight { background-color: #fef3c7; padding: 0.5rem; }
فقط عنصرهایی که class="highlight" دارند این استایل را می‌گیرند. یک کلاس را می‌توانی روی چندین عنصر استفاده کنی.

۳. انتخاب‌گر آیدی (ID Selector)

با # شروع می‌شود. معمولاً برای یک عنصر یکتا استفاده می‌شود.

#main-title { font-size: 2.2rem; color: #0f172a; }
فقط عنصری که id="main-title" دارد هدف قرار می‌گیرد. آیدی باید در صفحه یکتا باشد.

اشتباه رایج

.highlight { color: red } #main-title { font-size: 2rem }
مشکل: بعد از مقادیر ; جا افتاده.
نتیجه: استایل ممکن است اعمال نشود.
درست: همیشه بعد از هر مقدار ; بگذار.
معیار تمام‌شدن درس: بتوانی یک انتخاب‌گر تگ، یک کلاس و یک آیدی بنویسی و نتیجه را در مرورگر ببینی.
جمع‌بندی
  • انتخاب‌گر تگ: نام تگ (p, h1, ...)
  • انتخاب‌گر کلاس: با نقطه شروع می‌شود (.name)
  • انتخاب‌گر آیدی: با # شروع می‌شود (#name)
  • کلاس برای چند عنصر، آیدی برای یک عنصر یکتا

گام عملی

  1. یک کلاس به نام note بساز که پس‌زمینه روشن و padding داشته باشد.
  2. یک آیدی به نام header بساز و اندازه فونت آن را بزرگ کن.

اگر استایل اعمال نشد، اول نام انتخاب‌گر و وجود ; و } را چک کن.
