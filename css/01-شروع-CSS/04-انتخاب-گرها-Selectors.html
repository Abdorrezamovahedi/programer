انتخاب گرها (Selectors)

هدف این درس: با تگ، class و id هدف استایل را دقیق کنی.

پوشه: شروع CSS  |  نقش: درس معرفی مبحث

مفهوم به زبان ساده

اگر استایل اعمال نشد، اول انتخاب‌گر را چک کن. نقطه برای class است؛ # برای id.

فهرست معرفی: انتخاب‌گرها

همهٔ موارد این مبحث را یک‌جا در کد ببین. هر خط با کامنت توضیح داده شده است.

/* انواع انتخاب‌گر */ p { color: #333; } /* تگ: همهٔ p */ .card { padding: 1rem; } /* class: class="card" */ #title { font-size: 1.5rem; } /* id: id="title" */ a:hover { color: #2563eb; } /* حالت نشانگر روی لینک */

مثال 1: کلاس کارت

.card { padding: 16px; border: 1px solid #e2e8f0; }
خط ۱: فقط عناصر با class=card.
خط ۲: فاصله داخلی.
خط ۳: لبهٔ نازک.

اشتباه رایج مبتدی‌ها

#card { } /* HTML: class="card" */
چرا اشتباه است؟ # برای id است نه class.
چه می‌بینی؟ بدون اثر
درست: .card { }
معیار تمام‌شدن درس: یک div با class=card بسازی و padding از CSS بگیرد.
جمع‌بندی
  • . کلاس
  • # id
  • اشتباه پیشوند = صفر اثر

گام عملی — همین الان

  1. دو کارت با یک کلاس بساز.

اگر گیر کردی، همان خط کد را با توضیح زیر مثال مقایسه کن.
