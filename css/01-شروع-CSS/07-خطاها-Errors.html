خطاها (Errors)

هدف این درس: خطاهای رایج CSS را بشناس و یاد بگیر چطور سریع پیدایشان کنی.

پوشه: شروع CSS  |  نقش: درس معرفی مبحث

مفهوم به زبان ساده

CSS معمولاً خطای قرمز بزرگ نشان نمی‌دهد؛ فقط استایل اعمال نمی‌شود. رایج‌ترین علت‌ها: فراموش کردن ; یا }، غلط نوشتن نام ویژگی، یا اشتباه در انتخاب‌گر است.

خطاهای پرتکرار

/* ۱. فراموش کردن ; */ p { color: red font-size: 18px; } /* ۲. فراموش کردن } */ .box { padding: 1rem; /* اینجا } جا افتاده */ /* ۳. نام ویژگی غلط */ .text { colour: blue; /* درست: color */ }
نکته: ابزار DevTools مرورگر (F12) بهترین دوست تو برای پیدا کردن این خطاهاست.

مثال: پیدا کردن مشکل

.card { background: #f8fafc; padding: 16px border: 1px solid #e2e8f0; }
مشکل: بعد از 16px علامت ; نیست. در نتیجه ویژگی بعدی هم ممکن است نادیده گرفته شود.

اشتباه رایج مبتدی‌ها

p { color: red; } .card { padding: 1rem }
چرا اشتباه است؟ در قانون دوم ; بعد از 1rem جا افتاده (قبل از }).
چه می‌بینی؟ در بعضی مرورگرها کار می‌کند، در بعضی نه. همیشه ; بگذار.
معیار تمام‌شدن درس: بتوانی با نگاه به کد، حداقل دو نوع خطای رایج را تشخیص دهی.
جمع‌بندی
  • فراموش کردن ; و } خیلی رایج است
  • نام ویژگی را درست بنویس (color نه colour)
  • از DevTools برای بررسی استفاده کن

گام عملی — همین الان

  1. عمداً یک ; را پاک کن و ببین چه می‌شود.
  2. با DevTools (F12) استایل عنصر را بررسی کن.

اگر گیر کردی، همان خط کد را با توضیح زیر مثال مقایسه کن.
