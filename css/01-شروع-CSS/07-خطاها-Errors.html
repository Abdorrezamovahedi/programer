خطاهای رایج در CSS

هدف این درس: رایج‌ترین اشتباهات CSS را بشناسی و بتوانی سریع آن‌ها را پیدا و درست کنی.

مفهوم به زبان ساده

وقتی استایل اعمال نمی‌شود، معمولاً یکی از این سه مورد اتفاق افتاده: علامت فراموش شده، انتخاب‌گر اشتباه نوشته شده، یا فایل CSS به درستی وصل نشده است.

خطای ۱: فراموشی نقطه‌ویرگول یا آکولاد

p { color: red font-size: 18px }
مشکل: بعد از red و 18px علامت ; جا افتاده.
نتیجه: استایل اعمال نمی‌شود یا فقط بخشی از آن کار می‌کند.
درست:
p { color: red; font-size: 18px; }

خطای ۲: انتخاب‌گر اشتباه

.titel { color: navy; }
اگر در HTML نوشته‌ای class="title" ولی در CSS نوشته‌ای .titel، هیچ اتفاقی نمی‌افتد. املای دقیق مهم است.

خطای ۳: فایل CSS وصل نشده

اگر از فایل خارجی استفاده می‌کنی، مسیر فایل را دوباره چک کن:

<link rel="stylesheet" href="css/style.css">
اگر مسیر اشتباه باشد، هیچ استایلی اعمال نمی‌شود. در ابزارهای توسعه‌دهنده مرورگر (F12) می‌توانی ببینی فایل لود شده یا نه.
معیار تمام‌شدن درس: بتوانی حداقل دو خطای رایج را در کد خودت پیدا و درست کنی.
جمع‌بندی
  • همیشه ; و } را چک کن
  • املای انتخاب‌گر باید دقیقاً با HTML یکی باشد
  • مسیر فایل CSS را بررسی کن
  • از ابزارهای مرورگر (Inspect) برای دیدن خطاها استفاده کن

گام عملی

  1. عمداً یک ; را حذف کن و ببین چه می‌شود، بعد آن را درست کن.
  2. یک کلاس را با املای اشتباه بنویس و بعد اصلاح کن.
