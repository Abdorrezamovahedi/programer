خطاها (Errors)

هدف این درس: اولین قانون ظاهر را بنویسی و رنگ متن را عوض کنی.

پوشه: شروع CSS  |  پیش‌نیاز: درس‌های قبلی همین پوشه («شروع CSS») را با تایپ و اجرا خوانده باشی.

مفهوم به زبان ساده

CSS ظاهر صفحه را کنترل می‌کند: رنگ، فاصله، فونت، چیدمان. یک قانون می‌گوید «کدام بخش» و «چه شکلی». HTML ساختار را می‌سازد؛ CSS لباس آن است.

ساختار (Syntax)

selector { property: value; }

مثال 1: خواناتر کردن بندها

p { color: #1e293b; line-height: 1.8; font-size: 1.05rem; }
p: همهٔ بندهای صفحه.
color: رنگ نوشته.
line-height: فاصلهٔ بین خط‌ها — برای خواندن فارسی مهم است.
;: پایان هر دستور داخل بلوک.

اشتباه رایج مبتدی‌ها

p { color: red
چرا اشتباه است؟ آکولاد بسته یا نقطه‌ویرگول جا افتاده.
چه می‌بینی؟ استایل اعمال نمی‌شود یا قوانین بعدی خراب می‌شوند
درست: p { color: red; }
معیار تمام‌شدن درس: این قانون را در صفحه بگذاری و رنگ بند را با چشم ببینی.
جمع‌بندی
  • هر قانون: هدف + ویژگی‌ها
  • نقطه‌ویرگول و } را کامل بنویس
  • اول ساده شروع کن

گام عملی — همین الان

  1. رنگ را عوض کن.
  2. اندازهٔ فونت را بزرگ‌تر کن.

اگر گیر کردی، فقط همان یک خطی که خطا می‌دهد را با بخش «اشتباه رایج» مقایسه کن. لازم نیست همه چیز را یک‌جا حفظ کنی — با تمرین جا می‌افتد.
