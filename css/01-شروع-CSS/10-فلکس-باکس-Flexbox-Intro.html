معرفی فلکس‌باکس

هدف این درس: بفهمی فلکس‌باکس چیست و بتوانی یک ردیف ساده از عناصر را با آن بچینی.

مفهوم به زبان ساده

فلکس‌باکس مثل یک قفسه انعطاف‌پذیر است. وقتی به یک عنصر می‌گویی display: flex، فرزندانش در یک ردیف (یا ستون) قرار می‌گیرند و می‌توانند خودشان را با فضای موجود تنظیم کنند.

اولین مثال

.container { display: flex; gap: 1rem; }
display: flex → فرزندان در یک ردیف قرار می‌گیرند.
gap → فاصله بین آیتم‌ها را مشخص می‌کند.

جهت چیدمان

.container { display: flex; flex-direction: row; /* افقی (پیش‌فرض) */ /* flex-direction: column; عمودی */ }
معیار تمام‌شدن درس: بتوانی یک container با display: flex بسازی و چند آیتم داخل آن بچینی.
جمع‌بندی
  • display: flex عناصر فرزند را در یک ردیف یا ستون می‌چیند
  • gap فاصله بین آیتم‌ها را کنترل می‌کند
  • flex-direction جهت چیدمان را مشخص می‌کند
  • فلکس‌باکس پایه بسیاری از چیدمان‌های مدرن است

گام عملی

  1. یک div با کلاس container بساز و display: flex به آن بده.
  2. سه جعبه رنگی داخل آن قرار بده و فاصله بین آن‌ها را با gap تنظیم کن.
