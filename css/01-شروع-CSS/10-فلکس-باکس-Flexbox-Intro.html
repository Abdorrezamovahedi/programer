فلکس باکس (Flexbox Intro)

هدف این درس: با display:flex یک ردیف از آیتم‌ها بساز و تراز افقی و عمودی آن‌ها را کنترل کن.

پوشه: شروع CSS  |  نقش: درس معرفی مبحث

مفهوم به زبان ساده

فلکس‌باکس برای چیدمان یک‌بعدی (ردیف یا ستون) است. وقتی به یک ظرف display: flex می‌دهی، فرزندانش در یک خط قرار می‌گیرند و می‌توانی فاصله و ترازشان را خیلی راحت تنظیم کنی.

فهرست معرفی: فلکس‌باکس

همهٔ موارد این مبحث را یک‌جا در کد ببین. هر خط با کامنت توضیح داده شده است.

.container { display: flex; /* فعال کردن فلکس */ justify-content: center; /* تراز افقی */ align-items: center; /* تراز عمودی */ gap: 1rem; /* فاصله بین آیتم‌ها */ }
display: flex: ظرف را به فلکس تبدیل می‌کند.
justify-content: آیتم‌ها را در محور اصلی (معمولاً افقی) تراز می‌کند.
align-items: تراز در محور عمود.
gap: فاصله یکنواخت بین آیتم‌ها.

مثال 1: سه کارت در یک ردیف

.row { display: flex; gap: 12px; } .card { flex: 1; /* همه کارت‌ها عرض برابر */ padding: 1rem; background: #f1f5f9; }
خط ۱–۳: ظرف فلکس با فاصله ۱۲ پیکسل.
flex: 1: هر کارت فضای مساوی می‌گیرد.

اشتباه رایج مبتدی‌ها

.container { display: flex justify-content: center }
چرا اشتباه است؟ بعد از هر ویژگی باید ; باشد.
چه می‌بینی؟ استایل اعمال نمی‌شود.
درست: بعد از flex و center علامت ; بگذار.
معیار تمام‌شدن درس: سه آیتم را با flex در یک ردیف ببینی و فاصله و ترازشان را عوض کنی.
جمع‌بندی
  • display: flex ظرف را فلکس می‌کند
  • justify-content تراز افقی
  • align-items تراز عمودی
  • gap فاصله بین آیتم‌ها

گام عملی — همین الان

  1. یک ظرف با سه فرزند بساز و display: flex بده.
  2. justify-content را به space-between تغییر بده و نتیجه را ببین.

اگر گیر کردی، همان خط کد را با توضیح زیر مثال مقایسه کن.
