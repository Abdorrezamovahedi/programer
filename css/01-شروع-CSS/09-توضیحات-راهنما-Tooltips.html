راهنما (Tooltip) در CSS

هدف این درس: بتوانی یک راهنمای کوچک بسازی که با رفتن موس روی عنصر ظاهر شود.

مفهوم به زبان ساده

Tooltip همان متن کوچکی است که وقتی موس را روی دکمه‌ای می‌بری، ظاهر می‌شود و توضیح کوتاهی می‌دهد.

.tooltip { position: relative; } .tooltip::after { content: "این یک راهنما است"; position: absolute; bottom: 100%; background: #333; color: #fff; padding: 0.3rem 0.6rem; border-radius: 4px; font-size: 0.85rem; white-space: nowrap; opacity: 0; transition: opacity 0.2s; } .tooltip:hover::after { opacity: 1; }
با hover موس، راهنما ظاهر می‌شود.
معیار تمام‌شدن درس: بتوانی یک tooltip ساده روی یک دکمه یا لینک بسازی.
جمع‌بندی
  • از position و ::after برای ساخت tooltip استفاده می‌کنیم
  • با hover ظاهر و ناپدید می‌شود
  • برای راهنمایی کوتاه به کاربر عالی است

گام عملی

  1. یک دکمه بساز و tooltip روی آن قرار بده.
  2. متن راهنما را به چیزی مفید تغییر بده.
