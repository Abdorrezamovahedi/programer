راهنما (Tooltip) در CSS

هدف این درس: بتوانی یک راهنمای کوچک بسازی که با رفتن موس روی عنصر ظاهر شود.

مفهوم به زبان ساده

Tooltip همان متن کوچکی است که وقتی موس را روی دکمه‌ای می‌بری، ظاهر می‌شود و توضیح کوتاهی می‌دهد.

.tooltip { position: relative; } .tooltip::after { content: "این یک راهنما است"; position: absolute; bottom: 100%; background: #333; color: #fff; padding: 0.3rem 0.6rem; border-radius: 4px; font-size: 0.85rem; white-space: nowrap; opacity: 0; transition: opacity 0.2s; } .tooltip:hover::after { opacity: 1; }
توضیح خط‌به‌خط همین مثال
  1. خط 1: .tooltip { — یک انتخابگر را باز می‌کند تا استایل‌هایش را بنویسیم.
  2. خط 2: position: relative; — ویژگی «position» را مقداردهی می‌کند.
  3. خط 3: } — پایان بلوک استایل.
  4. خط 4: .tooltip::after { — شروع یک بلوک جدید از دستورات.
  5. خط 5: content: "این یک راهنما است"; — ویژگی «content» را مقداردهی می‌کند.
  6. خط 6: position: absolute; — ویژگی «position» را مقداردهی می‌کند.
  7. خط 7: bottom: 100%; — ویژگی «bottom» را مقداردهی می‌کند.
  8. خط 8: background: #333; — ویژگی «background» را مقداردهی می‌کند.
  9. خط 9: color: #fff; — ویژگی «color» را مقداردهی می‌کند.
  10. خط 10: padding: 0.3rem 0.6rem; — ویژگی «padding» را مقداردهی می‌کند.
  11. خط 11: border-radius: 4px; — ویژگی «border-radius» را مقداردهی می‌کند.
  12. خط 12: font-size: 0.85rem; — ویژگی «font-size» را مقداردهی می‌کند.
  13. خط 13: white-space: nowrap; — ویژگی «white-space» را مقداردهی می‌کند.
  14. خط 14: opacity: 0; — ویژگی «opacity» را مقداردهی می‌کند.
  15. خط 15: transition: opacity 0.2s; — ویژگی «transition» را مقداردهی می‌کند.
  16. خط 16: } — پایان بلوک استایل.
  17. خط 17: .tooltip:hover::after { — شروع یک بلوک جدید از دستورات.
  18. خط 18: opacity: 1; — ویژگی «opacity» را مقداردهی می‌کند.
  19. خط 19: } — پایان بلوک استایل.
با hover موس، راهنما ظاهر می‌شود.
معیار تمام‌شدن درس: بتوانی یک tooltip ساده روی یک دکمه یا لینک بسازی.
جمع‌بندی
  • از position و ::after برای ساخت tooltip استفاده می‌کنیم
  • با hover ظاهر و ناپدید می‌شود
  • برای راهنمایی کوتاه به کاربر عالی است

گام عملی

  1. یک دکمه بساز و tooltip روی آن قرار بده.
  2. متن راهنما را به چیزی مفید تغییر بده.
