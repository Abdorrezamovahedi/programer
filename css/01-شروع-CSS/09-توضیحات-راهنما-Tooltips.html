توضیحات راهنما (Tooltips)

هدف این درس: با CSS یک راهنمای شناور (Tooltip) ساده بساز که با هاور ظاهر شود.

پوشه: شروع CSS  |  نقش: درس معرفی مبحث

مفهوم به زبان ساده

تولتیپ همان متن کوچکی است که وقتی ماوس را روی یک عنصر می‌بری ظاهر می‌شود. با ترکیب position و :hover می‌توانی آن را فقط با CSS بسازی.

فهرست معرفی: Tooltip

.tooltip { position: relative; /* مرجع برای فرزند */ display: inline-block; } .tooltip .tip { visibility: hidden; /* مخفی در حالت عادی */ position: absolute; bottom: 125%; left: 50%; transform: translateX(-50%); background: #1e293b; color: #fff; padding: 6px 10px; border-radius: 4px; white-space: nowrap; font-size: 0.85rem; } .tooltip:hover .tip { visibility: visible; /* نمایش با هاور */ }
position: relative روی والد و absolute روی فرزند، موقعیت را کنترل می‌کند.
:hover باعث می‌شود فقط وقتی ماوس روی عنصر است، راهنما دیده شود.

مثال 1: دکمه با راهنما

.btn-tip { position: relative; } .btn-tip::after { content: "این یک راهنماست"; position: absolute; bottom: 120%; left: 50%; transform: translateX(-50%); background: #0f172a; color: white; padding: 4px 8px; border-radius: 4px; font-size: 12px; opacity: 0; transition: opacity 0.2s; pointer-events: none; } .btn-tip:hover::after { opacity: 1; }
::after + content: بدون HTML اضافه، متن راهنما ساخته می‌شود.

اشتباه رایج مبتدی‌ها

.tip { position: absolute; /* والد relative ندارد */ }
چرا اشتباه است؟ اگر والد position: relative نداشته باشد، absolute نسبت به کل صفحه محاسبه می‌شود.
درست: همیشه روی ظرف والد position: relative بگذار.
معیار تمام‌شدن درس: یک عنصر بسازی که با هاور متن راهنما نشان دهد.
جمع‌بندی
  • والد: position: relative
  • فرزند راهنما: position: absolute
  • با :hover یا opacity نمایش را کنترل کن

گام عملی — همین الان

  1. یک دکمه با راهنمای هاور بساز.
  2. موقعیت راهنما را از بالا به پایین تغییر بده.
