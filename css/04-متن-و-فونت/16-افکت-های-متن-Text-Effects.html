افکت های متن (Text Effects)

هدف این درس: تراز، تزئین و فاصلهٔ حروف متن را برای خوانایی تنظیم کنی.

پوشه: متن و فونت  |  پیش‌نیاز: درس‌های قبلی «متن و فونت».

مفهوم به زبان ساده

text-align جهت قرارگیری متن در بلوک است. text-decoration خط زیر/روی متن. letter-spacing فاصلهٔ حروف. برای لینک‌ها معمولاً underline پیش‌فرض را کنترل می‌کنی.

ساختار (Syntax)

text-align: right; text-decoration: none; letter-spacing: 0.02em;

مثال 1: متن و لینک

p { text-align: right; line-height: 1.8; } a { text-decoration: none; color: #2563eb; } a:hover { text-decoration: underline; }
توضیح خط‌به‌خط همین مثال
  1. خط 1: p { — یک انتخابگر را باز می‌کند تا استایل‌هایش را بنویسیم.
  2. خط 2: text-align: right; — ویژگی «text-align» را مقداردهی می‌کند.
  3. خط 3: line-height: 1.8; — ویژگی «line-height» را مقداردهی می‌کند.
  4. خط 4: } — پایان بلوک استایل.
  5. خط 5: a { — یک انتخابگر را باز می‌کند تا استایل‌هایش را بنویسیم.
  6. خط 6: text-decoration: none; — ویژگی «text-decoration» را مقداردهی می‌کند.
  7. خط 7: color: #2563eb; — ویژگی «color» را مقداردهی می‌کند.
  8. خط 8: } — پایان بلوک استایل.
  9. خط 9: a:hover { — شروع یک بلوک جدید از دستورات.
  10. خط 10: text-decoration: underline; — ویژگی «text-decoration» را مقداردهی می‌کند.
  11. خط 11: } — پایان بلوک استایل.
text-align: برای فارسی معمولاً right.
decoration none: خط زیر لینک برداشته می‌شود.
hover: وقتی نشانگر روی لینک است خط برمی‌گردد — بازخورد واضح.

اشتباه رایج مبتدی‌ها

text-align: left روی کل سایت فارسی بدون فکر
توضیح خط‌به‌خط همین مثال
  1. خط 1: text-align: left روی کل سایت فارسی بدون فکر — این خط بخشی از منطق مثال را انجام می‌دهد.
چرا اشتباه است؟ خواندن فارسی سخت‌تر می‌شود.
چه می‌بینی؟ UX ضعیف
درست: برای بدنه right؛ موارد خاص جدا
معیار تمام‌شدن درس: لینکی بسازی که پیش‌فرض بدون خط باشد و در hover خط بگیرد.
جمع‌بندی
  • align برای بلوک
  • decoration برای خط
  • hover بازخورد می‌دهد

گام عملی — همین الان

  1. letter-spacing روی عنوان را کمی کم کن.

اگر گیر کردی فقط همان خط خطا را با «اشتباه رایج» مقایسه کن. با تایپ و اجرا جا می‌افتد.
