متن و فونت

1. فونت

فونت در CSS

هدف این درس: بتوانی خانواده فونت و اندازه متن را تنظیم کنی.

body { font-family: Tahoma, Arial, sans-serif; font-size: 16px; } h1 { font-size: 2rem; }
اگر فونت اول موجود نباشد، مرورگر سراغ بعدی می‌رود.
معیار تمام‌شدن درس: فونت و اندازه متن صفحه را عوض کرده باشی.
جمع‌بندی
  • font-family خانواده فونت را مشخص می‌کند
  • font-size اندازه متن را تعیین می‌کند
  • از واحدهایی مثل px، rem و em استفاده می‌شود

گام عملی

  1. فونت body را عوض کن و اندازه h1 را بزرگ‌تر کن.
