1. فونت

فونت در CSS

هدف این درس: بتوانی خانواده فونت و اندازه متن را تنظیم کنی.

body { font-family: Tahoma, Arial, sans-serif; font-size: 16px; } h1 { font-size: 2rem; }
توضیح خط‌به‌خط همین مثال
  1. خط 1: body { — یک انتخابگر را باز می‌کند تا استایل‌هایش را بنویسیم.
  2. خط 2: font-family: Tahoma, Arial, sans-serif; — ویژگی «font-family» را مقداردهی می‌کند.
  3. خط 3: font-size: 16px; — ویژگی «font-size» را مقداردهی می‌کند.
  4. خط 4: } — پایان بلوک استایل.
  5. خط 5: h1 { — یک انتخابگر را باز می‌کند تا استایل‌هایش را بنویسیم.
  6. خط 6: font-size: 2rem; — ویژگی «font-size» را مقداردهی می‌کند.
  7. خط 7: } — پایان بلوک استایل.
اگر فونت اول موجود نباشد، مرورگر سراغ بعدی می‌رود.
معیار تمام‌شدن درس: فونت و اندازه متن صفحه را عوض کرده باشی.
جمع‌بندی
  • font-family خانواده فونت را مشخص می‌کند
  • font-size اندازه متن را تعیین می‌کند
  • از واحدهایی مثل px، rem و em استفاده می‌شود

گام عملی

  1. فونت body را عوض کن و اندازه h1 را بزرگ‌تر کن.
