آیکون ها (Icons)

هدف این درس: ویژگی مربوط به «آیکون ها» را روی یک بخش صفحه آزمایش کنی.

پوشه: متن و فونت  |  پیش‌نیاز: درس‌های قبلی همین پوشه («متن و فونت») را با تایپ و اجرا خوانده باشی.

مفهوم به زبان ساده

در این درس فقط «آیکون ها» را تمرین می‌کنی. یک کلاس بساز، مقدار را عوض کن، نتیجه را در مرورگر ببین. ابزار توسعه‌دهنده (F12) بهترین دوست توست.

ساختار (Syntax)

selector { property: value; }

مثال 1: جعبهٔ آزمایش

.demo { /* آیکون ها */ padding: 0.75rem; border-radius: 8px; border: 1px solid #cbd5e1; }
.demo: هدف تمرین.
padding: فاصله داخلی قابل‌دیدن.
radius: گوشه گرد.
