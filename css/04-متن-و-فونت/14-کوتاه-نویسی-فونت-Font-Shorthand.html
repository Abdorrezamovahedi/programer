کوتاه نویسی فونت (Font Shorthand)

هدف این درس: پشتهٔ فونت امن و وزن عنوان را درست تنظیم کنی.

پوشه: متن و فونت  |  پیش‌نیاز: درس‌های قبلی «متن و فونت».

مفهوم به زبان ساده

مرورگر فونت‌ها را به ترتیب لیست امتحان می‌کند. اگر اولی نبود دومی. همیشه یک خانوادهٔ عمومی مثل sans-serif در انتها بگذار. font-weight ضخامت است (۴۰۰ عادی، ۷۰۰ ضخیم).

ساختار (Syntax)

font-family: Tahoma, Arial, sans-serif; font-weight: 700; font-size: 1.25rem;

مثال 1: بدنه و عنوان

body { font-family: Tahoma, Arial, sans-serif; font-size: 1rem; } h1 { font-weight: 700; font-size: 1.75rem; }
پشته: Tahoma اول؛ اگر نبود Arial؛ در نهایت sans-serif.
rem: نسبت به اندازهٔ ریشه — مقیاس‌پذیرتر از px ثابت در بعضی طراحی‌ها.
weight 700: عنوان مشخص‌تر از متن عادی.

اشتباه رایج مبتدی‌ها

font-family: IRANSans;
چرا اشتباه است؟ بدون " (دابل‌کوتیشن) و بدون fallback.
چه می‌بینی؟ ممکن است فونت نیاید
درست: font-family: "IRANSans", Tahoma, sans-serif;
معیار تمام‌شدن درس: بدنه و h1 را با پشته و وزن متفاوت تنظیم کنی.
جمع‌بندی
  • همیشه fallback
  • نام چندکلمه‌ای در " (دابل‌کوتیشن)
  • weight برای سلسله‌مراتب

گام عملی — همین الان

  1. font-style: italic روی یک " (دابل‌کوتیشن).
