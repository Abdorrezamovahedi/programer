تزئین متن (Text Decoration)

هدف این درس: تراز، تزئین و فاصلهٔ حروف متن را برای خوانایی تنظیم کنی.

پوشه: متن و فونت  |  پیش‌نیاز: درس‌های قبلی «متن و فونت».

مفهوم به زبان ساده

text-align جهت قرارگیری متن در بلوک است. text-decoration خط زیر/روی متن. letter-spacing فاصلهٔ حروف. برای لینک‌ها معمولاً underline پیش‌فرض را کنترل می‌کنی.

ساختار (Syntax)

text-align: right; text-decoration: none; letter-spacing: 0.02em;

مثال 1: متن و لینک

p { text-align: right; line-height: 1.8; } a { text-decoration: none; color: #2563eb; } a:hover { text-decoration: underline; }
text-align: برای فارسی معمولاً right.
decoration none: خط زیر لینک برداشته می‌شود.
hover: وقتی نشانگر روی لینک است خط برمی‌گردد — بازخورد واضح.

اشتباه رایج مبتدی‌ها

text-align: left روی کل سایت فارسی بدون فکر
چرا اشتباه است؟ خواندن فارسی سخت‌تر می‌شود.
چه می‌بینی؟ UX ضعیف
درست: برای بدنه right؛ موارد خاص جدا
معیار تمام‌شدن درس: لینکی بسازی که پیش‌فرض بدون خط باشد و در hover خط بگیرد.
جمع‌بندی
  • align برای بلوک
  • decoration برای خط
  • hover بازخورد می‌دهد

گام عملی — همین الان

  1. letter-spacing روی عنوان را کمی کم کن.
