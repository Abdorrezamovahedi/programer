تراز متن در CSS

هدف این درس: بتوانی متن را چپ، راست یا وسط‌چین کنی.

h1 { text-align: center; } p { text-align: right; } .note { text-align: left; }
مقادیر رایج: left، right، center و justify.
معیار تمام‌شدن درس: یک عنوان وسط‌چین و یک بند راست‌چین ساخته باشی.
جمع‌بندی
  • text-align جهت قرارگیری متن را مشخص می‌کند
  • center برای عنوان‌ها زیاد استفاده می‌شود

گام عملی

  1. یک عنوان را وسط و یک پاراگراف را justify کن.
