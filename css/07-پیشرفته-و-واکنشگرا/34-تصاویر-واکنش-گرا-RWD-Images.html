تصاویر واکنش گرا (RWD Images)

هدف این درس: استایل را برای صفحهٔ باریک و عریض متفاوت کنی.

درس معرفی «چیدمان Flex و Grid»: اگر هنوز فهرست کامل این مبحث را نخوانده‌ای، اول برو به فلکس واکنش گرا (Flex Responsive) (همین پوشه — معمولاً اولین درس). آنجا همهٔ انواع/علامت‌ها یک‌جا معرفی شده‌اند.
پوشه: پیشرفته و واکنش‌گرا  |  پیش‌نیاز: درس‌های قبلی همین پوشه («پیشرفته و واکنش‌گرا») را با تایپ و اجرا خوانده باشی.

مفهوم به زبان ساده

موبایل و دسکتاپ عرض متفاوت دارند. با @media می‌گویی اگر عرض از حدی کمتر/بیشتر بود، قوانین دیگر اعمال شود.

ساختار (Syntax)

@media (max-width: 600px) { ... }

مثال 1: منو در موبایل

.nav { display: flex; gap: 1rem; } @media (max-width: 600px) { .nav { flex-direction: column; } }
پایه: در عرض زیاد افقی.
max-width 600: در عرض کم عمودی.

اشتباه رایج مبتدی‌ها

فقط کوچک کردن فونت بدون عوض کردن چیدمان
چرا اشتباه است؟ کلیک و خواندن سخت می‌ماند.
چه می‌بینی؟ صفحه موبایل‌دوست نیست
درست: چیدمان را ساده و ستونی کن
معیار تمام‌شدن درس: یک تغییر واقعی زیر ۶۰۰px ببینی (مثلاً جهت منو).
