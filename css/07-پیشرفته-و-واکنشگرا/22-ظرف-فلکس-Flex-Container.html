ظرف فلکس (Flex Container)

هدف این درس: چند آیتم را با flex کنار هم بچینی.

پوشه: پیشرفته و واکنش‌گرا  |  نقش: درس معرفی مبحث

مفهوم به زبان ساده

display:flex را روی ظرف بگذار نه روی هر فرزند.

فهرست معرفی: Flexbox

همهٔ موارد این مبحث را یک‌جا در کد ببین. هر خط با کامنت توضیح داده شده است.

/* Flex — روی والد */ .row { display: flex; /* فرزندان در یک ردیف */ gap: 12px; /* فاصله بین آیتم‌ها */ flex-wrap: wrap; /* در عرض کم به خط بعد */ }

مثال 1: ردیف سه تایی

.row { display: flex; gap: 12px; } .row > * { flex: 1; }
display:flex: روی والد.
gap: فاصله یکسان.
flex: 1: فرزندان فضای مساوی بگیرند.

اشتباه رایج مبتدی‌ها

display:flex روی هر فرزند
چرا اشتباه است؟ باید روی والد باشد.
چه می‌بینی؟ چیدمان عوض نمی‌شود
درست: روی ظرف
معیار تمام‌شدن درس: سه جعبه در یک ردیف با gap ببینی.
جمع‌بندی
  • flex روی والد
  • gap
  • wrap برای موبایل

گام عملی — همین الان

  1. flex-direction: column را تست کن.

اگر گیر کردی، همان خط کد را با توضیح زیر مثال مقایسه کن.
