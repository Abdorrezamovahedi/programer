ترتیب آیتم شبکه (Grid Item Order)

هدف این درس: صفحه را به ستون‌های منظم تقسیم کنی.

درس معرفی «چیدمان Flex و Grid»: اگر هنوز فهرست کامل این مبحث را نخوانده‌ای، اول برو به فلکس واکنش گرا (Flex Responsive) (همین پوشه — معمولاً اولین درس). آنجا همهٔ انواع/علامت‌ها یک‌جا معرفی شده‌اند.
پوشه: پیشرفته و واکنش‌گرا  |  پیش‌نیاز: درس‌های قبلی همین پوشه («پیشرفته و واکنش‌گرا») را با تایپ و اجرا خوانده باشی.

مفهوم به زبان ساده

گرید برای چیدمان دوبعدی است. می‌گویی چند ستون و با چه نسبتی. در موبایل معمولاً ستون‌ها را یکی می‌کنی.

ساختار (Syntax)

display: grid; grid-template-columns: 1fr 1fr; gap: 1rem;

مثال 1: دو ستون واکنش‌گرا

.layout { display: grid; grid-template-columns: 1fr 1fr; gap: 1rem; } @media (max-width: 600px) { .layout { grid-template-columns: 1fr; } }
1fr 1fr: دو ستون هم‌عرض.
gap: فاصله شبکه.
media: زیر ۶۰۰ پیکسل یک ستون.

اشتباه رایج مبتدی‌ها

فقط کل صفحه را کوچک کردن برای موبایل
چرا اشتباه است؟ متن و دکمه‌ها غیرقابل استفاده می‌شوند.
چه می‌بینی؟ تجربهٔ موبایل بد
درست: چیدمان را با media عوض کن
معیار تمام‌شدن درس: در عرض کم مرورگر، دو ستون به یک ستون تبدیل شود.
جمع‌بندی
  • گرید برای شبکه
  • fr سهم انعطاف
  • media برای موبایل

گام عملی — همین الان

  1. سه ستون برای صفحهٔ عریض تعریف کن.
