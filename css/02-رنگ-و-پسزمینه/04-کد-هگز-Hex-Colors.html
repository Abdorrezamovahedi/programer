کد هگز رنگ در CSS

هدف این درس: بفهمی کد هگز چیست و بتوانی رنگ دقیق بسازی.

h1 { color: #0f172a; } p { color: #334155; } a { color: #0369a1; }
کد هگز با # شروع می‌شود و شش کاراکتر دارد (دو تا برای قرمز، دو تا سبز، دو تا آبی).
معیار تمام‌شدن درس: حداقل دو رنگ با کد هگز نوشته باشی.
جمع‌بندی
  • کد هگز دقیق‌ترین و رایج‌ترین روش در پروژه‌هاست
  • فرمت: #RRGGBB
  • می‌توانی از ابزارهای انتخاب رنگ مرورگر استفاده کنی

گام عملی

  1. یک عنوان با رنگ هگز تیره و یک بند با رنگ هگز خاکستری بنویس.
