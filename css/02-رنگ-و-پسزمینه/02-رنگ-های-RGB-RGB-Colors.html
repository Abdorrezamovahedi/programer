رنگ های RGB (RGB Colors)

هدف این درس: رنگ متن و پس‌زمینه را با نام، hex و rgb درست و خوانا تنظیم کنی.

پوشه: رنگ و پس‌زمینه  |  پیش‌نیاز: درس‌های قبلی «رنگ و پس‌زمینه».

مفهوم به زبان ساده

رنگ در CSS سه شکل رایج دارد: نام انگلیسی (red)، هگز (#rrggbb) و rgb(قرمز، سبز، آبی). color رنگ نوشته است؛ background-color رنگ سطح. خوانایی یعنی تضاد کافی بین متن و پس‌زمینه.

فهرست معرفی: رنگ و پس‌زمینه

قبل از جزئیات، همهٔ موارد این مبحث را یک‌جا ببین. بعد هر کدام را جداگانه با مثال می‌بینی.

نقشهٔ مبحث
  • color — رنگ متن.
  • background-color — رنگ سطح پشت محتوا.
  • hex — شکل #rrggbb.
  • rgb — rgb(قرمز، سبز، آبی) هر کدام ۰ تا ۲۵۵.
  • background-image — تصویر پس‌زمینه با url().
  • background-size — cover یا contain برای اندازه تصویر.

توضیح دانه‌به‌دانه با مثال

1. color

رنگ متن.

p { color: #0f172a; }

2. background-color

رنگ سطح پشت محتوا.

body { background-color: #f8fafc; }

3. hex

شکل #rrggbb.

color: #2563eb;

4. rgb

rgb(قرمز، سبز، آبی) هر کدام ۰ تا ۲۵۵.

color: rgb(37, 99, 235);

5. background-image

تصویر پس‌زمینه با url().

background-image: url("bg.jpg");

6. background-size

cover یا contain برای اندازه تصویر.

background-size: cover;

ساختار (Syntax)

color: #1e293b; background-color: #f8fafc; color: rgb(30, 41, 59);

مثال 1: سه روش رنگ

body { color: #0f172a; background-color: #f1f5f9; } .alert { color: rgb(185, 28, 28); background-color: #fef2f2; }
#0f172a: هگز شش‌رقمی: هر دو رقم یک کانال رنگ.
background-color: رنگ پشت متن؛ با color اشتباه نشود.
rgb(...): همان ایده با اعداد ۰ تا ۲۵۵.
.alert: پیام خطا: متن قرمز روی زمینه صورتی خیلی روشن.

اشتباه رایج مبتدی‌ها

color: 0f172a;
چرا اشتباه است؟ هگز بدون #.
چه می‌بینی؟ رنگ اعمال نمی‌شود
درست: color: #0f172a;
معیار تمام‌شدن درس: یک صفحه با متن تیره، پس‌زمینه روشن، و یک باکس هشدار قرمز بسازی.
جمع‌بندی
  • # برای هگز
  • color ≠ background
  • تضاد برای خوانایی

گام عملی — همین الان

  1. rgb را به hex نزدیک ترجمه کن.
  2. عمداً متن خاکستری روی خاکستری بگذار و ببین چرا بد است.
