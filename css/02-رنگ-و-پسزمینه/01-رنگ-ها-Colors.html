رنگ‌ها در CSS

هدف این درس: بتوانی رنگ متن و عناصر را با روش‌های مختلف مشخص کنی.

مفهوم به زبان ساده

با ویژگی color رنگ متن را عوض می‌کنیم. سه روش رایج وجود دارد:

p { color: red; } /* نام رنگ */ h1 { color: #0f172a; } /* کد هگز */ span { color: rgb(15, 23, 42); } /* RGB */
نام رنگ ساده‌ترین است. کد هگز و RGB کنترل دقیق‌تری می‌دهند.
معیار تمام‌شدن درس: بتوانی رنگ یک عنوان و یک بند را با دو روش مختلف عوض کنی.
جمع‌بندی
  • color رنگ متن را مشخص می‌کند
  • می‌توان از نام، هگز یا RGB استفاده کرد
  • هگز رایج‌ترین روش در پروژه‌های واقعی است

گام عملی

  1. رنگ یک h1 را با کد هگز تیره کن.
  2. رنگ یک پاراگراف را با نام رنگ عوض کن.
