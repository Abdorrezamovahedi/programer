اندازه پس زمینه (Background Size)

هدف این درس: رنگ و تصویر پس‌زمینه را کنترل کنی و بدانی size و repeat چه می‌کنند.

درس معرفی «رنگ و پس‌زمینه»: اگر هنوز فهرست کامل این مبحث را نخوانده‌ای، اول برو به رنگ حاشیه بیرونی (Outline Color) (همین پوشه — معمولاً اولین درس). آنجا همهٔ انواع/علامت‌ها یک‌جا معرفی شده‌اند.
پوشه: رنگ و پس‌زمینه  |  پیش‌نیاز: درس‌های قبلی «رنگ و پس‌زمینه».

مفهوم به زبان ساده

پس‌زمینه می‌تواند رنگ ساده یا تصویر باشد. background-image مسیر می‌خواهد داخل url(). size مشخص می‌کند تصویر چقدر بزرگ شود؛ repeat تکرار را کنترل می‌کند.

ساختار (Syntax)

background-color: #fff; background-image: url("bg.jpg"); background-size: cover;

مثال 1: تصویر تمام‌بخش

.hero { background-color: #0f172a; background-image: url("hero.jpg"); background-size: cover; background-position: center; background-repeat: no-repeat; min-height: 240px; }
background-color: اگر تصویر دیر لود شد، رنگ پشتیبان دیده می‌شود.
url(...): مسیر تصویر اجباری است.
cover: تصویر کل ناحیه را می‌پوشاند؛ ممکن است کمی برش بخورد.
no-repeat: کاشی نمی‌شود.
position: center: مرکز تصویر در مرکز بخش می‌ماند.

اشتباه رایج مبتدی‌ها

background-image: hero.jpg;
چرا اشتباه است؟ بدون url().
چه می‌بینی؟ تصویر نمی‌آید
درست: url("hero.jpg")
معیار تمام‌شدن درس: یک .hero با رنگ پشتیبان و cover بسازی.
جمع‌بندی
  • url الزامی
  • cover برای پوشش
  • رنگ پشتیبان مفید است

گام عملی — همین الان

  1. size را contain کن و فرق را ببین.
  2. repeat را repeat-x امتحان کن.

اگر گیر کردی فقط همان خط خطا را با «اشتباه رایج» مقایسه کن. با تایپ و اجرا جا می‌افتد.
