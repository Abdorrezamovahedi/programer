5. RGB 6. شفافیت

شفافیت در CSS

هدف این درس: بتوانی شفافیت یک عنصر را کنترل کنی.

.box { background-color: rgba(15, 23, 42, 0.8); opacity: 0.9; }
opacity روی کل عنصر اثر می‌گذارد. rgba فقط روی رنگ (مقدار چهارم شفافیت است).
معیار تمام‌شدن درس: یک جعبه نیمه‌شفاف ساخته باشی.
جمع‌بندی
  • opacity از ۰ (کامل شفاف) تا ۱ (کامل مات)
  • rgba برای شفاف کردن فقط رنگ مفید است

گام عملی

  1. یک جعبه با پس‌زمینه rgba نیمه‌شفاف بساز.
