نام رنگ‌ها در CSS

هدف این درس: با نام‌های آماده رنگ در CSS آشنا شوی و از آن‌ها استفاده کنی.

h1 { color: navy; } p { color: dimgray; } .alert { color: crimson; }
نام‌هایی مثل red, blue, green, navy, crimson, dimgray و ... از قبل تعریف شده‌اند.
معیار تمام‌شدن درس: حداقل سه عنصر را با نام رنگ مختلف استایل داده باشی.
جمع‌بندی
  • CSS بیش از ۱۴۰ نام رنگ آماده دارد
  • برای شروع و تست سریع عالی هستند
  • در پروژه‌های واقعی بیشتر از کد هگز استفاده می‌شود

گام عملی

  1. سه عنوان با سه نام رنگ مختلف بنویس.
  2. یک کلاس هشدار با رنگ crimson بساز.
