4. کد هگز 5. RGB

رنگ RGB در CSS

هدف این درس: بتوانی با rgb رنگ دقیق بسازی.

h1 { color: rgb(15, 23, 42); } p { color: rgb(51, 65, 85); }
هر عدد از ۰ تا ۲۵۵ است: قرمز، سبز، آبی.
معیار تمام‌شدن درس: حداقل دو رنگ با rgb نوشته باشی.
جمع‌بندی
  • فرمت: rgb(قرمز, سبز, آبی)
  • هر مقدار بین ۰ تا ۲۵۵
  • برای کنترل دقیق رنگ مفید است

گام عملی

  1. یک عنوان و یک بند را با دو رنگ rgb مختلف استایل بده.
