رنگ حاشیه بیرونی (Outline Color)

هدف این درس: فرق padding و margin و border را در عمل ببینی.

پوشه: رنگ و پس‌زمینه  |  نقش: درس معرفی مبحث

مفهوم به زبان ساده

هر عنصر یک جعبه است: محتوا، فاصله داخلی، لبه، فاصله بیرونی.

فهرست معرفی: مدل جعبه

همهٔ موارد این مبحث را یک‌جا در کد ببین. هر خط با کامنت توضیح داده شده است.

/* مدل جعبه */ .box { padding: 16px; /* داخل لبه تا محتوا */ border: 1px solid #e2e8f0; /* خود لبه */ margin-bottom: 12px; /* بیرون لبه تا همسایه */ border-radius: 8px; /* گوشه گرد */ box-sizing: border-box; /* width قابل‌پیش‌بینی‌تر */ }
توضیح خط‌به‌خط همین مثال
  1. خط 1: /* مدل جعبه */ — این خط توضیح (کامنت) است و اجرا نمی‌شود.
  2. خط 2: .box { — یک انتخابگر را باز می‌کند تا استایل‌هایش را بنویسیم.
  3. خط 3: padding: 16px; /* داخل لبه تا محتوا */ — ویژگی «padding» را مقداردهی می‌کند.
  4. خط 4: border: 1px solid #e2e8f0; /* خود لبه */ — ویژگی «border» را مقداردهی می‌کند.
  5. خط 5: margin-bottom: 12px; /* بیرون لبه تا همسایه */ — ویژگی «margin-bottom» را مقداردهی می‌کند.
  6. خط 6: border-radius: 8px; /* گوشه گرد */ — ویژگی «border-radius» را مقداردهی می‌کند.
  7. خط 7: box-sizing: border-box; /* width قابل‌پیش‌بینی‌تر */ — ویژگی «box-sizing» را مقداردهی می‌کند.
  8. خط 8: } — پایان بلوک استایل.

مثال 1: دو کارت

.card { padding: 16px; margin-bottom: 12px; border: 1px solid #ddd; }
توضیح خط‌به‌خط همین مثال
  1. خط 1: .card { — یک انتخابگر را باز می‌کند تا استایل‌هایش را بنویسیم.
  2. خط 2: padding: 16px; — ویژگی «padding» را مقداردهی می‌کند.
  3. خط 3: margin-bottom: 12px; — ویژگی «margin-bottom» را مقداردهی می‌کند.
  4. خط 4: border: 1px solid #ddd; — ویژگی «border» را مقداردهی می‌کند.
  5. خط 5: } — پایان بلوک استایل.
padding: نفس داخل کارت.
margin-bottom: فاصله با کارت بعدی.
border: لبه.

اشتباه رایج مبتدی‌ها

/* فقط padding برای جدا کردن دو کارت */
توضیح خط‌به‌خط همین مثال
  1. خط 1: /* فقط padding برای جدا کردن دو کارت */ — این خط توضیح (کامنت) است و اجرا نمی‌شود.
چرا اشتباه است؟ padding داخل است.
چه می‌بینی؟ از بیرون می‌چسبند
درست: margin بین کارت‌ها
معیار تمام‌شدن درس: دو جعبه با margin جدا از هم ببینی.
جمع‌بندی
  • padding داخل
  • margin بیرون
  • border لبه
