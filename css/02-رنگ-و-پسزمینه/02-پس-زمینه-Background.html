پس‌زمینه در CSS

هدف این درس: بتوانی رنگ پس‌زمینه عناصر را تنظیم کنی.

body { background-color: #f8fafc; } .card { background-color: white; padding: 1rem; }
background-color رنگ پشت عنصر را مشخص می‌کند.
معیار تمام‌شدن درس: رنگ پس‌زمینه body و یک جعبه را عوض کرده باشی.
جمع‌بندی
  • background-color رنگ پس‌زمینه را تنظیم می‌کند
  • می‌توان از نام رنگ یا کد هگز استفاده کرد

گام عملی

  1. رنگ پس‌زمینه صفحه را روشن کن.
  2. یک div با پس‌زمینه متفاوت بساز.
