پس‌زمینه در CSS

هدف این درس: بتوانی رنگ پس‌زمینه عناصر را تنظیم کنی.

body { background-color: #f8fafc; } .card { background-color: white; padding: 1rem; }
توضیح خط‌به‌خط همین مثال
  1. خط 1: body { — یک انتخابگر را باز می‌کند تا استایل‌هایش را بنویسیم.
  2. خط 2: background-color: #f8fafc; — ویژگی «background-color» را مقداردهی می‌کند.
  3. خط 3: } — پایان بلوک استایل.
  4. خط 4: .card { — یک انتخابگر را باز می‌کند تا استایل‌هایش را بنویسیم.
  5. خط 5: background-color: white; — ویژگی «background-color» را مقداردهی می‌کند.
  6. خط 6: padding: 1rem; — ویژگی «padding» را مقداردهی می‌کند.
  7. خط 7: } — پایان بلوک استایل.
background-color رنگ پشت عنصر را مشخص می‌کند.
معیار تمام‌شدن درس: رنگ پس‌زمینه body و یک جعبه را عوض کرده باشی.
جمع‌بندی
  • background-color رنگ پس‌زمینه را تنظیم می‌کند
  • می‌توان از نام رنگ یا کد هگز استفاده کرد

گام عملی

  1. رنگ پس‌زمینه صفحه را روشن کن.
  2. یک div با پس‌زمینه متفاوت بساز.
