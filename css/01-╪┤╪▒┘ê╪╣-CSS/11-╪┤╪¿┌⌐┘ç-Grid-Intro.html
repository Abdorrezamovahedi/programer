معرفی شبکه (Grid)

هدف این درس: بفهمی Grid چیست و بتوانی یک شبکه ساده دو ستونی بسازی.

مفهوم به زبان ساده

اگر فلکس‌باکس مثل یک ردیف قفسه باشد، Grid مثل یک جدول کامل با ردیف و ستون است. برای چیدمان‌های دوبعدی (هم ردیف و هم ستون) عالی است.

اولین مثال

.container { display: grid; grid-template-columns: 1fr 1fr; gap: 1rem; }
display: grid → حالت شبکه را فعال می‌کند.
grid-template-columns: 1fr 1fr → دو ستون مساوی می‌سازد.
gap → فاصله بین خانه‌ها.

تفاوت ساده با فلکس‌باکس

  • فلکس‌باکس: بیشتر برای یک ردیف یا یک ستون
  • Grid: برای چیدمان همزمان ردیف و ستون
معیار تمام‌شدن درس: بتوانی یک container با display: grid و دو ستون بسازی.
جمع‌بندی
  • display: grid شبکه دوبعدی می‌سازد
  • grid-template-columns تعداد و اندازه ستون‌ها را مشخص می‌کند
  • 1fr یعنی یک واحد مساوی از فضای موجود
  • Grid برای صفحه‌بندی کامل بسیار قدرتمند است

گام عملی

  1. یک شبکه سه ستونی با gap مناسب بساز.
  2. چند جعبه رنگی داخل آن قرار بده و نتیجه را ببین.
