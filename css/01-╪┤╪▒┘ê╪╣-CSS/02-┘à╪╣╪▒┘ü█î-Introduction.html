معرفی CSS — اولین قدم

هدف این درس: بفهمی CSS چیست و بتوانی اولین قانون CSS را بنویسی تا رنگ متن را عوض کنی.

پوشه: شروع CSS  |  نقش: درس معرفی مبحث

مفهوم به زبان ساده

فرض کن HTML اسکلت یک خانه است. HTML می‌گوید: «اینجا یک بند متن است» یا «اینجا یک دکمه است». اما ظاهر آن را مشخص نمی‌کند. CSS مثل رنگ‌آمیزی، کاغذدیواری و چیدمان مبلمان است. با CSS می‌گویی این متن چه رنگی باشد، چقدر بزرگ باشد، فاصله خطوط چقدر باشد و پس‌زمینه چه شکلی داشته باشد.

به زبان خیلی ساده:
HTML = چه چیزی وجود دارد
CSS = آن چیز چه شکلی باشد

اولین قانون CSS چگونه نوشته می‌شود؟

هر قانون CSS از دو بخش اصلی تشکیل شده:

  • انتخاب‌گر (Selector): می‌گوید روی کدام عنصر کار کن (مثلاً همه بندها)
  • بلوک ویژگی‌ها: داخل آکولاد { } می‌نویسی چه تغییراتی اعمال شود

همه موارد این مبحث را یک‌جا در کد ببین. هر خط با کامنت توضیح داده شده است:

/* یک قانون CSS = انتخاب‌گر + ویژگی‌ها */ p { /* همهٔ بندهای متن (تگ p) را انتخاب کن */ color: #1e293b; /* رنگ متن را تیره کن */ line-height: 1.8; /* فاصله بین خطوط را بیشتر کن تا خواناتر شود */ font-size: 1.05rem; /* اندازه نوشته را کمی بزرگ‌تر از حالت عادی کن */ }
نکته مهم درباره ; و }:
هر ویژگی با علامت نقطه‌ویرگول (;) تمام می‌شود.
کل بلوک ویژگی‌ها با آکولاد بسته (}) تمام می‌شود.
اگر این دو را فراموش کنی، استایل اعمال نمی‌شود.

مثال ۱: اعمال روی صفحه

بیایید یک قانون ساده بنویسیم که رنگ متن و پس‌زمینه بندها را تغییر دهد:

p { color: #0f172a; background-color: #f8fafc; }
خط ۱: با نوشتن p می‌گوییم: «روی همه تگ‌های p کار کن».
خط ۲: رنگ متن را به یک خاکستری خیلی تیره تغییر می‌دهیم.
خط ۳: پس‌زمینه را روشن می‌کنیم تا متن راحت‌تر خوانده شود.

اشتباه رایج مبتدی‌ها

خیلی از افراد تازه‌کار این کد را می‌نویسند و تعجب می‌کنند چرا هیچ اتفاقی نمی‌افتد:

p { color: red
چرا اشتباه است؟ هم علامت ; بعد از red جا افتاده و هم آکولاد بسته } وجود ندارد.
چه می‌بینی؟ هیچ استایلی اعمال نمی‌شود و صفحه مثل قبل می‌ماند.
شکل درست:
p { color: red; }
معیار تمام‌شدن این درس:
باید بتوانی رنگ یک بند متن را در مرورگر عوض‌شده ببینی. اگر رنگ تغییر کرد، درس را درست فهمیده‌ای.
جمع‌بندی این درس
  • CSS ظاهر عناصر HTML را کنترل می‌کند.
  • هر قانون از انتخاب‌گر + بلوک ویژگی‌ها تشکیل شده است.
  • ویژگی color رنگ متن را عوض می‌کند.
  • هر ویژگی با ; تمام می‌شود و بلوک با } بسته می‌شود.
  • اگر ; یا } را فراموش کنی، استایل کار نمی‌کند.

گام عملی — همین الان انجام بده

  1. در مثال بالا، مقدار font-size را اضافه کن و آن را بزرگ‌تر از حالت عادی قرار بده (مثلاً 1.2rem).
  2. رنگ متن را به رنگ دلخواه خودت تغییر بده و نتیجه را در مرورگر ببین.

اگر گیر کردی، همان خط کد را با توضیح زیر مثال مقایسه کن. عجله نکن؛ همین تمرین‌های کوچک باعث می‌شوند مفهوم در ذهنت بنشیند.
