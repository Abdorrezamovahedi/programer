شاخص Z (Z-index)

هدف این درس: ویژگی مربوط به «شاخص Z» را روی یک بخش صفحه آزمایش کنی.

پوشه: چیدمان پایه  |  پیش‌نیاز: درس‌های قبلی همین پوشه («چیدمان پایه») را با تایپ و اجرا خوانده باشی.

مفهوم به زبان ساده

در این درس فقط «شاخص Z» را تمرین می‌کنی. یک کلاس بساز، مقدار را عوض کن، نتیجه را در مرورگر ببین. ابزار توسعه‌دهنده (F12) بهترین دوست توست.

ساختار (Syntax)

selector { property: value; }

مثال 1: جعبهٔ آزمایش

.demo { /* شاخص Z */ padding: 0.75rem; border-radius: 8px; border: 1px solid #cbd5e1; }
.demo: هدف تمرین.
padding: فاصله داخلی قابل‌دیدن.
radius: گوشه گرد.
