مفهوم به زبان ساده

صفحه بعد از بارگذاری به صورت درختی از عناصر در حافظه است (DOM). اول عنصر را پیدا می‌کنی، بعد می‌گویی وقتی رویدادی مثل کلیک رخ داد چه کند. اگر اسکریپت زودتر از دکمه اجرا شود، دکمه را پیدا نمی‌کند.

ساختار (Syntax)

document.querySelector("#btn") btn.addEventListener("click", () => { ... })

مثال 1: دکمه واکنش‌نشان‌دهنده

const btn = document.querySelector("#btn"); btn.addEventListener("click", () => { btn.textContent = "کلیک شد"; });
querySelector: اولین عنصر با این مشخصه را پیدا می‌کند.
addEventListener: شنوندهٔ رویداد.
textContent: متن روی دکمه عوض می‌شود.

اشتباه رایج مبتدی‌ها

اسکریپت در بالای صفحه قبل از دکمه
چرا اشتباه است؟ هنوز دکمه‌ای در صفحه ساخته نشده.
چه می‌بینی؟ Cannot read properties of null
درست: اسکریپت را پایین صفحه بگذار یا بعد از بارگذاری اجرا کن
معیار تمام‌شدن درس: یک دکمه با id در HTML بسازی و با کلیک متنش عوض شود.
جمع‌بندی
  • اول پیدا کن بعد واکنش
  • null یعنی پیدا نشد
  • جای اسکریپت مهم است
