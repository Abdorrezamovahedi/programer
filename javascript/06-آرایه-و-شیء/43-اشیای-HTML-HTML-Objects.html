اشیای HTML (HTML Objects)

هدف این درس: داده را با نام فیلد (نه فقط شماره) ذخیره و بخوانی.

پوشه: آرایه و شیء  |  پیش‌نیاز: درس‌های قبلی همین پوشه («آرایه و شیء») را با تایپ و اجرا خوانده باشی.

مفهوم به زبان ساده

شیء مجموعه‌ای از جفت‌های نام و مقدار است؛ مثل کارت مشخصات. با نقطه به فیلد دسترسی داری. JSON روش نوشتن همین داده به صورت متن برای جابه‌جایی است.

ساختار (Syntax)

const user = { name: "سارا", age: 20 }; user.name

مثال 1: کارت کاربر

const user = { name: "سارا", age: 20 }; console.log(user.name); const text = JSON.stringify(user); console.log(text);
{ }: ساخت شیء.
user.name: خواندن فیلد.
stringify: تبدیل به متن JSON.

اشتباه رایج مبتدی‌ها

console.log(user[0])
چرا اشتباه است؟ شیء مثل فهرست شماره‌ای نیست مگر خودت چنین کلیدی گذاشته باشی.
چه می‌بینی؟ undefined
درست: user.name یا user["name"]
معیار تمام‌شدن درس: یک شیء با دو فیلد بسازی و هر دو را log کنی.
جمع‌بندی
  • فیلد با نام
  • دسترسی با نقطه
  • JSON متن است
