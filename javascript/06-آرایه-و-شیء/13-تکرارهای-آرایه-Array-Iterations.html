تکرارهای آرایه (Array Iterations)

هدف این درس: چند مقدار را در یک فهرست نگه داری و رویشان کار کنی.

پوشه: آرایه و شیء  |  پیش‌نیاز: درس‌های قبلی همین پوشه («آرایه و شیء») را با تایپ و اجرا خوانده باشی.

مفهوم به زبان ساده

آرایه فهرستی مرتب از مقدارهاست. از صفر شماره‌گذاری می‌شود. می‌توانی به ته فهرست اضافه کنی یا از هر عضو نسخهٔ تازه‌ای بسازی.

فهرست معرفی: آرایه در JS

قبل از جزئیات، همهٔ موارد این مبحث را یک‌جا ببین. بعد هر کدام را جداگانه با مثال می‌بینی.

نقشهٔ مبحث
  • ساختن — با []
  • push — اضافه به انتها.
  • length — تعداد عضوها.
  • map — از هر عضو مقدار جدید می‌سازد → آرایهٔ جدید.
  • filter — فقط عضوهای شرط‌دار را نگه می‌دارد.

توضیح دانه‌به‌دانه با مثال

1. ساختن

با []

const a = [10, 20]; console.log(a[0]);

2. push

اضافه به انتها.

const a = [1]; a.push(2); console.log(a);

3. length

تعداد عضوها.

console.log([1,2,3].length);

4. map

از هر عضو مقدار جدید می‌سازد → آرایهٔ جدید.

console.log([1,2,3].map(n => n * 2));

5. filter

فقط عضوهای شرط‌دار را نگه می‌دارد.

console.log([1,2,3,4].filter(n => n % 2 === 0));

ساختار (Syntax)

const a = [1, 2, 3]; a.push(4); a.map(n => n * 2)

مثال 1: ساخت و تبدیل

const nums = [1, 2, 3]; nums.push(4); const doubled = nums.map(n => n * 2); console.log(nums, doubled);
[1,2,3]: فهرست اولیه.
push: ۴ به انتها اضافه می‌شود.
map: از هر عدد، دو برابرش را در فهرست جدید می‌سازد.

اشتباه رایج مبتدی‌ها

console.log(nums[10])
چرا اشتباه است؟ آن شماره وجود ندارد.
چه می‌بینی؟ undefined
درست: اول طول فهرست را با length ببین
معیار تمام‌شدن درس: یک فهرست نام بسازی و طول هر نام را با map به دست بیاوری.
جمع‌بندی
  • شماره از صفر
  • push اضافه می‌کند
  • map فهرست جدید می‌سازد

گام عملی — همین الان

  1. فقط عددهای زوج را با filter جدا کن.

اگر گیر کردی، فقط همان یک خطی که خطا می‌دهد را با بخش «اشتباه رایج» مقایسه کن. لازم نیست همه چیز را یک‌جا حفظ کنی — با تمرین جا می‌افتد.
