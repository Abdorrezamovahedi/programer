گواهینامه (Certificate)

هدف این درس: بر اساس یک شرط، یکی از دو مسیر را اجرا کنی.

پوشه: شرط و حلقه  |  پیش‌نیاز: درس‌های قبلی همین پوشه («شرط و حلقه») را با تایپ و اجرا خوانده باشی.

مفهوم به زبان ساده

گاهی برنامه باید تصمیم بگیرد. if یعنی اگر شرط درست بود این کار را بکن؛ else یعنی در غیر این صورت. شرط را داخل پرانتز و کارهای مربوط را داخل { } بنویس.

ساختار (Syntax)

if (شرط) { ... } else { ... }

مثال 1: سن مجاز

const age = 17; if (age >= 18) { console.log("مجاز"); } else { console.log("غیرمجاز"); }
توضیح خط‌به‌خط همین مثال
  1. خط 1: const age = 17; — یک متغیر در JavaScript تعریف می‌کند.
  2. خط 2: if (age >= 18) { — شرط را بررسی می‌کند؛ اگر درست باشد وارد این بخش می‌شود.
  3. خط 3: console.log("مجاز"); — پیام یا مقدار را در کنسول مرورگر چاپ می‌کند.
  4. خط 4: } else { — شروع یک بلوک جدید از دستورات.
  5. خط 5: console.log("غیرمجاز"); — پیام یا مقدار را در کنسول مرورگر چاپ می‌کند.
  6. خط 6: } — پایان این بلوک.
age >= 18: سؤال درست/نادرست.
شاخه if: اگر بله.
else: اگر نه.

اشتباه رایج مبتدی‌ها

if (x = 5) { }
توضیح خط‌به‌خط همین مثال
  1. خط 1: if (x = 5) { } — شرط را بررسی می‌کند؛ اگر درست باشد وارد این بخش می‌شود.
چرا اشتباه است؟ یک مساوی برای گذاشتن مقدار است نه مقایسه.
چه می‌بینی؟ تقریباً همیشه وارد if می‌شود
درست: if (x === 5)
معیار تمام‌شدن درس: برای یک نمره، پیام قبولی یا رد بنویسی.
جمع‌بندی
  • شرط در ()
  • بدنه در {}
  • برای مقایسه ===

گام عملی — همین الان

  1. یک else if برای سطح متوسط اضافه کن.

اگر گیر کردی، فقط همان یک خطی که خطا می‌دهد را با بخش «اشتباه رایج» مقایسه کن. لازم نیست همه چیز را یک‌جا حفظ کنی — با تمرین جا می‌افتد.
