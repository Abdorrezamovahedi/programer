مفهوم به زبان ساده

DOM همان HTML در حافظه است. اول عنصر را پیدا کن، بعد رویداد بده. اسکریپت باید بعد از وجود دکمه در صفحه اجرا شود.

فهرست معرفی: DOM و رویداد

همهٔ موارد این مبحث را یک‌جا در کد ببین. هر خط با کامنت توضیح داده شده است.

// ارتباط با صفحه const btn = document.querySelector("#btn"); // پیدا کردن عنصر btn.textContent = "کلیک شد"; // عوض کردن متن btn.addEventListener("click", () => { // واکنش به کلیک console.log("clicked"); });

مثال 1: کلیک

const btn = document.querySelector("#btn"); btn.addEventListener("click", () => { btn.textContent = "OK"; });
خط ۱: دکمه با id=btn پیدا می‌شود.
خط ۲: شنوندهٔ کلیک.
خط ۳: متن دکمه عوض می‌شود.

اشتباه رایج مبتدی‌ها

اسکریپت در head قبل از دکمه
چرا اشتباه است؟ عنصر هنوز نیست.
چه می‌بینی؟ null
درست: script ته body یا defer
معیار تمام‌شدن درس: دکمه‌ای که با کلیک متنش عوض شود بسازی.
