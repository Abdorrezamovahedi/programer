break (Break)

هدف این درس: یک کار را چند بار بدون کپی کردن کد تکرار کنی.

پوشه: شرط و حلقه  |  پیش‌نیاز: درس‌های قبلی همین پوشه («شرط و حلقه») را با تایپ و اجرا خوانده باشی.

مفهوم به زبان ساده

حلقه برای تکرار است. for وقتی می‌دانی چند دور لازم است مناسب است. سه قسمت دارد: شروع، شرط ادامه، و قدم بعد از هر دور. اگر قدم را فراموش کنی ممکن است برای همیشه تکرار شود.

ساختار (Syntax)

for (let i = 1; i <= 3; i++) { ... }

مثال 1: سه دور

for (let i = 1; i <= 3; i++) { console.log("دور", i); }
let i = 1: شمارنده از یک.
i <= 3: تا وقتی این درست است ادامه بده.
i++: بعد از هر دور یکی اضافه کن.

اشتباه رایج مبتدی‌ها

let i = 0; while (i < 3) { console.log(i); }
چرا اشتباه است؟ i زیاد نمی‌شود؛ شرط همیشه درست می‌ماند.
چه می‌بینی؟ صفحه ممکن است قفل شود
درست: داخل حلقه i++ بگذار
معیار تمام‌شدن درس: اعداد ۱ تا ۵ را با حلقه در کنسول ببینی.
جمع‌بندی
  • حلقه = تکرار
  • قدم را فراموش نکن
  • برای شروع for ساده‌تر است

گام عملی — همین الان

  1. جمع اعداد ۱ تا ۱۰ را با حلقه حساب کن.

موضوع این درس: break Break در مسیر جاوااسکریپت.

حلقه برای تکرار یک کار است تا وقتی شرط برقرار باشد یا روی مجموعه‌ای از آیتم‌ها حرکت کنی.

کاربرد واقعی

وقتی پروژه‌ای می‌نویسی، بارها به «break Break» برمی‌خوری. اگر همین‌جا خوب یادش بگیری، در درس‌های بعدی و پروژه‌های کوچک سریع‌تر جلو می‌روی.

روش یادگیری این درس

  1. عنوان و هدف درس را یک‌بار با صدای خودت بگو.

  3. یک مقدار یا شرط را تغییر بده و خروجی جدید را ببین.
  4. یک تمرین ۳۰ ثانیه‌ای برای خودت تعریف کن و حل کن.
