تعریف تابع (Function Definitions)

هدف این درس: یک کار را داخل تابع بگذاری و نتیجه را برگردانی.

پوشه: توابع  |  پیش‌نیاز: درس‌های قبلی همین پوشه («توابع») را با تایپ و اجرا خوانده باشی.

مفهوم به زبان ساده

تابع یک دستورالعمل نام‌دار است. ورودی می‌گیرد، کار می‌کند، و با return نتیجه می‌دهد. اگر return نباشد، نتیجه خالی (undefined) است.

ساختار (Syntax)

function add(a, b) { return a + b; }

مثال 1: جمع و ضرب

function add(a, b) { return a + b; } const mul = (a, b) => a * b; console.log(add(2, 3), mul(2, 3));
function add: تعریف تابع.
return: خروجی را به بیرون می‌دهد.
=>: شکل کوتاه برای تابع‌های ساده.

اشتباه رایج مبتدی‌ها

function f(x) { x * 2; } console.log(f(3));
چرا اشتباه است؟ حساب شده ولی برگردانده نشده.
چه می‌بینی؟ undefined
درست: return x * 2;
معیار تمام‌شدن درس: تابعی بنویسی که میانگین دو عدد را برگرداند و آن را صدا بزنی.
جمع‌بندی
  • تابع کار را بسته‌بندی می‌کند
  • return نتیجه است
  • بدون return نتیجه خالی است

گام عملی — همین الان

  1. تابع بدون ورودی که یک پیام چاپ کند.

اگر گیر کردی، فقط همان یک خطی که خطا می‌دهد را با بخش «اشتباه رایج» مقایسه کن. لازم نیست همه چیز را یک‌جا حفظ کنی — با تمرین جا می‌افتد.
