کجا JavaScript را قرار دهیم؟

هدف این درس: سه روش قرار دادن کد JavaScript را بشناسی و بهترین روش را بدانی.

روش ۱: داخل تگ script

<script> console.log("سلام"); </script>

روش ۲: فایل خارجی (پیشنهادی)

<script src="script.js"></script>
کد را در فایل جدا با پسوند .js بنویس و با این تگ وصل کن. تمیزتر و حرفه‌ای‌تر است.

محل قرارگیری

معمولاً تگ script را قبل از بسته شدن body می‌گذارند تا صفحه اول لود شود و بعد اسکریپت اجرا شود.

معیار تمام‌شدن درس: بتوانی یک فایل .js بسازی و آن را به HTML وصل کنی.
جمع‌بندی
  • می‌توانی کد را داخل script یا فایل خارجی بنویسی
  • فایل خارجی روش بهتر و تمیزتری است
  • معمولاً script را آخر body قرار می‌دهند

گام عملی

  1. یک فایل script.js بساز و یک console.log در آن بنویس.
  2. آن را به صفحه HTML وصل کن و نتیجه را در Console ببین.
