ساختار نوشتاری JavaScript

هدف این درس: قواعد اصلی نوشتن کد در JavaScript را بشناسی.

نقطه‌ویرگول

let x = 10; console.log(x);
توضیح خط‌به‌خط همین مثال
  1. خط 1: let x = 10; — یک متغیر در JavaScript تعریف می‌کند.
  2. خط 2: console.log(x); — پیام یا مقدار را در کنسول مرورگر چاپ می‌کند.
در JavaScript معمولاً هر دستور با ; تمام می‌شود (هرچند گاهی اختیاری است، بهتر است بنویسی).

حروف بزرگ و کوچک مهم است

let name = "Ali"; // console.log(Name); // خطا می‌دهد
توضیح خط‌به‌خط همین مثال
  1. خط 1: let name = "Ali"; — یک متغیر در JavaScript تعریف می‌کند.
  2. خط 2: // console.log(Name); // خطا می‌دهد — این خط توضیح (کامنت) است و اجرا نمی‌شود.
معیار تمام‌شدن درس: چند دستور ساده با ; درست بنویسی و اجرا کنی.
جمع‌بندی
  • معمولاً دستورها با ; تمام می‌شوند
  • حروف بزرگ و کوچک مهم هستند
  • کد را مرتب و خوانا بنویس

گام عملی

  1. سه دستور ساده با console.log بنویس.
  2. عمداً حروف بزرگ/کوچک را اشتباه بنویس و خطا را ببین.
