دستورات خطا (Error Statements)

هدف این درس: اولین دستور جاوااسکریپت را در کنسول مرورگر اجرا کنی.

پوشه: شروع JavaScript  |  پیش‌نیاز: درس‌های قبلی همین پوشه («شروع JavaScript») را با تایپ و اجرا خوانده باشی.

مفهوم به زبان ساده

جاوااسکریپت زبانی است که مرورگر می‌فهمد تا صفحه زنده شود: کلیک، محاسبه، پیام. برای شروع، کنسول مرورگر را باز کن (معمولاً F12 و تب Console) و دستور بنویس. console.log چیزی را در همان کنسول نشان می‌دهد تا بفهمی برنامه چه می‌کند.

ساختار (Syntax)

console.log("سلام");

مثال 1: اولین پیام‌ها

console.log("سلام"); console.log(2 + 3); const name = "سارا"; console.log(name);
پیام متنی: رشته داخل " (دابل‌کوتیشن).
2 + 3: حساب می‌کند و ۵ را نشان می‌دهد.
const name: یک نام برای نگه داشتن مقدار.
log(name): محتوای آن نام را نشان می‌دهد.

اشتباه رایج مبتدی‌ها

console.log(salam)
چرا اشتباه است؟ بدون " (دابل‌کوتیشن)، مرورگر دنبال متغیری به نام salam می‌گردد.
چه می‌بینی؟ ReferenceError
درست: console.log("salam")
معیار تمام‌شدن درس: کنسول را باز کنی و دو پیام جدا ببینی.
جمع‌بندی
  • F12 → Console
  • log برای دیدن نتیجه
  • متن داخل " (دابل‌کوتیشن)

گام عملی — همین الان

  1. یک جمع دیگر را log کن.
  2. عمداً بدون " (دابل‌کوتیشن) بنویس و خطا را بخوان.

اگر گیر کردی، فقط همان یک خطی که خطا می‌دهد را با بخش «اشتباه رایج» مقایسه کن. لازم نیست همه چیز را یک‌جا حفظ کنی — با تمرین جا می‌افتد.
