خطاها: مقدمه (Errors Intro)

هدف این درس: اولین دستورها را در Console اجرا کنی.

پوشه: شروع JavaScript  |  نقش: درس معرفی مبحث

مفهوم به زبان ساده

JavaScript را مرورگر اجرا می‌کند تا صفحه تعاملی شود. console.log برای دیدن مقدار هنگام یادگیری است.

فهرست معرفی: شروع JS

همهٔ موارد این مبحث را یک‌جا در کد ببین. هر خط با کامنت توضیح داده شده است.

// خروجی در Console مرورگر (F12) console.log("سلام"); // چاپ متن console.log(2 + 3); // چاپ نتیجهٔ حساب const name = "سارا"; // ثابت نام console.log(name); // چاپ مقدار متغیر

مثال 1: متن و عدد

console.log("hi"); console.log(10 / 2); let n = 1; n = 2; console.log(n);
خط ۱: متن در کنسول.
خط ۲: حاصل تقسیم → ۵.
خط ۳: متغیر قابل تغییر.
خط ۴: مقدار عوض شد.
خط ۵: چاپ ۲.

اشتباه رایج مبتدی‌ها

console.log(salam)
چرا اشتباه است؟ بدون " (دابل‌کوتیشن) نام متغیر است.
چه می‌بینی؟ ReferenceError
درست: console.log("salam")
معیار تمام‌شدن درس: دو log در Console ببینی.
جمع‌بندی
  • F12 → Console
  • " (دابل‌کوتیشن) برای متن
  • log برای دیدن

گام عملی — همین الان

  1. یک جمع و یک متن log کن.
