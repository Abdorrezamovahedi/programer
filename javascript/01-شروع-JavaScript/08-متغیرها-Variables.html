متغیرها در JavaScript

هدف این درس: بفهمی متغیر چیست و بتوانی با let و const مقدار ذخیره کنی.

مفهوم به زبان ساده

متغیر مثل جعبه‌ای است که یک نام دارد و می‌توانی چیزی داخلش بگذاری و بعداً استفاده کنی.

let name = "علی"; const age = 30; console.log(name); console.log(age);
let برای مقادیری که ممکن است بعداً عوض شوند.
const برای مقادیری که نباید عوض شوند.

تغییر مقدار با let

let score = 10; score = 15; console.log(score); // 15
معیار تمام‌شدن درس: بتوانی یک متغیر با let و یک متغیر با const بسازی و چاپ کنی.
جمع‌بندی
  • متغیر نامی برای نگهداری مقدار است
  • let قابل تغییر است
  • const معمولاً ثابت می‌ماند

گام عملی

  1. نام و سن خودت را با let و const ذخیره کن و چاپ کن.
  2. مقدار یک متغیر let را عوض کن و دوباره چاپ کن.
