JavaScript چیست؟

هدف این درس: بفهمی JavaScript چیست و چه نقشی در صفحات وب دارد.

مفهوم به زبان خیلی ساده

HTML اسکلت صفحه است. CSS ظاهر آن را زیبا می‌کند. JavaScript به صفحه جان می‌دهد: می‌تواند به کلیک واکنش نشان دهد، محتوا را عوض کند، محاسبه انجام دهد و با سرور حرف بزند.

اولین دستور

console.log("سلام از جاوااسکریپت");
این دستور پیام را در Console مرورگر نشان می‌دهد. برای دیدن آن کلید F12 را بزن و به تب Console برو.
معیار تمام‌شدن درس: بتوانی با زبان خودت بگویی JavaScript چه کاری انجام می‌دهد و یک console.log ساده نوشته باشی.
جمع‌بندی
  • JavaScript صفحه را تعاملی می‌کند
  • در مرورگر اجرا می‌شود
  • console.log برای دیدن خروجی در Console است

گام عملی

  1. یک پیام دلخواه با console.log بنویس و در Console ببین.
  2. دو پیام پشت سر هم چاپ کن.
