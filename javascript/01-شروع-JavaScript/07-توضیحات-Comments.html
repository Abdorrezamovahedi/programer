توضیحات در JavaScript

هدف این درس: بتوانی کامنت تک‌خطی و چندخطی بنویسی.

// این یک کامنت تک‌خطی است console.log("سلام"); /* این یک کامنت چندخطی است */
توضیح خط‌به‌خط همین مثال
  1. خط 1: // این یک کامنت تک‌خطی است — این خط توضیح (کامنت) است و اجرا نمی‌شود.
  2. خط 2: console.log("سلام"); — پیام یا مقدار را در کنسول مرورگر چاپ می‌کند.
  3. خط 3: /* این یک کامنت — این خط توضیح (کامنت) است و اجرا نمی‌شود.
  4. خط 4: چندخطی است */ — این خط بخشی از منطق مثال را انجام می‌دهد.
مرورگر کامنت را اجرا نمی‌کند. فقط برای انسان است.
معیار تمام‌شدن درس: حداقل دو نوع کامنت نوشته باشی.
جمع‌بندی
  • تک‌خطی با //
  • چندخطی با /* */
  • برای توضیح و غیرفعال کردن موقت کد مفید است

گام عملی

  1. یک دستور را با کامنت موقتاً غیرفعال کن.
