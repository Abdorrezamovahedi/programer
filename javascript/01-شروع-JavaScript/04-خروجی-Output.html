خروجی در JavaScript

هدف این درس: روش‌های مختلف نشان دادن نتیجه را بشناسی.

۱. console.log (پرکاربردترین)

console.log("سلام"); console.log(2 + 3);
نتیجه در تب Console مرورگر (F12) دیده می‌شود. برای اشکال‌زدایی عالی است.

۲. alert

alert("یک پیام مهم");
یک پنجره باز می‌شود و تا وقتی کاربر تأیید نکند، ادامه نمی‌دهد.
معیار تمام‌شدن درس: بتوانی هم با console.log و هم با alert خروجی بگیری.
جمع‌بندی
  • console.log برای دیدن نتیجه در Console
  • alert برای پیام به کاربر
  • در یادگیری بیشتر از console.log استفاده کن

گام عملی

  1. چند پیام مختلف با console.log چاپ کن.
  2. یک alert با پیام دلخواه بنویس.
