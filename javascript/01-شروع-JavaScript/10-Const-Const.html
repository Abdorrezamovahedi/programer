Const (Const)

هدف این درس: فرق let و const را با مثال بفهمی.

پوشه: شروع JavaScript  |  نقش: درس معرفی مبحث

مفهوم به زبان ساده

const جلوی عوض شدن ارجاع را می‌گیرد. let وقتی مقدار باید عوض شود.

فهرست معرفی: let و const

همهٔ موارد این مبحث را یک‌جا در کد ببین. هر خط با کامنت توضیح داده شده است.

// اعلام متغیر let score = 0; // قابل تغییر score = 10; // انتساب مجدد OK const APP = "Demo"; // ثابت؛ دوباره APP = ... خطا // var قدیمی است — در کد جدید استفاده نکن

مثال 1: امتیاز

let score = 0; score += 5; const title = "Game"; console.log(score, title);
خط ۱: شروع از ۰.
خط ۲: ۵ تا اضافه.
خط ۳: نام بازی ثابت.
خط ۴: چاپ هر دو.

اشتباه رایج مبتدی‌ها

const n = 1; n = 2;
چرا اشتباه است؟ const دوباره انتساب نمی‌پذیرد.
چه می‌بینی؟ TypeError
درست: let n = 1; n = 2;
معیار تمام‌شدن درس: یک let و یک const بسازی و log کنی.
جمع‌بندی
  • let تغییر می‌کند
  • const ثابت است
  • از var پرهیز

گام عملی — همین الان

  1. عمداً const را عوض کن و خطا را بخوان.

اگر گیر کردی، همان خط کد را با توضیح زیر مثال مقایسه کن.
