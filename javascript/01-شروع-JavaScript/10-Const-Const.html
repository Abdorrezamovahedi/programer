9. Let 10. Const

کلمه کلیدی const

هدف این درس: بفهمی const چه زمانی استفاده می‌شود و چرا مفید است.

const PI = 3.14; const siteName = "MCD Code Up"; console.log(PI); console.log(siteName);
مقدار const را نمی‌توان دوباره نسبت داد. برای مقادیر ثابت عالی است.
معیار تمام‌شدن درس: دو ثابت با const تعریف کرده باشی.
جمع‌بندی
  • const برای مقادیری است که نباید عوض شوند
  • تلاش برای تغییر آن خطا می‌دهد
  • در کدهای مدرن زیاد استفاده می‌شود

گام عملی

  1. نام سایت و یک عدد ثابت با const تعریف کن و چاپ کن.
