کنترل جریان (Control Flow)

در جاوااسکریپت، «کنترل جریان» بخشی از رفتار صفحه است. JS بعد از HTML/CSS اجرا می‌شود و صفحه را زنده می‌کند.

کجا به درد می‌خورد؟ کلیک، فرم، محاسبه، درخواست به سرور؛ هر جا به «کنترل جریان» نیاز داری.

کنترل جریان چیست

«کنترل جریان» در جاوااسکریپت یک قطعه رفتار است. با console.log ببین چه می‌شود.

// کنترل جریان const value = 10; console.log("مقدار", value); console.log(typeof value);
خط 1: این خط کامنت است و اجرا نمی‌شود: «کنترل جریان».
خط 2: جعبه ثابت «value» را می‌سازد. const یعنی خود این اسم را نمی‌شود بعداً به چیز دیگری وصل کرد. اگر آرایه/شیء باشد، داخلش هنوز قابل تغییر است.
خط 3: در کنسول مرورگر چاپ می‌کند تا تو ببینی چه شده. کاربر عادی سایت این را نمی‌بیند. مقدار: "مقدار", value.
خط 4: در کنسول مرورگر چاپ می‌کند تا تو ببینی چه شده. کاربر عادی سایت این را نمی‌بیند. مقدار: typeof value.

مثال با شرط

مسیر برنامه را عوض کن.

const n = 7; if (n % 2 === 0) { console.log("زوج"); } else { console.log("فرد"); }
خط 1: جعبه ثابت «n» را می‌سازد. const یعنی خود این اسم را نمی‌شود بعداً به چیز دیگری وصل کرد. اگر آرایه/شیء باشد، داخلش هنوز قابل تغییر است.
خط 2: شرط را چک می‌کند. اگر درست باشد بلوک بعدی اجرا می‌شود. شرط: داخل پرانتز. «if (n % 2 === 0) {».
خط 3: در کنسول مرورگر چاپ می‌کند تا تو ببینی چه شده. کاربر عادی سایت این را نمی‌بیند. مقدار: "زوج".
خط 4: شروع یا پایان بلوک کد. «} else {».
خط 5: در کنسول مرورگر چاپ می‌کند تا تو ببینی چه شده. کاربر عادی سایت این را نمی‌بیند. مقدار: "فرد".
خط 6: آکولاد شروع یا پایان یک بلوک است. دستورهای داخل یک گروه می‌شوند.

مثال با حلقه

تکرار کار.

for (let i = 1; i <= 3; i++) { console.log(i, i * i); }
خط 1: حلقه تکرار. در for کلاسیک سه بخش است: شروع؛ شرط ادامه؛ افزایش. «for (let i = 1; i <= 3; i++) {».
خط 2: در کنسول مرورگر چاپ می‌کند تا تو ببینی چه شده. کاربر عادی سایت این را نمی‌بیند. مقدار: i, i * i.
خط 3: آکولاد شروع یا پایان یک بلوک است. دستورهای داخل یک گروه می‌شوند.

مثال با آرایه

چند مقدار.

const nums = [2, 4, 6]; const doubled = nums.map(x => x * 2); console.log(doubled);
خط 1: جعبه ثابت «nums» را می‌سازد. const یعنی خود این اسم را نمی‌شود بعداً به چیز دیگری وصل کرد. اگر آرایه/شیء باشد، داخلش هنوز قابل تغییر است.
خط 2: جعبه ثابت «doubled» را می‌سازد. const یعنی خود این اسم را نمی‌شود بعداً به چیز دیگری وصل کرد. اگر آرایه/شیء باشد، داخلش هنوز قابل تغییر است.
خط 3: در کنسول مرورگر چاپ می‌کند تا تو ببینی چه شده. کاربر عادی سایت این را نمی‌بیند. مقدار: doubled.

مثال با تابع

منطق را جمع کن.

function sum(arr) { return arr.reduce((a, b) => a + b, 0); } console.log(sum([1,2,3]));
خط 1: تابع «sum» را تعریف می‌کند. پرانتز جای ورودی است. آکولاد باز یعنی بدنه از اینجا شروع می‌شود.
خط 2: تابع پیکانی است: سمت چپ ورودی، سمت راست بعد از => کار تابع. کوتاه‌تر از function است. «return arr.reduce((a, b) => a + b, 0);».
خط 3: آکولاد شروع یا پایان یک بلوک است. دستورهای داخل یک گروه می‌شوند.
خط 4: در کنسول مرورگر چاپ می‌کند تا تو ببینی چه شده. کاربر عادی سایت این را نمی‌بیند. مقدار: sum([1,2,3]).

اشتباه رایج

== تبدیل نوع می‌کند؛ معمولاً === بگذار.

console.log(0 == "0"); console.log(0 === "0");
خط 1: در کنسول مرورگر چاپ می‌کند تا تو ببینی چه شده. کاربر عادی سایت این را نمی‌بیند. مقدار: 0 == "0".
خط 2: در کنسول مرورگر چاپ می‌کند تا تو ببینی چه شده. کاربر عادی سایت این را نمی‌بیند. مقدار: 0 === "0".
JS داخل مرورگر است. فایل را با زنده کردن صفحه ببین؛ بعضی چیزها بدون تگ HTML معنی ندارند.

اگر این درس سخت بود، درس قبلی همان زبان را یک‌بار دیگر بخوان. بعد همین «کنترل جریان» را با تغییر عدد یا متن مثال دوباره اجرا کن.

جمع‌بندی سریع
  • موضوع: کنترل جریان.
  • با console.log خروجی را ببین.
  • === برای مقایسه دقیق.
  • const را پیش‌فرض بگذار.
  • خطا را در کنسول بخوان نه حدس.
