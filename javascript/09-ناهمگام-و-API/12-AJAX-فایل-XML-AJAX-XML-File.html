مفهوم به زبان ساده

گاهی داده روی سرور دیگری است. fetch درخواست می‌فرستد. چون جواب طول می‌کشد، برنامه صبر می‌کند (await) تا صفحه قفل نشود. این الگو را قدم‌به‌قدم با مثال یاد بگیر.

ساختار (Syntax)

const res = await fetch(url); const data = await res.json();

مثال 1: یک درخواست نمونه

async function load() { try { const res = await fetch("https://jsonplaceholder.typicode.com/todos/1"); const data = await res.json(); console.log(data.title); } catch (e) { console.error("خطا", e); } } load();
async: اجازه می‌دهد داخل تابع await بنویسی.
await fetch: صبر تا پاسخ شبکه.
await res.json(): بدنه را به دادهٔ قابل استفاده تبدیل می‌کند.
try/catch: اگر شبکه قطع باشد برنامه نمی‌ترکد.

اشتباه رایج مبتدی‌ها

fetch(url).json()
چرا اشتباه است؟ اول باید پاسخ برسد؛ json روی خود پاسخ است.
چه می‌بینی؟ TypeError
درست: دو مرحله با await
معیار تمام‌شدن درس: همین مثال را با اینترنت اجرا کنی و یک عنوان در کنسول ببینی.
جمع‌بندی
  • شبکه زمان می‌برد
  • await صبر می‌کند
  • خطا را مدیریت کن
