منطقی (Logical)

مفهوم به زبان ساده

در JS ترجیح بده === به ==. + اگر یکی رشته باشد می‌چسباند نه جمع عددی.

فهرست معرفی: عملگرها

همهٔ موارد این مبحث را یک‌جا در کد ببین. هر خط با کامنت توضیح داده شده است.

// عملگرهای پرکاربرد JS console.log(3 + 2); // + جمع (روی رشته می‌چسباند) console.log(7 / 2); // / تقسیم console.log(2 ** 3); // ** توان console.log(5 === "5"); // === مقایسه سخت → false console.log(5 == "5"); // == با تبدیل نوع → true (گیج‌کننده) console.log(true && false); // and منطقی console.log(!false); // not
===: هم مقدار هم نوع را چک می‌کند — امن‌تر است.

مثال 1: دام + و ===

console.log(1 + 2); console.log("1" + 2); console.log(1 === "1"); console.log(1 == "1");
خط ۱: جمع عددی → ۳.
خط ۲: چسباندن → "12".
خط ۳: نوع فرق دارد → false.
خط ۴: تبدیل پنهان → true.

اشتباه رایج مبتدی‌ها

if (x = 5)
چرا اشتباه است؟ = انتساب است.
چه می‌بینی؟ منطق غلط
درست: if (x === 5)
معیار تمام‌شدن درس: فرق 1+2 و "1"+2 را خودت در کنسول ببینی.
جمع‌بندی
  • === پیش‌فرض
  • + حساس به نوع
  • && || !

  1. not یک مقایسه را امتحان کن.
