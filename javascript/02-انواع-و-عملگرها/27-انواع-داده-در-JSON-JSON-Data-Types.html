فهرست معرفی: انواع رایج در JavaScript

قبل از جزئیات، همهٔ موارد این مبحث را یک‌جا ببین. بعد هر کدام را جداگانه با مثال می‌بینی.

نقشهٔ مبحث
  • number — عدد صحیح یا اعشاری.
  • string — متن داخل " (دابل‌کوتیشن) یا `قالب`.
  • boolean — true یا false.
  • undefined — اعلام شده ولی مقدار نگرفته.
  • null — عمداً «خالی» گذاشته‌ای.
  • object — شیء یا آرایه (آرایه هم در typeof می‌گوید object).

توضیح دانه‌به‌دانه با مثال

1. number

عدد صحیح یا اعشاری.

console.log(typeof 3); console.log(typeof 3.14);

2. string

متن داخل " (دابل‌کوتیشن) یا `قالب`.

console.log(typeof "hi");

3. boolean

true یا false.

console.log(typeof true);

4. undefined

اعلام شده ولی مقدار نگرفته.

let x; console.log(x); // undefined

5. null

عمداً «خالی» گذاشته‌ای.

let y = null; console.log(y);

6. object

شیء یا آرایه (آرایه هم در typeof می‌گوید object).

console.log(typeof {a:1}); console.log(typeof [1,2]);

مرور سریع مثال 1

console.log(typeof 3); console.log(typeof 3.14);
number: عدد صحیح یا اعشاری.

مرور سریع مثال 2

console.log(typeof "hi");
string: متن داخل " (دابل‌کوتیشن) یا `قالب`.
