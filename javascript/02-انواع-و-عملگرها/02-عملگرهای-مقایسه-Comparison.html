عملگرهای مقایسه در JavaScript

هدف این درس: بتوانی دو مقدار را با هم مقایسه کنی.

console.log(5 > 3); // true console.log(5 === 5); // true console.log(5 == "5"); // true (فقط مقدار) console.log(5 === "5"); // false (مقدار و نوع)
توضیح خط‌به‌خط همین مثال
  1. خط 1: console.log(5 > 3); // true — پیام یا مقدار را در کنسول مرورگر چاپ می‌کند.
  2. خط 2: console.log(5 === 5); // true — پیام یا مقدار را در کنسول مرورگر چاپ می‌کند.
  3. خط 3: console.log(5 == "5"); // true (فقط مقدار) — پیام یا مقدار را در کنسول مرورگر چاپ می‌کند.
  4. خط 4: console.log(5 === "5"); // false (مقدار و نوع) — پیام یا مقدار را در کنسول مرورگر چاپ می‌کند.
=== هم مقدار و هم نوع را چک می‌کند و معمولاً توصیه می‌شود.
معیار تمام‌شدن درس: تفاوت == و === را فهمیده باشی.
جمع‌بندی
  • === مقایسه سخت‌گیرانه (پیشنهادی)
  • == مقایسه سست
  • > < >= <= برای بزرگ‌تر و کوچک‌تر

گام عملی

  1. چند مقایسه با === و == بنویس و نتیجه را ببین.
