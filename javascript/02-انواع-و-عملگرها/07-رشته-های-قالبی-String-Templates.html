رشته های قالبی (String Templates)

هدف این درس: نوع مقدار را بشناسی و بفهمی چرا بعضی جمع‌ها عجیب می‌شوند.

درس معرفی «انواع رایج در JavaScript»: اگر هنوز فهرست کامل این مبحث را نخوانده‌ای، اول برو به انواع داده در JSON (JSON Data Types) (همین پوشه — معمولاً اولین درس). آنجا همهٔ انواع/علامت‌ها یک‌جا معرفی شده‌اند.
پوشه: انواع و عملگرها  |  پیش‌نیاز: درس‌های قبلی همین پوشه («انواع و عملگرها») را با تایپ و اجرا خوانده باشی.

مفهوم به زبان ساده

عدد و متن فرق دارند. اگر متن "5" را با 1 جمع کنی، ممکن است بچسبد و بشود "51". برای حساب واقعی، متن عددی را به عدد تبدیل کن. typeof نوع را می‌گوید. قالب با ` و ${} متن و مقدار را قاطی می‌کند.

ساختار (Syntax)

typeof x Number("5") `سلام ${name}`

مثال 1: نوع و قالب

console.log(typeof 3); console.log(typeof "3"); console.log("5" + 1); console.log(Number("5") + 1); const user = "علی"; console.log(`سلام ${user}`);
typeof 3: عدد.
typeof "3": متن.
"5"+1: چسباندن → 51.
Number + 1: حساب واقعی → 6.
قالب: مقدار داخل متن قرار می‌گیرد.

اشتباه رایج مبتدی‌ها

if (x == "5")
چرا اشتباه است؟ مقایسهٔ شل ممکن است نوع را پنهانی عوض کند.
چه می‌بینی؟ منطق اشتباه پنهان
درست: از === استفاده کن
معیار تمام‌شدن درس: یک typeof و یک قالب متنی در کنسول اجرا کنی.
جمع‌بندی
  • متن و عدد فرق دارند
  • برای حساب Number کن
  • === امن‌تر است

گام عملی — همین الان

  1. Boolean("") را امتحان کن.
