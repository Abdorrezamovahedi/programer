عملگرهای منطقی در JavaScript

هدف این درس: بتوانی چند شرط را با هم ترکیب کنی.

let age = 20; let hasId = true; console.log(age >= 18 && hasId); // true console.log(age < 18 || hasId); // true console.log(!hasId); // false
&& یعنی «و»، || یعنی «یا»، ! یعنی «نقیض».
معیار تمام‌شدن درس: یک شرط ترکیبی با && یا || نوشته باشی.
جمع‌بندی
  • && هر دو شرط باید درست باشند
  • || کافی است یکی درست باشد
  • ! مقدار را برعکس می‌کند

گام عملی

  1. یک شرط ترکیبی برای ورود به سایت بنویس (سن و داشتن حساب).
