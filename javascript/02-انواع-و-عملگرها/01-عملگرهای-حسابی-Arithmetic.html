عملگرهای حسابی در JavaScript

هدف این درس: بتوانی محاسبات ساده را با عملگرها انجام بدهی.

console.log(10 + 5); // 15 console.log(10 - 3); // 7 console.log(4 * 6); // 24 console.log(20 / 4); // 5 console.log(17 % 5); // 2 (باقی‌مانده)
% باقی‌مانده تقسیم را می‌دهد.
معیار تمام‌شدن درس: هر پنج عملگر را امتحان کرده باشی.
جمع‌بندی
  • + جمع   - تفریق   * ضرب   / تقسیم   % باقی‌مانده
