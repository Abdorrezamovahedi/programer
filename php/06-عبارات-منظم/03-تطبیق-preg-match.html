تطبیق (preg_match)

هدف این درس: با یک الگوی کامل، قالب شناسهٔ سفارش را بررسی و نتیجهٔ preg_match را تفسیر کنی.

پیش‌نیاز: آشنایی با delimiterها و الگوی رقم در درس قبل.

مفهوم به زبان ساده

preg_match فقط اولین تطبیق را بررسی می‌کند: اگر الگو پیدا شود 1، اگر پیدا نشود 0 و در صورت خطای الگو false برمی‌گرداند. آرایهٔ سوم اختیاری است و بخش‌های پیدا‌شده را نگه می‌دارد.

ساختار (Syntax)

preg_match($pattern, $subject, $matches = [], $flags = 0, $offset = 0);

مثال: بررسی شناسهٔ سفارش

<?php $orderId = "INV-4821"; $pattern = '/^INV-\d{4}$/'; $result = preg_match($pattern, $orderId); if ($result === 1) { echo "شناسه معتبر است"; } elseif ($result === 0) { echo "قالب شناسه معتبر نیست"; } else { echo "الگوی جستجو خطا دارد"; } ?>
خروجی: شناسه معتبر است
^ و $: ابتدا و انتهای کل رشته را مشخص می‌کنند.
\d{4}: دقیقاً چهار رقم می‌خواهد.

اشتباه رایج

نتیجه را فقط به‌صورت شرطی بررسی نکن. مقدار 0 یعنی تطبیقی نیست، اما false یعنی اجرای الگو با خطا روبه‌رو شده است؛ این دو را با مقایسهٔ دقیق از هم جدا کن.
معیار پایان: شناسهٔ درست و نادرست را آزمایش کنی و هر سه حالت بازگشتی را بشناسی.
جمع‌بندی
  • preg_match اولین تطبیق را بررسی می‌کند.
  • مقدار بازگشتی میان 1، 0 و false تفاوت می‌گذارد.
  • لنگرهای ^ و $ کل رشته را محدود می‌کنند.

گام عملی — همین الان

  1. الگو را تغییر بده تا شناسه‌هایی با پیشوند ORD- و پنج رقم را بپذیرد.

برای یافتن همهٔ تطبیق‌ها در متن، درس بعدی دربارهٔ preg_match_all را بخوان.
