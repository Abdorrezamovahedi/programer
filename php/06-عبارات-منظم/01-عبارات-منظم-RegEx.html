عبارات منظم (RegEx)

هدف این درس: بفهمی الگوی منظم چگونه بخشی از متن را پیدا می‌کند و یک رقم را از شناسهٔ سفارش بیرون بکشی.

پیش‌نیاز: آشنایی با رشته‌ها و متغیرها در PHP کافی است.

مفهوم به زبان ساده

عبارت منظم الگویی برای توصیف متن است. در PHP با توابعی مثل preg_match از آن استفاده می‌کنیم. الگو معمولاً میان delimiterهایی مثل / نوشته می‌شود؛ مثلاً /\d+/ یعنی یک یا چند رقم. تابعی به نام regex() در PHP وجود ندارد.

ساختار (Syntax)

preg_match($pattern, $text, $matches);

مثال: پیدا کردن شمارهٔ سفارش

<?php $text = "شماره سفارش: 4821"; $found = preg_match('/\d+/', $text, $matches); if ($found === 1) { echo $matches[0]; } else { echo "شماره‌ای پیدا نشد"; } ?>
خروجی: 4821
/\d+/: یک یا چند رقم را پیدا می‌کند.
$matches[0]: متن کامل تطبیق‌یافته را نگه می‌دارد.

اشتباه رایج

الگو را بدون delimiter ننویس. در PHP الگو باید مانند /\d+/ delimiter داشته باشد؛ \d+ به‌تنهایی الگوی کامل این تابع نیست.
معیار پایان: بتوانی با preg_match یک عدد را از متن دلخواه پیدا کنی و حالت پیدا نشدن را هم بررسی کنی.
جمع‌بندی
  • الگو شکل متن مورد نظر را توصیف می‌کند.
  • delimiterها مرز الگو را مشخص می‌کنند.
  • preg_match اولین تطبیق را پیدا می‌کند.

گام عملی — همین الان

  1. الگو را طوری تغییر بده که فقط شناسه‌های چهاررقمی را پیدا کند.

درس بعدی: استفاده از الگو برای فیلترکردن چند رشته با preg_grep.
