جایگزینی با کال بک (preg_replace_callback)

هدف این درس: برای هر قیمت پیدا‌شده، با یک callback مقدار تازه محاسبه و جایگزین کنی.

پیش‌نیاز: آشنایی با preg_match_all و تابع‌های بی‌نام در PHP.

مفهوم به زبان ساده

در preg_replace_callback تابعی دریافت می‌شود که برای هر تطبیق اجرا می‌شود. این روش وقتی مفید است که جایگزین ثابت نباشد و از دادهٔ همان تطبیق محاسبه شود.

ساختار (Syntax)

preg_replace_callback($pattern, $callback, $subject, $limit = -1, $count = null, $flags = 0);

مثال: افزودن ۱۰ درصد به قیمت‌ها

<?php $invoice = "دفتر 15.00 و خودکار 5.00"; $updated = preg_replace_callback( '/\d+\.\d{2}/', function ($matches) { return number_format((float) $matches[0] * 1.1, 2); }, $invoice ); echo $updated; ?>
خروجی: دفتر 16.50 و خودکار 5.50
$matches[0]: هر قیمت کامل را به callback می‌دهد.
return: متن جایگزین همان تطبیق را برمی‌گرداند.

اشتباه رایج

از callback برای جایگزین ثابت استفاده نکن. اگر همهٔ تطبیق‌ها یک متن یکسان می‌خواهند، preg_replace ساده‌تر است.
معیار پایان: برای چند تطبیق، جایگزین متفاوتی محاسبه کنی و دلیل نیاز به callback را توضیح بدهی.
جمع‌بندی
  • callback برای هر تطبیق جداگانه اجرا می‌شود.
  • مقدار بازگشتی callback متن جایگزین است.
  • برای جایگزینی ثابت، preg_replace مناسب‌تر است.

گام عملی — همین الان

  1. callback را تغییر بده تا به هر قیمت به‌جای ۱۰ درصد، مبلغ ثابت ۲ واحد اضافه کند.

در درس بعد، با preg_split یک رشته را بر اساس الگو به چند بخش تقسیم می‌کنی.
