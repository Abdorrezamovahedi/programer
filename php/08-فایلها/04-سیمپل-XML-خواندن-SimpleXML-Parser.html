سیمپل XML: خواندن (SimpleXML Parser)

هدف این درس: با موضوع «سیمپل XML: خواندن» در حد یک اسکریپت کوچک آشنا شوی.

پوشه: فایل‌ها  |  پیش‌نیاز: درس‌های قبلی همین پوشه («فایل‌ها») را با تایپ و اجرا خوانده باشی.

مفهوم به زبان ساده

این درس روی «سیمپل XML: خواندن» تمرکز دارد. کوچک بنویس، اجرا کن، خروجی را ببین، بعد یک تغییر بده. سرور باید فایل PHP را اجرا کند.

ساختار (Syntax)

<?php ... ?>

مثال 1: قالب کوچک

<?php // سیمپل XML: خواندن $topic = "سیمپل XML: خواندن"; echo $topic; ?>
$: شروع نام متغیر.
echo: نمایش در خروجی.
