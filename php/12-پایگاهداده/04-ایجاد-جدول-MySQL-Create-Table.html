ایجاد جدول (MySQL Create Table)

هدف این درس: بفهمی دادهٔ پایدار در پایگاه‌داده با دستور امن خوانده می‌شود.

پوشه: پایگاه‌داده  |  پیش‌نیاز: درس‌های قبلی همین پوشه («پایگاه‌داده») را با تایپ و اجرا خوانده باشی.

مفهوم به زبان ساده

پایگاه‌داده برای نگه‌داشتن اطلاعات بعد از بستن برنامه است. خطر بزرگ این است که ورودی کاربر را داخل دستور SQL بچسبانی. روش درست: قالب دستور را جدا بنویسی و مقدار را جدا بفرستی.

ساختار (Syntax)

$st = $pdo->prepare("SELECT ... WHERE id = ?"); $st->execute([$id]);

مثال 1: ایدهٔ دستور امن

<?php // $st = $pdo->prepare("SELECT name FROM users WHERE id = ?"); // $st->execute([$id]); echo "مقدار را به دستور نچسبان؛ جدا بفرست"; ?>
prepare: قالب دستور با جای خالی.
execute: مقدار را جدا می‌فرستد.

اشتباه رایج مبتدی‌ها

چسباندن نام کاربر داخل رشتهٔ SQL
چرا اشتباه است؟ مهاجم می‌تواند دستور را عوض کند.
چه می‌بینی؟ سرقت یا خرابکاری اطلاعات
درست: همیشه مقدار را پارامتریک بفرست
معیار تمام‌شدن درس: بتوانی با زبان خودت بگویی چرا چسباندن ورودی به SQL خطرناک است.
جمع‌بندی
  • داده پایدار
  • پارامتر جدا
  • هرگز ورودی را به SQL نچسبان
