nl2br (nl2br)

در PHP، «nl2br» یک ابزار سمت سرور است. PHP روی سرور اجرا می‌شود و معمولاً HTML یا JSON برای مرورگر می‌فرستد.

کجا به درد می‌خورد؟ فرم، فایل، دیتابیس، API؛ هر جا به «nl2br» نیاز داری.

رشته در PHP

متن داخل ' یا ".

<?php $s = "PHP"; echo strlen($s); echo $s[0]; ?>
خط 1: شروع بلوک PHP. از اینجا به بعد سرور کد را اجرا می‌کند، نه اینکه همان متن را به مرورگر بدهد.
خط 2: متغیر «$s» در PHP با $ شروع می‌شود. مقدار سمت راست داخلش می‌رود: "PHP". = یعنی بگذار داخل جعبه.
خط 3: نتیجه را برای مرورگر می‌فرستد تا کاربر ببیند. چیزی که چاپ می‌شود: strlen($s). نقطه اگر باشد یعنی چند متن را به هم چسبانده.
خط 4: نتیجه را برای مرورگر می‌فرستد تا کاربر ببیند. چیزی که چاپ می‌شود: $s[0]. نقطه اگر باشد یعنی چند متن را به هم چسبانده.
خط 5: پایان بلوک PHP. بعد از این اگر HTML باشد، همان‌طور به مرورگر می‌رود.
