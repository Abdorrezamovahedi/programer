مفهوم به زبان ساده

این درس، درسِ معرفی «انواع داده در PHP» است. اول فهرست کامل را می‌بینی، بعد هر مورد جداگانه با مثال کوتاه. درس‌های بعدی همین موضوع جزئی‌تر می‌شوند و دیگر کل فهرست را تکرار نمی‌کنند.

فهرست معرفی: انواع داده در PHP

قبل از جزئیات، همهٔ موارد این مبحث را یک‌جا ببین. بعد هر کدام را جداگانه با مثال می‌بینی.

نقشهٔ مبحث
  • int — عدد صحیح.
  • float / double — عدد اعشاری.
  • string — متن.
  • bool — true یا false.
  • array — فهرست یا نقشهٔ کلید→مقدار.
  • null — بدون مقدار.

توضیح دانه‌به‌دانه با مثال

1. int

عدد صحیح.

<?php var_dump(10); ?>

2. float / double

عدد اعشاری.

<?php var_dump(3.5); ?>

3. string

متن.

<?php var_dump("سلام"); ?>

4. bool

true یا false.

<?php var_dump(true); ?>

5. array

فهرست یا نقشهٔ کلید→مقدار.

<?php var_dump([1, 2]); var_dump(["name" => "سارا"]); ?>

6. null

بدون مقدار.

<?php $x = null; var_dump($x); ?>

مرور سریع مثال 1

<?php var_dump(10); ?>
int: عدد صحیح.

مرور سریع مثال 2

<?php var_dump(3.5); ?>
float / double: عدد اعشاری.
