مناطق زمانی PHP (PHP Timezones)

هدف این درس: با موضوع «مناطق زمانی PHP» در حد یک اسکریپت کوچک آشنا شوی.

پوشه: تاریخ و زمان  |  پیش‌نیاز: درس‌های قبلی همین پوشه («تاریخ و زمان») را با تایپ و اجرا خوانده باشی.

مفهوم به زبان ساده

این درس روی «مناطق زمانی PHP» تمرکز دارد. کوچک بنویس، اجرا کن، خروجی را ببین، بعد یک تغییر بده. سرور باید فایل PHP را اجرا کند.

ساختار (Syntax)

<?php ... ?>

مثال 1: قالب کوچک

<?php // مناطق زمانی PHP $topic = "مناطق زمانی PHP"; echo $topic; ?>
توضیح خط‌به‌خط همین مثال
  1. خط 1: <?php — شروع بلوک کد PHP.
  2. خط 2: // مناطق زمانی PHP — این خط توضیح (کامنت) است و اجرا نمی‌شود.
  3. خط 3: $topic = "مناطق زمانی PHP"; — یک متغیر PHP را مقداردهی می‌کند.
  4. خط 4: echo $topic; — متن یا مقدار را در خروجی چاپ می‌کند.
  5. خط 5: ?> — این خط بخشی از منطق مثال را انجام می‌دهد.
$: شروع نام متغیر.
echo: نمایش در خروجی.
