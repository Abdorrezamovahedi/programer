فضاهای نام (Namespaces)

هدف این درس: یک کلاس ساده با سازنده و یک متد بنویسی.

پوشه: OOP  |  پیش‌نیاز: درس‌های قبلی همین پوشه («OOP») را با تایپ و اجرا خوانده باشی.

مفهوم به زبان ساده

کلاس قالب است؛ شیء نمونهٔ ساخته‌شده از آن قالب است. سازنده موقع ساخت اجرا می‌شود. $this به همان شیء اشاره می‌کند.

ساختار (Syntax)

class User { public function __construct(private string $name) {} }

مثال 1: کاربر

<?php class User { public function __construct(private string $name) {} public function hello(): string { return "سلام " . $this->name; } } echo (new User("سارا"))->hello(); ?>
__construct: موقع new صدا زده می‌شود.
$this->name: دادهٔ همان شیء.
new User: یک نمونه می‌سازد.

اشتباه رایج مبتدی‌ها

صدا زدن متد بدون new
چرا اشتباه است؟ متد متعلق به نمونه است نه فقط نام کلاس (مگر static).
چه می‌بینی؟ خطا
درست: اول new بعد متد
معیار تمام‌شدن درس: یک کلاس با یک متد بسازی و خروجی‌اش را ببینی.
جمع‌بندی
  • کلاس قالب است
  • new نمونه می‌سازد
  • $this خود شیء است
