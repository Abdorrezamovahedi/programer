MCD programmers
===============

ساختار پروژه
------------
- index.html: صفحهٔ اصلی و ورودی مسیرهای یادگیری
- python/، html/، css/، javascript/ و php/: دوره‌ها
  - index.html: فهرست موضوع‌های هر دوره
  - پوشهٔ شماره‌دار هر موضوع: فهرست درس‌ها و فایل‌های درس
- tamrin/: تمرین‌های برنامه‌نویسی
  - index.html: صفحهٔ اصلی تمرین‌ها (انتخاب زبان)
  - python/، html/، css/، javascript/، php/: هر زبان پوشهٔ جدا
  - داخل هر پوشه:
      - index.html = فهرست تمرین‌های آن زبان
      - هر تمرین یک فایل HTML مستقل (صورت‌مسئله + مثال + خروجی مورد انتظار + راهنما)
- assets/css/: شیوه‌نامهٔ مشترک صفحات
- assets/js/: رفتارهای مشترک و دادهٔ تمرین‌ها
- robots.txt و sitemap.xml
- madrase-programmers-single.html: نسخهٔ یک‌صفحه‌ای

راهنمای ویرایش برای افراد غیربرنامه‌نویس
---------------------------------------
- متن یک درس: فایل HTML همان درس را باز کن و متن داخل تگ‌های p و h3 را عوض کن
- متن یک تمرین: برو به tamrin/نام-زبان/ و فایل همان تمرین را ویرایش کن
  (صورت‌مسئله، باکس مثال، راهنماها همه در همان فایل هستند)
- ظاهر مشترک: assets/css/main.css
- نام پوشه‌ها و فایل‌ها فارسی و خوانا هستند

اجرا در رایانهٔ شخصی
-------------------
از ریشهٔ پروژه:

    python -m http.server 8080

سپس http://localhost:8080 را باز کنید.
