مدرسه برنامه‌نویسان
===================

ساختار پروژه
------------
- index.html: صفحهٔ اصلی و ورودی مسیرهای یادگیری
- python/، html/، css/، javascript/ و php/: دوره‌ها
  - index.html: فهرست موضوع‌های هر دوره
  - پوشهٔ شماره‌دار هر موضوع: فهرست درس‌ها و فایل‌های درس
- tamrin/: تمرین‌های برنامه‌نویسی
  - index.html: صفحهٔ اصلی تمرین‌ها
  - python/، html/، css/، javascript/، php/: هر زبان پوشهٔ جدا
  - داخل هر پوشه: هر تمرین یک فایل HTML مستقل + index.html فهرست
- assets/css/: شیوه‌نامهٔ مشترک صفحات
- assets/js/: رفتارهای مشترک، جست‌وجو و تمرین‌ها
- robots.txt و sitemap.xml: راهنمای خزنده‌های موتور جست‌وجو
- madrase-programmers-single.html: نسخهٔ یک‌صفحه‌ای مستقل

راهنمای ویرایش برای افراد غیربرنامه‌نویس
---------------------------------------
- متن صفحهٔ اصلی: index.html
- متن یک درس: فایل HTML همان درس را باز کن و فقط متن داخل تگ‌های p و h3 را عوض کن
- متن یک تمرین: برو به tamrin/نام-زبان/ و فایل مربوط به آن مسئله را ویرایش کن
- ظاهر مشترک همهٔ صفحه‌ها: assets/css/main.css
- نام فایل‌ها و پوشه‌ها فارسی و خوانا هستند

نکته‌های مهم
------------
- نمونه‌کدها را داخل تگ pre و code نگه دارید
- در کد آموزشی فقط تورفتگی لازم زبان را حفظ کنید
- نام کلاس‌ها و شناسه‌های استفاده‌شده در JavaScript را بدون به‌روزرسانی هر دو طرف تغییر ندهید

اجرا در رایانهٔ شخصی
-------------------
از ریشهٔ پروژه اجرا کنید:

    python -m http.server 8080

سپس نشانی http://localhost:8080 را باز کنید.
