مدرسه برنامه‌نویسان
===================

ساختار پروژه
------------
- index.html: صفحهٔ اصلی و ورودی مسیرهای یادگیری
- python/، html/، css/، javascript/ و php/: دوره‌ها
  - index.html: فهرست موضوع‌های هر دوره
  - پوشهٔ شماره‌دار هر موضوع: فهرست درس‌ها و فایل‌های درس
- tamrin/: تمرین‌های برنامه‌نویسی
- assets/css/: شیوه‌نامهٔ مشترک صفحات
- assets/js/: رفتارهای مشترک، جست‌وجو و تمرین‌ها
- robots.txt و sitemap.xml: راهنمای خزنده‌های موتور جست‌وجو
- madrase-programmers-single.html: نسخهٔ یک‌صفحه‌ای مستقل

راهنمای ویرایش
--------------
- متن صفحهٔ اصلی: index.html
- متن درس: فایل HTML همان درس در پوشهٔ دوره
- ظاهر مشترک همهٔ صفحه‌ها: assets/css/main.css
- رفتارهای مشترک صفحه‌ها: assets/js/app.js
- جست‌وجوی درس‌ها: assets/js/search.js
- تمرین‌ها و آزمون‌ها: assets/js/exercises.js و پوشهٔ tamrin/

برای تغییر ظاهر، ابتدا کلاس عنصر را در HTML پیدا کنید و سپس همان کلاس را در
assets/css/main.css جست‌وجو کنید. برای تغییر رفتار، شناسه یا کلاس عنصر را در
HTML پیدا کنید و کاربرد آن را در فایل JavaScript مربوط بررسی کنید. نام کلاس‌ها
و شناسه‌های استفاده‌شده در JavaScript را بدون به‌روزرسانی هر دو طرف تغییر ندهید.

نمونه‌کدها را داخل تگ pre و code نگه دارید. در کد آموزشی فقط تورفتگی لازم زبان
را حفظ کنید؛ برای نمونه در Python تورفتگی بدنهٔ تابع و شرط بخشی از دستور زبان است.

اجرا در رایانهٔ شخصی
-------------------
از ریشهٔ پروژه اجرا کنید:

    python -m http.server 8080

سپس نشانی http://localhost:8080 را باز کنید.

نشانی صفحه‌های درس‌ها در نقشهٔ سایت و لینک‌های داخلی استفاده می‌شود؛ هنگام
سامان‌دهی پوشه‌ها، مسیرهای منتشرشده را تغییر ندهید مگر اینکه برای نشانی‌های
قدیمی تغییرمسیر دائمی در نظر گرفته شود. دامنهٔ فعلی نقشهٔ سایت در robots.txt و
sitemap.xml برابر با https://abdorrezamovahedi.github.io/programer/ است.
