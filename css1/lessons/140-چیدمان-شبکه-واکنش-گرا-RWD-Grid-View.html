چیدمان شبکه واکنش گرا (RWD Grid View)

در CSS، «چیدمان شبکه واکنش گرا» ظاهر عنصر را عوض می‌کند. HTML اسکلت است؛ CSS رنگ، فاصله و چیدمان است.

کجا به درد می‌خورد؟ هر صفحه وب که بخواهی «چیدمان شبکه واکنش گرا» را رویش ببینی.

گرید چیست

ردیف و ستون با هم.

.g { display: grid; grid-template-columns: 1fr 1fr 1fr; gap: 16px; }
خط 1: انتخاب می‌کند چه چیزی استایل بگیرد: «.g». این کلاس (نقطه یعنی class) است. آکولاد باز یعنی ویژگی‌ها از خط بعد شروع می‌شوند.
خط 2: نوع نمایش (بلوک، فلکس، گرید، مخفی…) را برابر «grid» می‌گذارد. اول نام ویژگی، بعد دو نقطه، بعد مقدار. نقطه‌ویرگول پایان این ویژگی است تا ویژگی بعدی قاطی نشود.
خط 3: تعداد و عرض ستون‌های گرید را برابر «1fr 1fr 1fr» می‌گذارد. اول نام ویژگی، بعد دو نقطه، بعد مقدار. نقطه‌ویرگول پایان این ویژگی است تا ویژگی بعدی قاطی نشود.
خط 4: فاصله بین بچه‌ها را برابر «16px» می‌گذارد. اول نام ویژگی، بعد دو نقطه، بعد مقدار. نقطه‌ویرگول پایان این ویژگی است تا ویژگی بعدی قاطی نشود.
خط 5: آکولاد بسته: قانون این انتخاب‌گر تمام شد.

۱۲ ستونه

مثل چارچوب‌های قدیمی.

.g { display: grid; grid-template-columns: repeat(12, 1fr); gap: 12px; } .span-6 { grid-column: span 6; }
خط 1: یک قانون یا بخش CSS: «.g { display: grid; grid-template-columns: repeat(12, 1fr); gap: 12px; }». انتخاب‌گر می‌گوید روی چه چیزی، آکولاد ویژگی‌ها را گروه می‌کند.
خط 2: یک قانون یا بخش CSS: «.span-6 { grid-column: span 6; }». انتخاب‌گر می‌گوید روی چه چیزی، آکولاد ویژگی‌ها را گروه می‌کند.

نواحی نام‌دار

خواناتر برای کل صفحه.

.page { display: grid; grid-template-areas: "h h" "s m"; } .header { grid-area: h; }
خط 1: انتخاب می‌کند چه چیزی استایل بگیرد: «.page». این کلاس (نقطه یعنی class) است. آکولاد باز یعنی ویژگی‌ها از خط بعد شروع می‌شوند.
خط 2: نوع نمایش (بلوک، فلکس، گرید، مخفی…) را برابر «grid» می‌گذارد. اول نام ویژگی، بعد دو نقطه، بعد مقدار. نقطه‌ویرگول پایان این ویژگی است تا ویژگی بعدی قاطی نشود.
خط 3: ویژگی «grid-template-areas» را برابر «» می‌گذارد. اول نام ویژگی، بعد دو نقطه، بعد مقدار. نقطه‌ویرگول پایان این ویژگی است تا ویژگی بعدی قاطی نشود.
خط 4: یک قانون یا بخش CSS: «"h h"». انتخاب‌گر می‌گوید روی چه چیزی، آکولاد ویژگی‌ها را گروه می‌کند.
خط 5: یک قانون یا بخش CSS: «"s m";». انتخاب‌گر می‌گوید روی چه چیزی، آکولاد ویژگی‌ها را گروه می‌کند.
خط 6: آکولاد بسته: قانون این انتخاب‌گر تمام شد.
خط 7: یک قانون یا بخش CSS: «.header { grid-area: h; }». انتخاب‌گر می‌گوید روی چه چیزی، آکولاد ویژگی‌ها را گروه می‌کند.

فاصله

gap ردیف و ستون.

.g { display: grid; gap: 12px 20px; }
خط 1: یک قانون یا بخش CSS: «.g { display: grid; gap: 12px 20px; }». انتخاب‌گر می‌گوید روی چه چیزی، آکولاد ویژگی‌ها را گروه می‌کند.

موبایل

یک ستون شود.

@media (max-width: 700px) { .g { grid-template-columns: 1fr; } }
خط 1: قانون شرطی برای اندازه صفحه. داخل پرانتز شرط است (مثلاً حداکثر عرض). فقط وقتی شرط درست باشد قوانین داخلش اعمال می‌شوند. «@media (max-width: 700px) {».
خط 2: یک قانون یا بخش CSS: «.g { grid-template-columns: 1fr; }». انتخاب‌گر می‌گوید روی چه چیزی، آکولاد ویژگی‌ها را گروه می‌کند.
خط 3: آکولاد بسته: قانون این انتخاب‌گر تمام شد.
گرید دو‌بعدی است؛ فلکس یک‌بعدی. برای کل صفحه گرید مناسب‌تر است.
